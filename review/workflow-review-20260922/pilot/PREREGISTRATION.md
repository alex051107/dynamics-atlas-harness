# 流程有没有用：小规模对照试验（事先登记）

登记时间 2026-09-22 晚 · 在任何一次运行之前写定 · 起草 Claude

## 要回答的问题

同一个模型读同一篇论文、填同一种数据库条目。给它阶段卡的一组，是否比不给的一组找到更多、更准的状态信息，说过头的地方更少。这是用户给这一轮定的完成标准的第一条。

## 试验对象

四篇没用来整理流程的论文，都有 PMC 开放全文，都在 PubMed 核对过身份。

| 代号 | 论文 | 选它的理由 |
|---|---|---|
| XIE20 | Xie 2020, Science, Abl 激酶，[10.1126/science.abc2754](https://doi.org/10.1126/science.abc2754)，PMC7920495 | 游离激酶在活性态和两个非活性态之间转换，药物 imatinib 只结合其中一个，正是"药物只结合一个 APO 状态"的例子 |
| STILLER22 | Stiller 2022, Nature, AdK，[10.1038/s41586-022-04468-9](https://doi.org/10.1038/s41586-022-04468-9)，PMC9126080 | 解出高能态结构，但测的是催化中的酶，考"算不算 APO"的判断 |
| PONT15 | Pontiggia 2015, Nat Commun, NtrC，[10.1038/ncomms8284](https://doi.org/10.1038/ncomms8284)，PMC4470301 | 未磷酸化的信号蛋白采样活性样构象，NMR 加 MD，考第六阶段 |
| WHIT13 | Whittier 2013, Science, 两种酪氨酸磷酸酶，[10.1126/science.1241735](https://doi.org/10.1126/science.1241735)，PMC4078984 | 活性位点环的开合速率和催化速率对应，也考"算不算 APO"的判断 |

这四篇跑完以后就算见过了，之后不能再当检验材料。流程冻结后的正式检验，改用 Gina 和 Soojung 留出的例子和另选的新论文。

## 两组

| 组 | 给模型什么 |
|---|---|
| 对照组（不给流程） | 任务说明、替代 APO 状态的定义、证据等级的说明、条目格式 |
| 流程组（给流程） | 对照组的全部内容，再加阶段卡（试验用冻结版，文件另存一份，跑的过程中不改） |

其余完全相同：模型、工具权限、能读的资料、输出格式、字数上限。两组都不许在条目里提到用了什么方法，避免评分时认出组别。

## 规模和模型

- 分析 agent 用 Sonnet。每篇每组跑 2 次，共 16 次。
- 参考答案每篇一份，共 4 份，由 Opus 在不看阶段卡的情况下，按同一条目格式通读全文写出，另列"必须写对的要点"和"算说过头的说法"。Claude 抽查。它是助手写的参考答案，不是专家金标准。
- 盲评每篇一次，共 4 次，由 Opus 完成。评分者看参考答案和打乱编号的四份条目（两组各两份），不知道哪份来自哪组。

## 能看到什么

- 分析 agent 只能读指定论文的 PMC 页面和补充材料，以及论文引用的 BMRB、PDB 条目；不做一般网页搜索，不读其他论文。
- 分析 agent 看不到参考答案、评分标准和其他运行的输出。
- 写参考答案的 agent 看不到阶段卡和任何一次运行的输出。

## 怎么打分

每份条目逐项打 0、1、2 分（错或缺、部分对、对），论文本身没有的项记"不适用"，不计入总分。

1. APO 判断：算不算替代 APO 状态，写明相对哪个配体。
2. 状态对：主状态和替代状态是否认对。
3. 交换参数：比例、交换速率是否正确并带出处。
4. 涉及残基或区域。
5. 身份依据：凭什么说次要状态像某个已知状态。
6. 结构与模拟：对应结构、MD 情况是否写对。
7. 功能相关性：是否写对，措辞是否和证据强度相称。
8. 证据类型与出处。
9. 证据等级是否合理。

另外数两个数：说过头的次数（超出论文证据的说法），事实错误的次数（数字、编号、条件写错）。

## 怎样算流程有帮助（事先定死）

- **有帮助**：流程组在四篇里至少三篇的平均总分高于对照组，而且流程组说过头的总次数不多于对照组。
- **没有显示出帮助**：达不到上一条，而且流程组也没有在三篇以上低于对照组。结论写成"这一版流程写进提示后，在单篇论文的信息提取上没有显示出优势"。
- **有害**：流程组在至少三篇里低于对照组，或者说过头的次数明显多于对照组。照实写。

样本很小，只报告逐篇结果和方向，不做显著性检验。

## 这个试验测不了什么

- 模型可能在训练中见过这些论文，无法排除。
- 参考答案来自助手，不是专家。
- 这里测的是"把流程写进提示"的效果，相当于计划第七节四组对照里"少量说明"对"全部写进提示"；按阶段卡一步步调度的 harness 还没做，它的效果这次测不到。
- 单篇论文的信息提取是短任务。会上说流程的价值主要在长流程里不跑偏，这个试验测不到那一部分。

## 运行记录与偏差（运行过程中追加，不改上面的设计）

- 2026-09-22 晚：第一轮 8 次运行（每篇每组 1 次）在分工分析返回之前先开跑，以节省时间；第二轮 8 次等分工分析确认设置后再跑。
- 同一时间：写参考答案的一个 agent 报告，有些 agent 在补充材料 PDF 被反爬拦截时会改用共享的内置浏览器，它的标签页曾被另一个 agent 导航到别的论文。风险是某次运行读错论文。处理：每份条目先核对写的是不是指定的蛋白和论文，读错的那次记为无效运行并单独报告，不悄悄重跑替换；第二轮两组的提示里都加一句"如需浏览器，只用自己新开的标签页，不碰别的标签页"，两组条件仍然一致。
- 同一晚：发现共享浏览器里还开着 Claude 之前预览计划用的标签页（08 号计划的 HTML，里面有中文的阶段卡总表），第一轮对照组运行期间一直在前台。发现后已关闭。没有迹象表明哪次运行读过它；评分时留意对照组条目里有没有阶段卡特有的说法，有就标出来。第二轮开跑前浏览器里不留任何项目文件。
- 参考答案的来源：四份都已写完。补充材料在 PMC 和 Europe PMC 被人机验证拦下时，三份参考答案改从同一文件的其他公开副本读取：Stiller 2022 用出版社的补充材料服务器，Whittier 2013 用 Internet Archive 保存的 PMC 同一文件，Xie 2020 用浏览器面板读 PMC 页面。没有绕过任何验证。分析 agent 的运行不受这条影响，但评分时如果参考答案里的某个数字只来自补充材料，而运行没读到补充材料，应当算作"缺"而不是"错"。
- Whittier 2013 的参考答案判定为 PTP1B 强标注、YopH 弱标注：它的游离态数据确实是在不含配体的酶上测的。选这篇时原以为它主要考"把催化状态误当 APO"，实际上它考的是反方向，就是会不会因为规则用过头而把它错判为不收录。两个方向都照样评分。
- 第二轮 8 次运行在分工分析返回之前开跑（分工分析已运行约 45 分钟仍未返回）。原先说第二轮要等分工分析，这里改了，理由是周四时间紧，而分工分析最多影响之后的安排，不太会改这次试验的设置。如果它的意见要求改设置，受影响的运行作废重跑，并在结果里写明。第二轮两组的提示在第一轮基础上只多了一句浏览器标签页的规则。
- 分工分析返回后逐条对照了它对这次试验的意见，判断不需要作废任何运行。
  - 它建议运行员用 Opus。这次两组都用 Sonnet，比较仍然公平，结论只适用于 Sonnet。
  - 它指出本工作区开的助手会自动带上项目的 CLAUDE.md。查了运行记录，确实每次运行都带上了，里面有"每条主张给出处""弃答是合法结果"这类规则。两组一样，所以对照组拿到的其实是任务说明加项目规则，流程组能多出来的空间更小。正式检验要换一个不带这些文件的目录跑。
  - 它指出 STILLER22 和写卡用的 Kerns 2015 同是 AdK。冻结的卡里没有出现 AdK 这个名字，Kerns 2015 作为出处出现 12 次，和 AdK 判断直接相关的有两条：第一阶段的卡住信号"替代状态是在结合底物时测的"，第四阶段的"晶体结构和 NMR 来自不同物种"。前一条任务说明的等级例子已经给了两组。照原规则判定，另外报告去掉 STILLER22 后三篇的方向，标明是事后补的。
  - 它建议参考答案另派人对照原文核对。登记里写的是"Claude 抽查"，改为每篇派一个 Sonnet 核对员逐项核对，核对员看不到卡和任何运行。Claude 此时已经在任务通知里看到过三份第二轮条目的全文，为免把条目里的说法带进参考答案，勘误只照搬核对员给出处的结论，Claude 不另加判断；勘误加在参考答案末尾，正文不动，全部在评分之前完成。
- 评分提示加三句，不改打分规则：表后附一个 JSON 块，方便脚本汇总；只在补充材料里的内容，条目没写算缺，不算事实错误（参考答案来源一条已经这样定）；参考答案末尾如有勘误，以勘误为准。
- 用脚本读了每次运行的工具调用记录。第一轮 8 次和第二轮已完成的运行里，对照组没有打开阶段卡；没有一次运行打开参考答案、别的运行、计划或证据表；没有一次用一般网页搜索。第二轮全部结束后再查一遍。
- 第二轮全部结束后复查：16 次运行都写的是指定的蛋白和论文，没有无效运行；流程组 8 次都打开了阶段卡，对照组 8 次都没有打开，16 次都打开了任务说明；条目复制成 E1 到 E4 的盲评文件后，没有阶段卡用语，也没有组别痕迹。
- 四份参考答案核对完，没有发现写错的数字、编号或条件，四个判定都被认为站得住，说过头清单里也没有哪条其实有论文支持。PONT15 和 WHIT13 各有一处出处位置写错；WHIT13 有一处论文正文和补充材料自相矛盾，记为有争议，两种读法都不算错；STILLER22 和 XIE20 各有一条图注与正文用词不一致的提示；XIE20 的补充材料核对员打不开，几处只在补充材料里的细节没有核。这些都以勘误形式加在各参考答案末尾，加完才开始对应那篇的评分。核对报告在 _sealed_reference 的 CHECK 文件里。
