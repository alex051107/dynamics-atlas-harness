# 阅读这些论文需要的生物与技术概念

解释服务于本项目的论文阅读。每项最后列出使用该概念的论文档案，那里保留具体方法、实验条件和局限。首次阅读先看左侧含义，再看它为什么会改变我们的判断。

## 分子、形状与功能

| 术语 | 具体是什么意思 | 为什么影响我们的设计 |
|---|---|---|
| 氨基酸、残基、侧链 | 蛋白由氨基酸连接成链；链上的一个单位常称残基，每个残基有连接主链及侧链部分 | “Phe4”是第4位苯丙氨酸残基；侧链暴露与整个结构域开闭是不同几何量。[L44](<paper_analyses/L44.md>) |
| 构象 conformation | 同一分子采用的一种空间形状 | 与更换序列的突变不同；比较前要核对是不是同一分子。[L16](<paper_analyses/L16.md>) |
| 结构域 domain | 蛋白中相对独立、常具有稳定折叠的部分；不同结构域可由柔性片段连接 | 每个结构域都预测得好，结构域之间的位置分布仍可能错。[L38](<paper_analyses/L38.md>) |
| 构建体 construct | 实验或模拟实际采用的具体序列，包括截短、突变、标签等 | 全长 HSP90 与孤立 N 端不是同一对象。[L01](<paper_analyses/L01.md>) |
| IDP / IDR | 内在无序蛋白 / 内在无序区域：在相应条件下没有唯一稳定折叠结构，但仍有形状与接触偏好 | 不应强行找一个“最佳静态结构”代表所有性质。[L16](<paper_analyses/L16.md>)、[L55](<paper_analyses/L55.md>) |
| 配体 ligand；apo / holo | 配体是与蛋白结合的分子；apo 通常指未结合，holo 指结合相关组分后的状态，具体配体由论文定义 | 结合条件与化学组分会改变分布；结构标签本身不是自由能测量。[L56](<paper_analyses/L56.md>) |
| 磷酸化 phosphorylation | 在特定位点加上磷酸基团的一类修饰，可改变电荷与相互作用 | 一个样品可混有不同修饰数目或位点，不能默认完全均一。[L02](<paper_analyses/L02.md>) |
| 突变 mutation | 蛋白序列发生特定替换等改变；例如 Y14A 表示第14位酪氨酸改为丙氨酸 | 突变可以检验接触假说，也可能同时改变修饰或其他性质。[L02](<paper_analyses/L02.md>) |
| 膜蛋白 membrane protein | 部分结构处于脂质膜中的蛋白；水相与膜内的化学环境不同 | 生成的形状必须与膜位置和构建体相容。[L57](<paper_analyses/L57.md>) |
| 纳米盘 nanodisc | 用支架蛋白围住一小块脂质双层形成的实验体系 | 支架局部距离与整盘形状看的是不同空间信息。[L04](<paper_analyses/L04.md>) |
| 催化活性 activity | 分子促进某种化学反应的能力，通常需用具体反应速率等量来测 | 看见闭合态、口袋或特定接触，不能直接代替活性测量。[L11](<paper_analyses/L11.md>) |

## 实验怎样“看见”分子

| 术语 | 具体是什么意思 | 为什么影响我们的设计 |
|---|---|---|
| 前向模型 forward model | 给定结构与测量条件，预测仪器应产生什么信号 | 两类实验各有自己的预测过程，不能把不同信号直接相减。[L13](<paper_analyses/L13.md>)、[B01](<paper_analyses/B01.md>) |
| FRET / smFRET | 荧光共振能量转移 / 单分子 FRET。两个探针之间的能量转移效率对距离、取向及光物理参数敏感 | 信号不是裸蛋白两点距离；单分子时间迹与效率直方图保留的信息不同。[L03](<paper_analyses/L03.md>) |
| Förster 半径 R₀ | 在相应简化条件下使 FRET 效率为一半的距离参数，依赖染料和环境 | 错误的 R₀ 会使效率到距离的换算共同偏移。[L08](<paper_analyses/L08.md>) |
| 染料 AV / ACV 模型 | 描述标签连接臂允许染料进入的空间；ACV 还考虑与表面接触的影响 | 从骨架坐标推算 FRET 时，要把探针位置的不确定性纳入。[L13](<paper_analyses/L13.md>) |
| 光子 burst、荧光寿命、各向异性 | burst 是一次观测中的一组光子事件；寿命是激发态衰减时间；各向异性反映偏振与转动等性质 | 它们帮助区分运动、噪声和染料接触；横轴有时间不等于同一种动力学。[L03](<paper_analyses/L03.md>)、[L45](<paper_analyses/L45.md>) |
| DEER / PELDOR | 通过自旋标签之间相互作用测量距离相关信息的一类脉冲电子顺磁共振方法 | 时间迹反演为距离分布依赖背景、正则化和数据长度，且常需核对低温制样条件。[L10](<paper_analyses/L10.md>) |
| SAXS / SANS | 小角 X 射线 / 中子散射，测量分子整体空间分布对散射的影响 | 一维曲线对许多不同结构可能相似；溶剂和对比度模型会影响解释。[L04](<paper_analyses/L04.md>) |
| 回转半径 Rg | 描述组成分子的位置相对于中心的分散程度，是整体尺寸指标 | 与链两端距离不是同一量；同 Rg 可对应不同形状。[L07](<paper_analyses/L07.md>) |
| NMR | 核磁共振：利用原子核在磁场中的行为探测化学环境、接触和运动等信息的一组方法 | NMR 不是单一观测量，必须注明实际使用的是 NOE、PRE、化学位移等哪一种。[L14](<paper_analyses/L14.md>) |
| NOE | 核 Overhauser 效应，核自旋间弛豫相关的信号，能提供接近程度信息 | 某些适用近似下涉及很强的逆距离幂依赖；处理后的距离上界不能当直接、精确的距离测量。[L04](<paper_analyses/L04.md>) |
| PRE | 顺磁弛豫增强，顺磁中心对附近核自旋弛豫的影响 | 少量短距离接触也可能有明显贡献；平均接触不等于所有接触同时存在。[L15](<paper_analyses/L15.md>) |
| 化学位移 chemical shift | 原子核的共振位置随局部电子/化学环境发生的变化 | 它能约束局部结构，预测器自身也有误差。[L14](<paper_analyses/L14.md>) |
| RDC | 残余偶极耦合，在部分取向条件下提供键方向与整体取向关系的信息 | 需要对齐张量等前向参数，不能按普通原子间距离处理。[L38](<paper_analyses/L38.md>) |
| J 耦合 / Karplus 关系 | 核自旋间通过化学键传递的耦合；某些耦合可用 Karplus 关系联系到扭转角 | 参数与模型误差影响从耦合推断局部构象。[L14](<paper_analyses/L14.md>) |
| 序参量 S² | 在指定模型与时间范围内描述角度运动受限程度的量 | 与“整体稳定性”或“活性”不是同一个指标。[L52](<paper_analyses/L52.md>) |
| cryo-EM / 冷冻电镜 | 从薄冰中分子的噪声投影等资料重建结构的方法；这里主要讨论单颗粒路线 | 图像、粒子选择和三维图各保留不同信息，模糊可能有多种来源。[L22](<paper_analyses/L22.md>)、[B01](<paper_analyses/B01.md>) |
| 玻璃化 vitrification | 快速冷却使样品形成非晶冰的制样过程 | 需要检查冷却是否改变目标群体与被测群体的联系。[L51](<paper_analyses/L51.md>) |
| 半图 half-map | 将颗粒资料分组后分别重建得到的图 | 为验证提供资料分离思路，但也要核对共享处理造成的依赖。[L09](<paper_analyses/L09.md>) |

## 从结构推断分布与时间

| 术语 | 具体是什么意思 | 为什么影响我们的设计 |
|---|---|---|
| ensemble / population / weight | 集合 / 状态群体比例 / 每个样本在计算中的权重 | 生成文件频率、实验推断权重和热力学群体需要分别标明。[L18](<paper_analyses/L18.md>)、[L53](<paper_analyses/L53.md>) |
| 平衡 equilibrium | 固定条件下整体分布随时间保持稳定，分子个体仍在运动 | 分布稳定与转换速度是不同信息。[L28](<paper_analyses/L28.md>) |
| 自由能 free energy | 联系群体概率与热力学条件的量，包含能量和熵的作用 | 一个构象势能较低，不足以证明对应状态最常见；状态所含构象数量也重要。[L39](<paper_analyses/L39.md>) |
| MD / 力场 / 粗粒度 | MD 是按动力学模型计算运动；力场近似相互作用；粗粒度把多个原子合成较少自由度 | 模拟的时间信息和精度依赖模型，粗粒度表示未必直接支持全原子观测。[L55](<paper_analyses/L55.md>) |
| 先验 / 后验 | 当前数据介入前采用的概率分布 / 结合数据和模型后更新的分布 | 后验的可靠性同时依赖先验、观测和误差模型。[L49](<paper_analyses/L49.md>) |
| 重加权 reweighting | 改变已有构象对整体预测的贡献 | 能调整已有状态比例，不能给库中不存在的状态分配有效样本。[L48](<paper_analyses/L48.md>) |
| 最大熵 MaxEnt / BME | 在给定约束与先验下尽量少添加额外分布假设；BME 将实验拟合与偏离先验的代价结合 | 需要保存观测误差、目标函数尺度和参数定义。[L26](<paper_analyses/L26.md>)、[L48](<paper_analyses/L48.md>) |
| KL 散度、θ、有效比例 | KL 量化相对先验的偏移；θ 控制该代价与数据拟合的相对强度；有效比例描述权重集中程度的一种定义 | 不同目标函数归一化会改变 θ 的含义；Q05 的约18%不等于活性态比例。[L04](<paper_analyses/L04.md>)、[L54](<paper_analyses/L54.md>) |
| CV / PCA | 集体变量是选来描述变化的少数坐标；PCA 找到数据中变化较大的线性方向 | 大方差不一定等于慢过程，低维图也会忽略其他差异。[L41](<paper_analyses/L41.md>) |
| 增强采样 / 自适应采样 | 前者通过专门策略增加难访问状态的探索；后者根据已观察结果调整后续起点等安排 | 输出分布是否需要重加权取决于具体方法；采样成本与动力学验证要分开。[L44](<paper_analyses/L44.md>)、[L58](<paper_analyses/L58.md>) |
| MSM / lag time | 马尔可夫状态模型用状态间转移近似动力学；lag time 是统计转移所采用的时间间隔 | 状态划分、采样及对时间间隔的稳定性都影响结论。[L28](<paper_analyses/L28.md>)、[L43](<paper_analyses/L43.md>) |
| WE / RiteWeight | weighted ensemble 通过带权的轨迹拆分/合并分配模拟工作；RiteWeight 根据局部转移估计权重 | 不是普通实验残差拟合；需要真实转移资料与足够连接。[L53](<paper_analyses/L53.md>) |
| 扩散生成 / 引导 | 生成模型逐步把噪声转换成结构；引导在过程中施加目标偏好 | 这里的“扩散”是生成算法，不是已经测得的分子随时间扩散。[L52](<paper_analyses/L52.md>)、[L59](<paper_analyses/L59.md>) |

## 评价方法与我们的系统

| 术语 | 具体是什么意思 | 为什么影响我们的设计 |
|---|---|---|
| RMSD / RMSF | RMSD 比较两结构的坐标差异；RMSF 描述某位置在样本集合中的涨落幅度，均依赖对齐等定义 | 结构接近、柔性轮廓相似与动力学速度不是同一个评价。[L56](<paper_analyses/L56.md>) |
| 残差 / χ² | 残差是预测减观测；χ² 类目标按误差尺度汇总残差平方 | 数据相关、预测误差和归一化会影响分数含义。[L02](<paper_analyses/L02.md>)、[L54](<paper_analyses/L54.md>) |
| 不可辨识性 identifiability | 不同模型在现有噪声与观测下可能无法区分 | 优化器输出一个答案，不证明只有这一种解释。[L14](<paper_analyses/L14.md>)、[L46](<paper_analyses/L46.md>) |
| 过拟合 / 保留数据验证 | 过拟合是对所用数据的细节适应却不一定能预测新资料；保留数据不参与该项拟合 | 对已用资料的改善与独立预测应分列；也要考虑共享来源与误差。[L05](<paper_analyses/L05.md>) |
| 消融 ablation | 在其他条件尽量一致时去掉一个组件，观察结果如何变化 | 去掉 Rules 后必须保持输入和主要计算可比，才能判断该组件贡献。[L36](<paper_analyses/L36.md>) |
| 精密度 / 准确度 | 重复测量是否集中 / 是否接近所关心的真实量 | 多实验室给相同答案仍可能共享系统偏差。[L08](<paper_analyses/L08.md>) |
| 收敛 convergence | 随计算继续，某个已定义结果或统计量趋于稳定 | 自身稳定不排除共同模型错误或漏掉重要状态。[L58](<paper_analyses/L58.md>) |
| Rules / operator / 工作流 | 本项目中，Rules 保存适用条件与动作要求；operator 实施具体计算；工作流组织输入、计算、验证和答案 | 必须分别检查规则覆盖、计算正确及最终科学答案，完整计划见[项目报告](<../reset_0908/REPORT_ZH.md>) |
