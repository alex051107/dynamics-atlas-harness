# 先读懂我们在研究什么，再读论文

这份导览从你给的博客与 JCIM 论文出发，再连接到近期相关研究。它帮助你先理解每篇论文为什么值得读；方法细节、数值和限制保留在[逐篇阅读档案](<paper_analyses/INDEX.md>)及综合综述（该链接目标未纳入本包）中。遇到陌生词，可以查[术语解释](<GLOSSARY_ZH.md>)。

## 先认识我们真正想回答的四个问题

蛋白质是一条由氨基酸连接而成的分子链。相同的链可以弯曲、局部展开，或者让两个较稳定的部分相对转动。同一分子采用的不同空间形状叫**构象（conformation）**；其中较稳定、能相对独立折叠的部分常叫**结构域（domain）**。

设想一个有开、闭两种形状的蛋白。这里的开闭只是几何描述，是否对应活性还要另查。研究可能依次问：

| 问题 | 实际想知道什么 | 怎样的资料才有帮助 |
|---|---|---|
| 闭合态存在吗？ | 分子是否能采用这个形状 | 结构、信号中可分辨的状态、可信的候选构象 |
| 闭合态有多少？ | 指定条件下多少比例的分子处于闭合态 | 对群体比例敏感的实验、具有可靠权重的集合 |
| 多快开关一次？ | 同一分子随时间转换的速度 | 带时间顺序的轨迹、时间分辨实验及相应动力学模型 |
| 开闭影响活性吗？ | 结构运动是否改变结合、催化等功能 | 功能测量、干预实验，以及结构与功能之间的对应证据 |

**构象集合（ensemble）包含可能的构象及其权重。** 如果 AI 给出一千个结构，七百个开放、三百个闭合，首先得到的是该生成流程的样本比例。要把它解释为溶液中分子的 70%/30%，需要证明生成或后处理过程能估计目标条件下的群体分布。这个数字是教学示意，不是任何论文的结果。上述四层区别贯穿整个综述。[Thomasen 与 Lindorff-Larsen 的方法综述](https://doi.org/10.1042/BST20210499)、[从可能性到精确分布的 Perspective](https://doi.org/10.1038/s41592-026-03084-z)。

## 第一份材料：博客先问“实验到底保留了什么”

*Are We Capturing the Ensemble?* 的关键，是把“我们关心的分子状态”与“仪器最后输出的数据”之间的过程展开。你关心常温溶液里的分子，实际样品可能经过冷冻；仪器只测到某种投影；分析程序再把大量原始数据压成一张图或几个参数。每一步都可能让某些差异保留下来，也可能把差异抹去。它是概念讨论文章，提出的是比较原则。[原文](https://rs-station.github.io/2026/08/31/are-we-capturing-the-ensemble.html)

**先看一个具体例子。** 平均 FRET 效率是“每种构象分别产生信号，再按比例平均”。FRET 可以理解为两个荧光探针之间、对距离敏感的能量传递。在简化模型中，效率与距离的六次方有关。因此，先平均距离再换算效率，通常会得到另一个答案。实验测到平均信号，不代表蛋白真的采用一个位于开、闭之间的“平均形状”。博客用前向模型说明的正是这一区别。[原文的 ensemble-average 部分](https://rs-station.github.io/2026/08/31/are-we-capturing-the-ensemble.html)

博客还区分两种资料。SAXS 这类测量汇总许多分子的贡献；单分子 FRET 可以沿同一分子观察时间变化；单颗粒冷冻电镜则从不同被冻结的分子取得投影，没有保留同一分子的运动顺序。因此，单颗粒图像丰富，不等于已经直接测到转换速度。平均测量也仍能约束分布的一些性质。[原文的 single-particle 部分](https://rs-station.github.io/2026/08/31/are-we-capturing-the-ensemble.html)

**对我们的设计有什么影响？** Rules 收到“两个集合不同”时，应先问差异落在哪个科学目标上、实验是否看得到；随后调用对应的信号预测。某个低维图上分成两团，不足以规定实验必须能区分两团。完整博客解读及其与冷冻研究的联系保存在[博客阅读档案](<paper_analyses/B01.md>)。

## 第二篇：JCIM 实际检验了 AI 提案怎样帮助模拟

Bhakat 的论文选用 **T4 溶菌酶（T4 lysozyme）**：这是一种能切割细菌细胞壁成分的酶，结构资料较丰富，两个结构域之间存在可研究的开闭运动。作者比较多种生成方法，再把它们提出的构象用作分子动力学模拟的起点。**分子动力学（MD）** 用近似的分子相互作用模型逐步计算运动，得到带时间顺序的轨迹；该近似模型称为**力场**。[论文](https://doi.org/10.1021/acs.jcim.6c02044)

作者先观察结构域开闭，以及第 4 位苯丙氨酸侧链暴露还是埋藏。**侧链**是每个氨基酸伸出主链的化学基团；暴露程度描述它与周围溶剂接触的情况。这两个几何描述把候选分成四个区域。多数纯生成结果集中在其中部分区域，说明大量生成文件仍可能没有探索到关键构象。[逐篇分析及 Fig.2–3 定位](<paper_analyses/L44.md>)

随后采用**自适应采样**：先运行一批较短模拟，根据已经访问的状态选择下一批起点。主文两轮合计 36 μs；另有总计 20 μs 的比较，其中常规 MD 为 20 条各 1 μs，自适应方案为 100 条各 200 ns。这里 1 μs 等于 1,000 ns。总模拟时间相同，单条轨迹长度与起点分配不同，所以“发现新区域的速度”与“长时间动力学是否可靠”仍需分别看。[逐篇分析及 Fig.1、4 定位](<paper_analyses/L44.md>)

去掉 AF-Cluster 提案后，闭合区域覆盖大幅减少；某个闭合区仍有 0.04%，应保留这个非零结果。这个消融说明：**好的起点确实能帮助有限预算的采样。** 后续实验预测和时间尺度检查仍留下差异，详细分析保留了 SI 中的 FRET 比较、MSM 时间尺度和区域权重信息。[逐篇分析及 Fig.5、SI 定位](<paper_analyses/L44.md>)

所以，我们应从论文借走的是“产生候选—运行物理模拟—估计群体—比较实验”的完整链条。原来的科学问题若只需要判断两组现有资料是否相容，可以先做信号比较；发现候选覆盖确实不足时，再考虑更昂贵的采样。单纯增加 Rules 条目不会产生缺失的构象。

## 顺着这两篇读，近期研究补上了哪几块

下面每一行都连接完整分析。正式文章与预印本的版本、读到的范围列在各篇档案中。

| 路线与论文 | 作者实际做的事 | 我们具体怎样借鉴 |
|---|---|---|
| [实验引导 AlphaFold3](<paper_analyses/L52.md>) | 在生成过程中加入实验约束，再经结构松弛与集合选择；检验 NOE 等资料，并采用额外指标检查模型 | 记录哪些资料参与生成/拟合，哪些留作验证；对已用约束的改善与独立预测分开报告 |
| [Metadiffusion](<paper_analyses/L59.md>) | 改变生成时的引导目标，也用样本之间的排斥扩大探索；过强引导可造成不良几何 | 几何修复后重新预测实验信号，不能继续沿用修复前分数 |
| [WE＋RiteWeight](<paper_analyses/L53.md>) | 从不同 AI 起始集合出发，用短轨迹的转移信息估计指定物理模型下的平衡群体 | 比较同一后处理能否消除起点依赖；无序结构文件不足以支持这类动力学重加权 |
| [STARLING](<paper_analyses/L55.md>) | 专门生成无序蛋白区域的集合，先对比模拟，再对比实验，并演示实验重加权 | 无序蛋白题可考虑专门的候选先验；仍需固定实验和前向方法后比较 |
| [trBME](<paper_analyses/L54.md>) | 用随时间变化的先验解释扰动后的时间分辨资料；BSA 示例使用合成数据 | 先区分平衡交换与受扰动后的演化；横轴都叫时间，不代表可用同一种模型 |
| [冷冻过程研究](<paper_analyses/L51.md>) | 用小蛋白模拟研究不同冷却速率对群体的影响及恢复问题 | 样品制备条件进入资料对应关系；冷冻前后的分布联系不能省略 |
| [BioEmu 的多任务评估](<paper_analyses/L56.md>)与[膜蛋白评估](<paper_analyses/L57.md>) | 分别检查柔性、突变、配体相关性质或膜环境，发现成功与失败依赖具体任务 | 分别评结构、比例、功能；注明参考是实验还是有限 MD，并检查膜等环境约束 |
| [Convergence is not correctness](<paper_analyses/L58.md>) | 在不同生物过程比较采样方法，发现自身结果稳定也可能偏离参考 | 将数值稳定、跨方法相容、实验预测分开检查；在需要昂贵计算时才扩验证 |

“无序蛋白区域（IDR）”指没有一个固定折叠形状的蛋白片段。它仍有序列依赖的接触和形状偏好，并不等于任意随机绳子。这解释了 STARLING 为什么需要专门学习这类分布。这里的**先验（prior）**是看当前实验之前采用的候选分布；加入数据后更新得到的分布常叫**后验（posterior）**。更新得更贴近已用实验，还需要检查是否能预测没有参与更新的数据。[STARLING](https://doi.org/10.1038/s41586-026-10141-2)、[整合集合方法综述](https://doi.org/10.1042/BST20210499)。

## 最值得一起精读的例子：Sic1 为什么比“拟合好了”更有说服力

Gomes 等人研究 Sic1 及其磷酸化状态。**磷酸化**是在分子特定位点添加磷酸基团，会改变局部化学性质与电荷；修饰后的样品可能包含不同修饰数目的分子。Sic1 属于无序蛋白，因此研究目标是构象分布如何改变，而不是寻找唯一的一张结构。[详细分析](<paper_analyses/L02.md>)

作者用 SAXS 约束整体空间分布，用 PRE 约束特定标签周围的接近关系，再将 FRET 留作验证。**SAXS**是小角 X 射线散射：一条曲线汇总分子内部的空间信息。**PRE**是顺磁弛豫增强：特定标签影响附近核磁信号的弛豫，对短距离接触很敏感。它们观测的空间关系不同，可以互相补充。

关键结果是：仅拟合 SAXS 时，FRET 的实验减预测效率差约为 0.17；仅用 PRE 时约为 −0.18；合用 SAXS 与 PRE 后约为 0.02，再加入化学位移后约为 −0.003。**化学位移**反映原子核局部化学环境，可提供局部结构信息。FRET 未被拿来调这套集合，因此这些差值比“参与拟合的分数下降”更能说明整合带来的预测价值。[Gomes，Table 1；详细分析](<paper_analyses/L02.md>)

同时，候选构象、探针模型、误差假设和混合修饰状态仍限制解释。论文支持一个更具体的集合描述；静态结构资料还不能独自给出功能因果和转换速度。保留这些限制，才能知道我们应该复用什么，以及下一步还缺哪种数据。

## 回到我们的 prototype：Rules 应该负责哪一步

我的设计判断是：**值得检验的是“给定真实资料，系统能否调用合适方法，得出范围清楚、可复核的科学答案”。** Rules Table 可以承载相对稳定的适用条件和后续检查；数值推断则交给经过验证的科学方法。

以 Sic1 为例，流程可以是：

1. 确认样品、修饰状态、条件与数据对应；保留论文结论作为待检验的参考。
2. 用固定候选集合分别预测 SAXS、PRE 与 FRET，记录各方法的误差与探针假设。
3. 按预先选定的方案，用 SAXS/PRE 更新集合，把 FRET 留作检验。
4. 报告哪些观测变好、哪些变差、哪些结构性质仍有多解；若有必要，再请求一个能区分这些解释的计算或测量。
5. 在同资料、同方法和同预算下比较有无 Rules 的工作流，判断它是否减少错误、改善有效答案或节约工作。

这是下一步的设计方案，尚未执行。本轮整理改变的是文献理解与阅读材料；它没有产生新的 Rules 正确率。工程可运行、论文支持某方法、我们已在独立问题上验证增益，是三个不同的进展状态。当前综合综述的项目设计（该链接目标未纳入本包）、[项目现状与完整计划报告](<../reset_0908/REPORT_ZH.md>)。
