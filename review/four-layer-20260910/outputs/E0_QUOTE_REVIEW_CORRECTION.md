# E0原文复核修正

初稿第11行以R28 NH1表格为证据，指称DHFR A2把O3P变化过度概括。完整阅读同一答复第7、43–48行后，该归因不够成立：答复正文明确写“O3P则混合”，且逐项列出NH2近距离比例上升。摘要“并不加强”较宽，但紧接“通常变长或比例降低”并非断言每项指标都下降。删除该错误计数，保留原始审计表供核查，不把措辞歧义升级为已证实科学错误。

撤回后剩12条观察来自7份有记录答复，实际审阅8份；其中仍含同一错误的多个表现和1条轻微措辞问题，因此不是12个独立核心错误。候选防范、实际回放与未验证防范作用继续分开。此修正不改变任何正在运行实验的题目、评分依据或运行顺序。

进一步核对A1同段的L28R N18均值，原答19.10→19.69 Å与原始缺陷表自身的19.64772281→18.50047205 Å不符，且方向被反转。已用独立标准库均值计算定位，加入一条有证据的新观察。因此最终为13条记录；它与初稿13条的内容不同。这里核对的是原表算术，原表的物理包装缺陷仍然成立。
