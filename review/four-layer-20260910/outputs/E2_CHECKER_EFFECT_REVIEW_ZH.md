# 一次反馈到底改变了什么

9条实际提示全部来自数字追溯，按“是否指向真实科学错误”计，精确率为0/9。提示原文本来只说未匹配，不说数字为假；这里测的是它作为科学纠错工具的价值。证据角色分支在E2没有输入，不能计作已验证能力。判断者为当前Codex，非独立专家。

12份反馈组初稿到终稿，没有一份降低核心错误数。V014丢失敏感性细分，V038丢失N18等支撑，V067改弱了图3错误表述，却新增M20百分比错误并删去N18支撑，核心错误数仍为1。V067首次检查无flag，仍在统一的一次修订机会中重写。因此损失属于整个反馈/修订流程，不能全部归因于错误警报。

普通组也有自发修订：V030修正O3P概括并补充支撑；V016新增因果升级，V064新增幅度大小写反。这说明“重写一次”本身有波动。ADK反馈组最终比普通组少错，但反馈组初稿已经没有这些错误，未建立检查器实际纠错的因果链。

主要比较未达预定的至少2/3题改善且不增遗漏：ADK核心错误中位数0.5→0；HSP90为0→0.5；DHFR为0→0.5，且DHFR遗漏中位数0.5→1.5。保留逐份得失，不用总体平均掩盖方向相反的结果。
