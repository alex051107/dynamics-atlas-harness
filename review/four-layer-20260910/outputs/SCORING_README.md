# Applying the already frozen scoring keys

This note describes recording, not a change to the frozen keys or success criteria. The primary reviewer reads de-identified final answers, the case key, and actual tool outputs. Conditions, run IDs and condition-specific rule IDs are withheld until scores are saved and sealed. E2 first submissions are also retained to inspect revisions. The evidence itself may reveal receipt of advice; blinding cannot guarantee that the reviewer cannot infer a condition.

For each answer, record each of its five frozen core units as supported correct / incomplete or omitted / incorrect, with an exact short quote or the location of the missing result. Count supported-correct units; retain a separate core-error count. An omission is not an asserted scientific error. Preserve subcomponent notes for bundled units instead of silently equating a partly answered unit with a fully correct one. Accept scientifically equivalent analyses under the original key.

Record critical overclaim, unnecessary abstention, defect recognition and consequential downgrade, useful next action, required evidence actually accessed, and actual analysis performed. A generic disclaimer does not cancel a contradictory positive conclusion. A clear partial answer with identified missing evidence is not unnecessary abstention. Source-reported numbers are not scored as the agent's computation unless it claims or executes the computation.

For E3, quote any affirmative transfer of an inapplicable method-specific prerequisite; discussion that rejects such a prerequisite does not count. For E4, retain coverage for the three predeclared subquestions and distinguish newly requested content from spontaneous discovery. For E2, independently judge the truth of each flagged item and any newly introduced error after feedback. Number occurrence in a log is not sufficient evidence of semantic provenance.

Save primary blind_scores.csv and supporting notes, timestamp and hash the completed score file, then reveal the condition mapping. Any later disagreement is written separately; do not replace the sealed score. Missing outputs, infrastructure failures and budget-limited attempts remain visible in denominators and completeness tables, not silently removed. An incomplete layer receives an incomplete-evidence conclusion rather than a forced scientific no-effect claim.

Report per-case distributions for n=4 and the frozen success tests. Do not claim significance, stable population accuracy, or human-time savings from model runtime. Human time not measured prospectively is unknown.

The referenced RULES_HARNESS_INCREMENT_ROUNDS_2_3_ZH.md §4 defines unnecessary abstention operationally as answerable key units not answered. Record that count separately from explicit refusals; it includes omissions and should not be described as evidence that the agent intentionally abstained. A genuinely unresolved point outside the answerable key is excluded. §5 specifies per-case medians across four runs; use those medians for per-case comparisons and also display all raw scores. E1b detection/downgrade is the expressly specified proportion. This preserves the pre-existing scoring method rather than selecting an aggregator after seeing outcomes.
