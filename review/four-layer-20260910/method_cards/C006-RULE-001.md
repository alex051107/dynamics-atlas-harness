方法卡 C006-RULE-001
适用方法族：SAXS
要核对：在 G1>G2>G3>G4 的重点检查中要求 SAXS likelihood, physical prior, nuisance error and state-weight parameterization；若无法验证则走 POSTERIOR_AMBIGUITY。
方法/算子：Bayesian_forward_model
依据：SAXS ensemble refinement needs an explicit intensity forward model, physical prior, nuisance/systematic-error model and posterior uncertainty because the curve is low-information.
来源：Shevchuk 2017 Bayesian SAXS refinement；SH-S02; SH-S04
迁移范围：state-number and prior choices remain explicit
可质疑：本卡是项目归纳；只有具体方法与物理对象适用时才执行。
