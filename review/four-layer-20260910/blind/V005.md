## 结论

**按首、末10%保存帧的均值变化，两个轨迹中两个结构域相对 CORE 的平均距离都增大，因此在这个指标上方向一致：都表现为相对 CORE 的外移/开放趋势。**但幅度不一致，而且依赖起始状态与结构域：

|起始轨迹|结构域–CORE|首10%均值 (Å)|末10%均值 (Å)|变化（末−首，Å）|
|---|---:|---:|---:|---:|
|open|NMP|26.216|26.286|+0.071|
|open|LID|34.393|36.683|+2.290|
|closed|NMP|25.252|26.343|+1.091|
|closed|LID|30.231|31.407|+1.176|

所以，open 轨迹主要表现为 LID 外移（NMP 仅 +0.071 Å，接近不变）；closed 轨迹中 NMP 与 LID 的外移幅度相近（约 +1.09 和 +1.18 Å）。描述性地，open 的 LID 变化约为 closed 的 1.95 倍，而 closed 的 NMP 变化约为 open 的 15.4 倍。这里的“方向”是平均结构域–CORE 距离的方向，不等同于已经从坐标拟合出的唯一刚体旋转向量；距离增大也可能包含局部重排。

## 实际分析与统计单位

我核对了列名、帧数、时间顺序和首末索引，然后对每条轨迹取 `floor(0.1*n)` 行的算术均值，并计算末均值减首均值：

* open：2253 帧，每端 225 帧；首段 frame 0–224，末段 2028–2252。
* closed：1678 帧，每端 167 帧；首段 frame 0–166，末段 1511–1677。
* 保存间隔为 0.2 ns；两端窗口的索引跨度分别为约 44.8 ns（open）和 33.2 ns（closed）。

每一行是一个保存帧；每个距离值是该帧内指定结构域与 CORE 的全部 Cα 对的平均分子内距离，单位 Å。帧不是独立实验重复；每种起始状态只有一条轨迹。因此没有把 225 或 167 帧当成独立生物学重复，也没有据此做独立重复意义上的 p 值检验。作为波动参照，首/末窗口的样本 SD 分别为：open-NMP 0.362/0.342 Å、open-LID 1.357/2.215 Å、closed-NMP 0.371/0.359 Å、closed-LID 1.444/0.987 Å；尤其 open-NMP 的 +0.071 Å 小于窗口内波动，不能据此宣称强的 NMP 定向运动。

## 与 Orädd 等（2021）及补充材料的联系

论文把 LID 视为 ATP-binding domain、NMP 视为 AMP-binding domain；底物结合相关的典型构象变化是两域相对 CORE 的向内旋转/闭合，晶体结构比较中约为 10–25 Å。论文使用从 open 和 closed 晶体结构开始的约 450 ns 和 335 ns MD：正文报告 open-start 轨迹可产生较闭合的 NMP 构象，而 LID 仍较开放；closed-start 轨迹则可访问较开放的域构象。当前首末距离结果与“起始状态影响域运动、两个域不必同步”的总体图景相容，但不能直接等同于论文的 RMSD 或 TR-XSS 距离差异矩阵：本题数据使用项目定义的非重叠内部集合 CORE 1–29、68–115、168–214，NMP 30–67、LID 118–160，而论文正文使用的边界不同。

对 ATP 结合响应的证据应分开理解：

1. **本题 MD 结果是间接背景证据。** 无配体的两条轨迹都能发生域–CORE 距离变化，且幅度依赖起始状态，说明 ADK 具有构象可塑性和预存构象集合；但不能证明变化由 ATP 引起。来源卡明确说明沉积坐标不含 ATP 或 AMP，且每个起始条件只有一条轨迹。
2. **ATP 因果响应的直接证据来自论文 TR-XSS。** 在 AMP 存在时用激光释放笼状 ATP，Orädd 等在 20 μs–25 ms 观察到时间演化散射信号；4.3-ms 晚期瞬态的结构精修显示 LID 与 NMP 均部分闭合，且 LID 伴随局部解折叠。论文据此提出 ATP 触发两个底物结合域的协同/同步部分闭合。补充 Fig. S4 提供晶体结构 Cα 距离差异矩阵；Fig. S5 显示 NMP 和 CORE 二级结构总体保持；主文 Fig. 5–6 与补充 Fig. S6–S7 则支持 LID 局部解折叠、Arg131–Asp146 盐桥相关性以及配体结合后的折叠恢复。

因此，当前数据可支持：ADK 的域运动不是一条对所有起始状态都相同的单一刚体路径；这与 ATP 结合时通过构象网络招募两个域的解释相容。但 ATP 触发、协同性和局部解折叠的直接证据主要是论文的配体触发 TR-XSS，而不是本题两条无配体轨迹的首末均值差。

## 仍未解决的内容

* 首末10%均值不能给出 ATP 结合的因果顺序、过渡时间、速率常数或真正的 LID-first/NMP-first 事件顺序；0.2 ns 保存间隔也不是 TR-XSS 的实验时间分辨率。
* 两条单轨迹不能估计 open/closed 的总体概率、重复性或统计显著性，也不能把 Å 级端点差直接解释成完整的 10–25 Å 闭合幅度。
* 平均距离不能区分刚体旋转、平移、局部解折叠和残基子群运动，也不能单独检测 Arg131–Asp146 盐桥或二级结构改变。
* 论文的笼状 ATP 释放与最早响应时间重叠，因此主要解析了 4.3-ms 晚期状态；ATP 结合后的超快初始事件、协同网络的传播方式，以及 induced fit 与 conformational selection 的相对贡献仍未完全区分。论文讨论认为两种机制可能并存。
* 当前衍生数据不是 ATP/AMP 结合态轨迹，且未提供实验散射曲线的逐点原始数值，不能仅凭本比较重建论文的 TR-XSS R-factor 精修。

## 最有信息价值的下一步

在相同残基定义下增加独立重复轨迹，分别比较 apo、ATP、AMP 和 ATP+AMP 条件；对每条轨迹联合分析 CORE 对齐后的 LID/NMP 局部 RMSD、刚体旋转角、域–CORE 距离、二级结构及 Arg131–Asp146 距离，再用预先定义的闭合指标和滞后/变点分析检验 ATP 是否提高闭合占比、先影响哪个域以及是否协同。若要直接连接实验，应使用与 TR-XSS 相同的结构集合和散射计算流程进行配体条件的 ensemble 拟合，而不是只比较端点均值。
