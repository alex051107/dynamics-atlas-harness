## 结论（带条件）

当前资料支持的最稳妥判断是：**SAXS 与蛋白局部 NOE 在经过 BME 重加权的构象集合中可以同时达到总体合理的一致，但这种一致是模型条件性的，且并不等于每一条 NOE 都被满足；跨观测一致性不能据此升级为唯一构象、真实热力学态比例或动力学结论。**

更具体地说：

1. **SAXS—NOE 的信息是互补而非重复。** 论文将 SAXS 解释为对约 10 Å 以上尺度的整体大小/形状、同时受蛋白和脂质影响的观测；NOE 则主要是蛋白带上的局部、特异原子间距离，不能直接提供脂质信息（`paper.txt` 第381–384行）。因此，二者能共同约束同一个 ensemble，并不要求每种观测单独决定同一组构象。
2. **原始 MD 已有“总体较好但有局部冲突”的特征。** 作者报告 SAXS 的中间 q 区域仍有偏差，且 methyl/amide NOE 总体较好但有少数超过实验上限（`paper.txt` 第300–318行）。这与“整体一致、局部不完全一致”的判断相符。
3. **联合 BME 结果支持可兼容性，但不是无条件验证。** 作者的 Table 2 给出：MD+SAXS+NOE 的 SAXS χ²=1.9、NOE χ²=6.0，且有效 ensemble size 为原始 frames 的约18%（`paper.txt` 第326–338、392–395行）。作者同时明确指出，χ²受最大熵正则影响，使用某类数据生成 ensemble 时，它只表示在该正则下的拟合程度，而不是无偏的模型检验（第376–380行）。

## 实际核对：逐点重算 SAXS 与 NOE 的直接比较

我读取了 `BME_reweight/reference_only/BME_stats_SAXS.dat`、`BME_stats_HN_NOE.dat`、`BME_stats_methyl_NOE.dat`，并把 SAXS 的 q 值与 `SAXS_and_SANS/Delta_H5_no_tag_Static_SAXS_30C_RB_subtracted.dat` 按 q 精确匹配；对每个点计算残差 `I_BME(q)-I_exp(q)`、RMSE、平均绝对误差，以及用实验文件第三列误差计算的 `χ² = Σ[(I_BME-I_exp)/σ]^2`。

结果（90个共同 q 点，q=0.00281393–0.240805694 Å⁻¹）为：

- SAXS RMSE = **0.00133546**；
- 平均绝对误差 = **0.000620667**；
- χ²=172.156，按90点归一化为 **1.913**。

该逐点结果与论文 Table 2 的联合结果（SAXS χ²约1.9）一致，直接支持“重加权 ensemble 对 SAXS 达到合理、但非完美拟合”。但这是对已给出的 BME back-calculated curve 的复核，不是独立重新优化。

同一资料包内的 NOE 交叉检查按实验文件的 `UPPER` 约束逐项进行：

- HN/amide NOE：292项中 **47项（16.1%）**高于对应 upper bound；
- methyl NOE：40项中 **8项（20.0%）**高于对应 upper bound。

因此，“联合结果总体可用”不能表述成“所有 NOE 均满足”。NOE 是上限约束，不是要求预测值等于文件中的标称上限；我采用是否超过 upper bound 作为比较。部分违规不自动证明 SAXS 与 NOE 互相矛盾，也可能反映局部构象、实验/模型误差或输入 ensemble 覆盖不足。

## 对方法卡要求的核对与限制

- **[rule id redacted]：部分满足。** 资料明确采用 BME/最大熵重加权：改变 MD frame 权重，同时平衡实验偏差和对原 ensemble 的扰动（`paper.txt` 第357–375行）；输入同时含 SAXS 和 NOE，且作者说明二者提供独立、互补信息（第376–395行）。因此可说存在共享权重、source-specific observables 的联合拟合。但 BME 本身不是 state discovery 或 kinetics estimator，现有文件也没有证明这些权重就是热力学态人口。
- **[rule id redacted]/002：不能完全验证，需标记 posterior ambiguity。** 本包可见 BME 的最大熵目标、超参数扫描文件和最终权重；但没有足够资料独立核查完整的 SAXS Bayesian forward likelihood、系统误差/nuisance 模型、物理先验、state-number 比较及 posterior sensitivity。因此不能把 χ²或权重唯一性当成后验确定性。
- **[rule id redacted]：不适用/未完成，而不是强行通过。** 当前对象是纳米盘，不是该卡所针对的 native IDP/heteropolymer 末端距离—全局尺寸反演问题；同时没有 distance-distribution assumption 与独立 model-check 结果。因此不能由 SAXS 与 NOE 的一致性推出 G1>G3>G4 式分布反演结论；若必须走该卡决策分支，应记录为 **INVERSE_MODEL_UNSUPPORTED**。

## 未解决部分

1. SAXS 核对使用的是已给出的 BME back-calculated curve；没有独立前向模型重建、替代 nuisance-error 模型或留出 q 区间检验。
2. χ²解释依赖实验误差列、q点独立性和数据处理方式；点间相关性、缩放/背景残差以及30°C无tag条件与其他资料的严格匹配，未在本次分析中重新估计。
3. NOE upper-bound 违规率是逐项诊断，不是正式 posterior predictive p-value；NOE 的加权方式、误差模型和不同 NOE 间相关性未独立重建。
4. 资料没有给出足以验证的 state-number、先验敏感性、后验区间或完整 model-check，因此不能判断是否遗漏了一个或多个显著构象状态。

## 信息价值最高的下一步

优先做预注册的留出/扰动检验：固定同一 MD prior，明确记录 SAXS intensity forward model、scale/background/systematic-error nuisance model 和 NOE upper-bound likelihood；分别留出一段 q 区间及一部分 HN/methyl NOE，比较 MD、SAXS-only、NOE-only、联合模型在未参与拟合数据上的 posterior predictive 残差，并改变先验/最大熵强度后报告预测区间。若联合模型只在训练数据上改善、留出数据不改善，则当前跨观测一致性主要是正则化拟合；若两类留出观测均改善，才更有力地支持共享 ensemble 的可迁移性。
