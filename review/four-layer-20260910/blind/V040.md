## 结论（限定在当前资料的 source-local consistency）

当前资料支持的最稳妥判断是：**MD/重加权构象集合与 SAXS 和 NOE 在总体上相容，但不是逐点、无冲突的一致；联合重加权能同时改善两类观测，却存在精度折衷，不能据此宣称唯一或已验证的真实构象集合。**

这里的“相容”是观测层面的拟合/诊断结论，不等同于跨实验独立验证，也不等同于证明动力学、构象人口或机制。

## 实际核对

### 1. SAXS：逐点用实验误差作了直接比较

我读取了 `/source/BME_reweight/reference_only/BME_stats_SAXS.dat`（90 个 q 点；列为重加权模拟值和实验值），并以 `/source/SAXS_and_SANS/Delta_H5_no_tag_Static_SAXS_30C_RB_subtracted.dat` 中相同 q 点的 `I_err` 计算

`z_i = (I_sim,i-I_exp,i)/I_err,i`，以及 `sqrt(mean((I_sim-I_exp)^2/I_err^2))`。

结果：

- 90 点的未加权强度 RMSE = **0.001335**（强度单位同原文件）；
- 按实验误差标准化的平方偏差和为 **172.16**，均方标准化偏差为 **1.913**（这里不是重新拟合得到的发表量，而是对给定重加权输出的当前计算）；
- 在论文讨论的 SAXS minimum 附近，q = 0.06936 Å⁻¹：模拟 0.00125、实验 0.00129，z = **−0.50**；
- 在 q = 0.15185 Å⁻¹：模拟 0.00408、实验 0.00401，z = **+1.80**；
- 在 q = 0.20382 Å⁻¹：模拟 0.00248、实验 0.00249，z = **−0.32**。

这直接支持“整体曲线相当接近、minimum 深度可捕捉，但中高 q 的 shoulder/局部点仍有偏差”的判断。论文也明确报告：MD 能较好捕捉约 0.07 Å⁻¹ minimum 的深度，但不能准确捕捉 0.15–0.20 Å⁻¹ shoulder（`/source/paper.txt:298-311`）。我的逐点核对与该描述一致。注意，标准化偏差的计算使用了实验误差列；文件没有明确说明所有误差项是否已涵盖背景、尺度和模型系统误差。

### 2. NOE：按其 upper-bound 语义检查，而不是把距离当作双向等式

我读取了重加权后的
`BME_stats_HN_NOE.dat` 和 `BME_stats_methyl_NOE.dat`，逐行以“模拟距离 ≤ 实验 upper bound”为满足条件：

- HN NOE：292 项中 **47 项超过上限（16.1%）**；最大超出 **4.91 Å**；
- methyl NOE：40 项中 **8 项超过上限（20.0%）**；最大超出 **2.75 Å**。

因此 NOE 不是“全部满足”，但大多数条目没有超过给出的上界，支持“总体符合、仍有少数局部冲突”。论文对原始模拟的定性结论也是总体良好但存在少数 methyl 和 amide NOE 违反，并指出 amide NOE 主要反映局部螺旋结构（`/source/paper.txt:312-318`）。

### 3. 跨观测的联合结果

论文 Table 2 给出的同一量纲下的 χ² 为（SAXS, NOE）：

- 原始 MD：**(10.0, 8.2)**；
- SAXS-only 重加权：**(1.5, 7.9)**；
- NOE-only 重加权：**(8.9, 4.2)**；
- SAXS+NOE 联合重加权：**(1.9, 6.0)**。

这说明两类观测的信息并非完全冗余：单独使用某一种数据主要改善其自身敏感的结构属性；联合使用仍可同时达到较低 χ²，但比各自单独优化时略差，表现为合理的折衷，而非两者互相否定。论文把 SAXS 描述为对整体大小/形状、蛋白和脂质 pair distribution 敏感，把 NOE 描述为纳米盘蛋白 belt 的局部原子距离、对脂质没有直接信息（`/source/paper.txt:376-395`）。

## 可以与不能下的判断

**可以下：**

1. 给定 MD 构象集合经过 BME 权重调整后，对 SAXS 的整体强度曲线和对 NOE 的多数约束可同时解释；这属于跨观测的**源内一致性/联合可拟合性**。
2. SAXS 与 NOE 约束具有互补性：SAXS-only 并不能把 NOE χ² 降到 NOE-only 的程度，反之亦然；联合结果保留了两种信息。
3. 不一致是有定位的：SAXS 在约 0.15–0.20 Å⁻¹ shoulder 附近、NOE 则有一部分局部 upper-bound 违反。故“总体相容”不能升级成“逐观测完美一致”。

**不能下：**

- 不能从这些数据判定某一个具体构象为 ground truth，也不能证明重加权集合给出了真实构象人口、交换动力学或机制；当前资料没有独立 ground truth/全面外部验证。
- 不能把 SAXS 的整体/平均散射与 NOE 的局部距离逐点一一对应；两者 forward observable、空间支持和时间平均语义不同。
- 不能把论文中的 χ² 当作独立验证，因为 Table 2 的数据本身被分别或联合用于重加权；论文也明确说明使用某类数据生成集合时，对该数据的 χ² 主要报告拟合程度（`/source/paper.txt:376-380`）。

## 限制与未解决部分

1. 当前比较主要是对已有 BME 输出的审计，不是从轨迹重新实现完整 forward model、误差协方差和 BME 优化；NOE 文件是 upper-bound 约束，而 SAXS 是强度曲线，不能用同一个简单误差模型概括。
2. NOE 结果文件给出了重加权模拟值和 upper bound，但没有在该输出中逐项给出可用于统计检验的独立测量不确定度；因此“16.1%/20.0% 违反”是约束计数，不是显著性或真实错误率。
3. BME 权重总和约为 1；我从 `/source/BME_reweight/reference_only/BME_simulation_weights.dat` 计算得到有效帧数 `1/sum(w²)=84.6`（共 1195 帧）。这提示重加权并非均匀使用全部帧，但有效样本的自相关、重复模拟之间的独立性和权重不确定度未在当前计算中估计。
4. 资料把该数据用于拟合；因此联合 χ² 的改善不能单独充当外部预测验证。论文虽提到 PRE/EPR 可作额外检查（`/source/paper.txt:396-401`），本题给定数据中没有把这些观测的逐点数值和不确定度完整纳入本次核对。

## 信息价值最高的下一步

最有区分力的是**预先冻结权重/超参数和构象集合后，用未参与 BME 的观测作盲预测**：至少提供完整 PRE/EPR（以及可用的 SANS）实验值、误差/协方差和对应 forward calculations；同时对两个独立 MD replicate 做 block/bootstrap 重采样，报告 SAXS q 区间、NOE 上界违反、χ² 和有效样本数的置信区间。这样才能把目前的“联合拟合且总体相容”推进到有明确外部验证边界的跨观测预测检验。
