## 结论

**不能说两条轨迹的 LID/NMP 相对于 CORE 运动“方向与幅度都一致”。**按给定的距离指标，四个比较都是首末均值增加，即 LID–CORE 和 NMP–CORE 的平均 Cα 间距都变大；若把“变大”解释为相对 CORE 更向外/更开放，则**方向（标量意义下）一致**。但幅度明显不一致，而且这不是论文所说的 ATP 触发闭合方向：

|起始轨迹|比较单位|首10%均值 → 末10%均值|变化（末−首）|
|---|---:|---:|---:|
|open|NMP–CORE|26.216 → 26.286 Å|+0.071 Å|
|open|LID–CORE|34.393 → 36.683 Å|+2.290 Å|
|closed|NMP–CORE|25.252 → 26.343 Å|+1.091 Å|
|closed|LID–CORE|30.231 → 31.407 Å|+1.176 Å|

因此，open 起始轨迹主要表现为 **LID 外移/开放（约 2.29 Å），NMP 基本不变**；closed 起始轨迹则是 **LID 和 NMP 都外移，幅度相近（约 1.18 和 1.09 Å）**。同一结构域在两轨迹中的幅度也不一致：LID 的 open−closed 变化差约 +1.114 Å，而 NMP 的 open−closed 变化差约 −1.020 Å。

## 统计单位与计算

- open：2253 个保存帧，时间 0–450.4 ns；首/末 10% 各取 `floor(2253×0.1)=225` 帧。
- closed：1678 个保存帧，时间 0–335.4 ns；首/末 10% 各取 `floor(1678×0.1)=167` 帧。
- 每一行是一个保存帧；每个数值是指定结构域与 CORE 之间**所有相应 Cα 对距离的均值**，单位 Å。表中均值是帧均值再对首或末窗口求平均，不是独立实验重复的均值。
- 作为窗口内波动的描述，首/末窗口样本 SD（Å）为：open NMP 0.362/0.342、open LID 1.357/2.215；closed NMP 0.371/0.359、closed LID 1.444/0.987。它们是逐帧波动，不是标准误，也不构成轨迹间显著性检验。
- 我检查了帧数、时间步长（0.2 ns）、首末窗口取法和距离单位；已有检查记录显示两套轨迹全帧连续性通过、无链内最小映像跳变，代表性距离与 GROMACS 打印值的最大差约 0.005 Å。这里的“方向”只能指平均距离增减；单个标量距离不能唯一恢复三维旋转方向。

## 与 Orädd 等（2021）的关系

论文及补充材料定义的物理图景是：LID（ATP-binding domain）和 NMP（AMP-binding domain）相对于 CORE 向内旋转、闭合，晶体构象差异约为 10–25 Å；论文使用的域边界是 LID 118–167、NMP 30–67、CORE 1–29/68–117/161–214。当前逐帧数据采用项目预先指定的非重叠内部集合（LID 118–160、CORE 1–29/68–115/168–214），所以数值不能直接当作论文原始 RMSD 或其 Cα 距离差矩阵。

论文的关键实验是 ATP 光释放后的 TR-XSS：在 AMP 存在时，约 4.3 ms 的后期瞬态由 LID 的局部展开、LID 部分闭合和 NMP 部分闭合共同描述；作者据此提出 ATP 触发两结构域的协同性闭合。主文还报告，从 open/closed 起始的 MD 中，open-start 可出现 NMP 闭合而 LID 保持开放，closed-start 两域都曾接近 open 构象；这些是轨迹内部的构象采样，不等同于 ATP 结合实验。

本题结果能提供的证据是较有限但有价值的：

1. **支持起始构象影响后续域运动。** open-start 的 LID 和 NMP 变化不对称，closed-start 的两域变化较协调，说明单一“刚体、固定幅度”的闭合路径不能概括这两条无配体轨迹。
2. **提示域间运动可能具有条件依赖的协同性/非协同性。** closed-start 中两个距离增量相近，而 open-start 中 LID 增大、NMP近乎不变；这与论文强调必须同时考虑 LID 和 NMP、且存在协同结构响应的观点相容，但不直接证明 ATP 诱导该响应。
3. **不支持把本数据本身解释为 ATP 触发闭合。** 两条轨迹均为距离增大（更开放的标量趋势），且来源说明坐标文件不含 ATP 或 AMP；因此它们不能直接复现论文的 ATP 结合后向内闭合结果，也不能仅凭此证明 ATP 是触发因子。

## 仍未解决的问题

- 只有每个起始条件一条轨迹，帧不是独立重复；不能给出可靠的轨迹间 p 值、总体方差或生物学重复结论。
- 首末 10% 是时间窗口均值，不是状态间配对差分；轨迹长度不同，且未去除 burn-in。不能排除漂移、松弛或有限采样造成的末端变化。
- 平均域间距离是压缩的标量，无法确定真实旋转轴、局部开裂、域内重排或“向内/向外”的三维方向；也没有直接计算 ATP 结合坐标、RMSD-to-open/closed、接触数或二级结构。
- 没有配体的这两条平衡/松弛 MD 不能回答 ATP 结合的因果顺序、结合动力学（论文实验覆盖约 20 μs–25 ms）或 induced-fit 与 conformational-selection 的相对贡献。
- Orädd 等的 TR-XSS 是群体平均信号；作者也明确指出 4.3-ms 瞬态可能是构象选择导致的开闭群体偏移，而不一定是单一路径的诱导契合。因此当前两条轨迹不能把“协同”唯一归因于 ATP 触发的单分子机制。

## 有信息价值的下一步

最有区分力的是在相同体系和重复数下加入 ATP（并保留 AMP、Mg²⁺条件对照），每个起始状态运行多条独立轨迹，按同一域定义计算：三维 CORE 对齐后的域质心/主轴旋转、LID/NMP–CORE 距离矩阵、接触数、RMSD-to-open/closed、LID 二级结构和 Arg131–Asp146 盐桥；再用 block/bootstrap 或轨迹级重复进行不确定度估计。把这些模拟 observable 与 TR-XSS 的 4.3-ms 部分闭合/局部展开模型比较，才能检验 ATP 是否使两域同时向内、是否 LID 先动，以及是否存在配体诱导的 cracking。
