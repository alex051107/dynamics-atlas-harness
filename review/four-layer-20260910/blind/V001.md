## 结论

**方向上：两条轨迹中 LID 和 NMP 相对 CORE 的平均距离均增加，因而按本数据定义都是向外/更开放的运动；幅度上：不一致。**但这里的“向外”仅指相对于 CORE 的平均 Cα–Cα 距离增加，不等同于直接测得的刚体旋转角或唯一反应坐标。

- **开态起始轨迹**（2253 帧）：NMP–CORE 首/末 10% 均值分别为 **26.2157/26.2864 Å**，变化 **+0.0707 Å**；LID–CORE 为 **34.3927/36.6831 Å**，变化 **+2.2904 Å**。因此开态轨迹主要是 LID 距离增加，NMP 变化很小。
- **闭态起始轨迹**（1678 帧）：NMP–CORE 首/末均值为 **25.2523/26.3432 Å**，变化 **+1.0909 Å**；LID–CORE 为 **30.2308/31.4073 Å**，变化 **+1.1764 Å**。该轨迹中两者方向相同，幅度近似相当。

所以，若“一致”同时要求方向和幅度，答案是：**方向一致，幅度不一致；幅度差异依赖起始构象。**两条轨迹各只有一个起始条件实例，末端差异不能直接解释为总体动力学速率或普遍响应。

## 统计单位与实际分析

每行是一帧，时间间隔 **0.2 ns**；距离是指定结构域与 CORE 间全部 Cα 对距离的平均值，单位 **Å**，不是 RMSD、旋转角或散射强度。按 `floor(帧数×0.1)` 取窗口：开态首/末各 **225 帧**，闭态各 **167 帧**；变化量为“末 10% 均值 − 首 10% 均值”。帧不是独立实验重复。

我实际读取两份 TSV，检查帧数和时间范围，并用 Python 对每个窗口求均值及变化量。窗口内逐帧样本 SD（仅作波动参考）为：开态 NMP 0.362/0.342 Å、LID 1.357/2.215 Å；闭态 NMP 0.371/0.359 Å、LID 1.444/0.987 Å（依次为首/末窗口）。因此开态 NMP 的 +0.0707 Å 相对其逐帧波动很小；不能把帧数当独立样本并据此作普通显著性检验。

## 对 ATP 结合响应的证据

这组派生距离数据与 Orädd 等（2021）的总体图景**部分相容，但不能单独重现实验结论**。

1. 论文将 LID（ATP 结合域）和 NMP（AMP 结合域）视为相对 CORE 运动的柔性域；完全开—闭晶体结构比较中，两域有相对 CORE 的向内旋转，尺度约 **10–25 Å**。本题首末变化为 **0.07–2.29 Å** 的平均 Cα 对距离差，不是论文的开—闭距离差矩阵，不能直接数值比较。
2. 论文的 TR-XSS 实验在 AMP 存在时光释放笼状 ATP，观察到约 **4.3 ms** 的晚期中间态；最佳拟合结构对显示 LID 和 NMP 均部分闭合/协同变化，同时 LID 局部解折叠。当前数据中两个域都发生可测的相对 CORE 变化，说明两域运动可能相关；但是本题轨迹的首末距离是增加，即开放方向，不能直接证明 ATP 触发的向内闭合。
3. 论文的 MD 结果显示，闭态起始模拟可访问类似开放晶体结构的构象；开态起始模拟产生较闭合的 NMP 构象而 LID 仍较开放。当前端点均值可作为“运动幅度依赖起始构象”的补充观察，但不能替代论文用结构对和散射曲线进行的拟合。
4. 论文及补充材料还支持 LID 的 Arg131–Asp146 盐桥断裂和局部解折叠可能参与响应；当前数据只有两个域—CORE 平均距离，不能检验盐桥、二级结构或局部解折叠。

## 仍未解决的部分

- **ATP 因果性**：来源卡说明坐标文件不含 ATP 或 AMP；这些无配体轨迹的距离变化不能证明由 ATP 结合引起。
- **运动几何**：平均跨域距离增加可能来自局部柔性、域内变形或不同区域的相对运动，不能唯一确定旋转轴、闭合角或开/闭状态。
- **协同性与顺序**：首末均值不能说明 LID 先动还是 NMP 先动，也未检验逐帧相关或滞后关系。
- **统计可推广性**：每个起始条件只有一条轨迹，帧具有时间相关性，不能估计总体效应或实验显著性。
- **模拟—实验对应**：模拟为 303.15 K、数百 ns；实验为 294 K、μs–ms，时间尺度不能直接标定。
- **机制判别**：诱导契合和构象选择仍都可能；论文也明确指出群体时间序列可能反映快速开—闭平衡向闭态偏移。

## 有信息价值的下一步

1. 对逐帧 LID–CORE 与 NMP–CORE 信号做交叉相关和滞后分析，并按相关时间 block bootstrap 或降采样；
2. CORE 对齐后计算域质心位移、主轴/旋转角和逐残基距离差矩阵，把“距离增加”与真实开合区分开；
3. 检查 Arg131–Asp146 距离、二级结构和 LID 局部 RMSD，直接检验 cracking/解折叠机制；
4. 加入 ATP、AMP 及双配体的多条独立重复轨迹，与无配体对照比较，再计算散射曲线并与实验 late basis spectrum 拟合。
