## 结论

在作者沉积的四条 1 μs 轨迹中，按逐帧重原子距离分析，论文关于“4′-DTMP 增加 M20 环相互作用”的描述得到**明确但有条件的支持**：最强、最一致的是 M20 N–O3P；WT 中也有 N18、W22 等配对显著靠近，而 L28R 中这些效应仍存在但幅度较小。关于“L28R 中 4′-DTMP 加强 R28 相互作用”，得到**明确支持**，主要是 R28 NE/NH1/NH2–O4P/O5P；但不是所有 R28 原子对都加强，O3P 配对反而多不变或变远。

这些局部几何证据与表1和图3共同支持的最稳妥结论是：L28R 使两种抑制剂的平衡亲和力都明显变弱，但 4′-DTMP 在 L28R 中相对 TMP 具有额外的、动态的尾部—R28 锚定，并在抑制实验中表现出较强的动力学抑制效果；因此其优势主要可归因于局部相互作用和产物释放/催化周转动力学，而不能据此声称 4′-DTMP 在 L28R 上具有更强的平衡结合亲和力。

## 比较条件、窗口和统计单位

比较了四条条件特异轨迹：WT–TMP、WT–4′-DTMP、L28R–TMP、L28R–4′-DTMP。数据文件的 ligand residue 分别为 TMPP/D4PP，四条轨迹各 1001 帧。主分析采用 frame 11–1000，即按沉积说明的 nominal 1 μs 映射去除前 10 ns；统计单位是**轨迹帧**，不是独立重复。每条轨迹因此为 990 个逐帧观测；不能把 990 帧当作 990 个独立实验样本，也不能把这四条轨迹当作论文所述重复 210 ns 模拟的全部重复。

距离是作者提供的、用 VMD `measure bond` 得到的重原子欧氏距离，单位 Å。为与 Figure 4 的解释保持一致，计算了每个原子对的均值、逐帧 `<6 Å` 比例（作者正文称其代表动力学轨迹中“频繁”氢键接触的近距离指标），并额外报告严格 `<3.2 Å` 的帧比例。后者不能单独当作完整氢键占有率，因为氢键定义还需要 20° 角条件，而角度数据未提供。

## 逐帧距离结果

### 1. M20 环：支持最强的是 M20 N–O3P

WT：

- M20 N–O3P：TMP 18.88 → 4′-DTMP 11.09 Å；`<6 Å` 帧比例 7.0% → 85.6%；`<3.2 Å` 0 → 1.1%。
- M20 N–O4P：19.95 → 13.23 Å；`<6 Å` 1.0% → 2.4%，支持很弱。
- M20 N–O5P：20.22 → 15.01 Å；两者 `<6 Å` 均为 0%，不支持。

L28R：

- M20 N–O3P：20.29 → 17.85 Å；`<6 Å` 0 → 70.1%；`<3.2 Å` 0 → 0.1%。这是清楚的动态靠近，但均值仍很大，说明接触是间歇性的。
- M20 N–O4P：20.80 → 19.71 Å；`<6 Å` 0 → 0.2%，基本不支持。
- M20 N–O5P：20.32 → 21.46 Å；没有近距离帧，方向反而变远。

所以，“4′-DTMP 增加 M20 环相互作用”应具体改写为：**M20 N 对 4′-DTMP 的 O3P 配对增加了显著的间歇性近距离接触**；不能推广到 M20 N 的 O4P/O5P，也不能仅凭所有 M20 配对都变短来表述。

### 2. 相关 M20 环/活性位点原子对

WT 中 4′-DTMP 相对 TMP 的强支持包括：

- N18 O–O3P：均值 18.14 → 12.16 Å，`<6 Å` 9.1% → 44.2%。但同一 N18 原子的 O4P/O5P 并不增强（分别 4.5% → 2.5%、13.9% → 0.2%）。
- W22 O–O3P：19.41 → 11.83 Å，`<6 Å` 1.9% → 80.3%。
- W22 O–O4P：21.14 → 13.01 Å，`<6 Å` 0.5% → 18.8%。
- D27 OD1/OD2–O3P：两组 `<6 Å` 分别 0 → 23.3% 和 0 → 40.2%，虽属于动态增强，仍未形成大量 `<3.2 Å` 帧。
- R52 NH1/NH2–O5P：均值约 22–23 → 15 Å，`<6 Å` 分别 1.1% → 38.0% 和 2.0% → 35.1%。

L28R 中，N18/W22 的 O3P 方向也支持但较弱：

- N18 O–O3P：19.65 → 18.50 Å，`<6 Å` 0.3% → 36.6%；但 O4P/O5P 不支持，后者 `<6 Å` 从 23.4% 降至 0。
- M20 N–O3P 和 W22 O–O3P 的 `<6 Å` 分别由 0 → 70.1% 和 0.2% → 71.0%。
- W22 O–O4P：0 → 18.3%，是较弱的附加支持。
- R52 NH1/NH2–O5P 也由约 0.1% → 15.3%/13.9%，但 O3P 配对没有增强，部分反而减少。

因此，“M20 loop interactions”在这四条轨迹中不是所有选定原子对的统一增强，而是明显的**配体氧位点选择性和轨迹动态重排**。

### 3. L28R 中 R28：明确支持集中在 O4P/O5P

对 L28R 的 R28 NE、NH1、NH2：

- NE–O4P：均值 19.65 → 17.52 Å；`<6 Å` 0.5% → 75.1%；`<3.2 Å` 0 → 21.9%。
- NE–O5P：21.32 → 17.81 Å；`<6 Å` 0 → 73.1%；`<3.2 Å` 0 → 39.4%。
- NH1–O4P：20.40 → 18.76 Å；`<6 Å` 7.1% → 72.9%。
- NH1–O5P：22.08 → 19.38 Å；`<6 Å` 0.9% → 53.7%。
- NH2–O4P：20.51 → 17.91 Å；`<6 Å` 6.7% → 70.0%；`<3.2 Å` 0 → 17.5%。
- NH2–O5P：22.16 → 18.47 Å；`<6 Å` 0 → 61.2%；`<3.2 Å` 0 → 20.0%。

这些是“4′/5′ 位氧与 R28 形成频繁强相互作用”的直接逐帧支持，尤其是 NE–O4P/O5P；严格 3.2 Å 近距离也显示 4′-DTMP 才出现相当比例的近接触。

但 R28–O3P 不支持“普遍加强”：NE–O3P 的均值 17.51 → 19.54 Å、`<6 Å` 45.6% → 38.1%；NH1–O3P 22.0% → 3.7%；NH2–O3P 23.2% → 36.4%。因此作者结论应限定为 O4P/O5P 选择性增强，而不是 R28 与配体所有氧的相互作用都加强。

## 与亲和力和抑制实验的合并解释

表1给出的 Ki（作者注明来自 ref. 25）为：WT TMP 4.2±0.5 nM、WT 4′-DTMP 5.1±1.0 nM；L28R TMP 65.0±7.5 nM、L28R 4′-DTMP 34.3±2.9 nM。也就是说，L28R 相对 WT 显著削弱两种配体的平衡结合；在 L28R 内，4′-DTMP 比 TMP 更强约 1.9 倍，但误差和量级不支持把它描述成巨大亲和力恢复。表中 ΔG 也相应为 WT −11.5/−11.4、L28R −9.9/−10.3 kcal/mol。

图3是在 12.5 μM DHF、500 nM 抑制剂的竞争条件下的重复动力学图，而不是结合常数测量。WT 中 TMP 和 4′-DTMP 都几乎完全阻止 DHF 消耗；L28R 中两者都只能减慢反应，且论文报告 4′-DTMP 对产物释放的减慢较 TMP 更明显。图像还显示 L28R+4′-DTMP 曲线高于 L28R+TMP，符合其在该实验时间尺度上抑制较弱/反应更慢的相对差异，但不能从图像反推出精确速率常数。

综合起来，最可辩护的机制结论是：L28R 的平衡结合损失不能由“4′-DTMP 与 R28 的新增接触”完全抵消；4′-DTMP 的取代基通过 O4P/O5P–R28 以及选择性的 N18/M20/W22 等尾部接触，改变配体构象和局部动态，从而在 L28R 中产生相对于 TMP 的动力学优势。局部距离证据支持“动态稳定/重排”而非一个始终存在的静态氢键网络。

## 仍不一致或未解决的问题

1. 仅有四条条件轨迹，且每条是一条长轨迹；没有独立复制的统计不确定度，990 帧的百分比不能当作独立样本置信区间。
2. 距离不是完整氢键判据；缺少供体—氢—受体角度，因此 `<3.2 Å` 只能称为距离近接触，不能等同于氢键占有率。
3. 轨迹文件只有所选原子对的距离，没有坐标、状态划分或配体构象标签，无法判断同一近接触是否属于同一结合姿态、是否协同发生，也无法直接得到 koff、产物释放速率或抑制速率常数。
4. 部分配对与作者概括不一致：WT N18 的 O4P/O5P、L28R N18 的 O4P/O5P、M20 的 O4P/O5P，以及 L28R 的 R28–O3P 并未增强；L28R 中一些原子对还变远。因此 Figure 4 的整体柱状图/“平均距离”概括掩盖了配对和氧位点的异质性。
5. 表1的 Ki 是文献转录值，不是本次轨迹分析的新实验；图3只提供发表的重复实验图和视觉曲线，缺乏原始数值，不能进行精确动力学重分析。
6. 尚不能仅凭这些证据区分：4′-DTMP 的优势究竟主要来自 R28 的直接局部接触、M20/FG 环的协同构象变化、产物释放步骤，还是多者共同作用。最有信息价值的下一步是用独立重复轨迹或原始坐标，以统一的距离+角度氢键判据和状态/构象分群，联同实验测定各条件的 kon、koff、kcat 与 product-release 分步参数；不需要新模拟来支持本次结论。
