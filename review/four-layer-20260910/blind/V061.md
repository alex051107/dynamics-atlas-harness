## 结论

**不能说 LID 与 NMP 的运动幅度一致；但按本数据的单一距离指标，两条轨迹中二者的首末变化方向一致，均为与 CORE 的平均 Cα 距离增加。** 因而这里的“同方向”是“该距离标量变大”（可称相对 CORE 的分离/外移趋势），不是已经由距离数据证明了完整三维旋转轴或刚体运动方向。

- **open 起始轨迹**：NMP–CORE 从 **26.2157 Å** 变为 **26.2864 Å**，Δ = **+0.0707 Å**（+0.27%）；LID–CORE 从 **34.3927 Å** 变为 **36.6831 Å**，Δ = **+2.2904 Å**（+6.66%）。LID 的绝对变化比 NMP 大约 **32.4 倍**。
- **closed 起始轨迹**：NMP–CORE 从 **25.2523 Å** 变为 **26.3432 Å**，Δ = **+1.0909 Å**（+4.32%）；LID–CORE 从 **30.2308 Å** 变为 **31.4073 Å**，Δ = **+1.1764 Å**（+3.89%）。两者幅度接近，LID 比 NMP 多 **0.0855 Å**（约 **1.08 倍**）。

所以，**跨轨迹比较时方向相同，但幅度模式不同**：open 轨迹主要是 LID 距离变化，NMP 几乎不变；closed 轨迹则是 NMP 和 LID 都约 1.1 Å 的变化。不能把这种结果概括为“两结构域总是协同、等幅运动”。此外，“距离增加”不等价于论文结构图所说的闭合/内旋方向；需要坐标向量、域质心/旋转拟合或 Cα 距离差矩阵才能判定真正的三维运动方向。

## 统计单位和计算方法

数据定义文件规定：每一行是一个保存帧；距离是指定结构域与 CORE 的**所有 Cα 对平均距离**，单位 Å；时间间隔为 **0.2 ns**；首末 10% 取 `floor(n×0.1)` 行，未去除 burn-in。实际计算如下：

1. open：2253 帧，取首、末各 **225 帧**；窗口分别为 0.0–44.8 ns 和 405.6–450.4 ns。
2. closed：1678 帧，取首、末各 **167 帧**；窗口分别为 0.0–33.2 ns 和 302.2–335.4 ns。
3. 对每个窗口内的逐帧 Å 值求算术平均，末窗均值减首窗均值；百分比为 Δ/首窗均值×100%。

因此这些数的统计单位是**帧内距离观测/保存帧**，不是独立蛋白分子、独立轨迹重复或实验生物学重复。帧间还可能有时间相关性，故不应把 225 和 167 帧直接当作独立样本来作常规显著性检验。作为波动检查，首/末窗口逐帧 SD（Å）为：open 的 NMP 0.362/0.342、LID 1.357/2.215；closed 的 NMP 0.371/0.359、LID 1.444/0.987。这些是描述性 SD，不是重复间误差。

## 与 Orädd 等（2021）的关系：能支持什么

论文把 AdK 分为 CORE、NMPbd（AMP-binding）和 LIDbd（ATP-binding），并指出经典开/闭结构显示底物结合伴随两个结构域相对 CORE 的大尺度闭合；其结构域定义为 LID 118–167、NMP 30–67、CORE 为 1–29、68–117、161–214（paper.md，第 11–17 行）。论文的 MD 结构精修使用了从 open（4AKE）和 closed（1AKE）起始的两条轨迹，分别约 450 ns 和 335 ns，并按每 1 ns 抽帧进行散射结构配对（第 55 行、第 145–149 行）。本题 TSV 则是项目定义的连续内域集合和所有 Cα 对平均距离，字段定义明确说明它**不是论文原始 RMSD 或散射坐标**；因此只能作相关的轨迹几何检查，不能冒充论文的 TR-XSS 结构精修结果。

在这一限制下，本计算可提供三点证据：

1. **结构域响应具有轨迹依赖性**：open 起始时 LID 的距离变化远大于 NMP，closed 起始时二者变化接近，说明从不同构象出发，两个域的局部几何响应并非固定的等幅模式。这与论文强调的构象集合、不同程度的部分闭合，而非单一确定过渡构象，是相容的。
2. **两个域可同时发生可测的变化**：closed 轨迹中 NMP 和 LID 均增加约 1.1 Å，说明不能只假定 ATP 相关响应限于 LID；从机制上与论文对“LID 和 NMP 部分闭合具有协同性”的报告相呼应。不过，本 TSV 的变化是距离增大，不能直接把它解释为论文实验中“向内闭合”。
3. **LID 可能是更显著/更柔性的响应部位**：open 轨迹 LID 的均值变化大且末窗波动增大（SD 2.215 Å），与论文报告的 LID 局部二级结构变化、Arg131–Asp146 盐桥断裂及 cracking/局部展开机制在定性上相容。论文正文第 65–83 行及补充材料 Fig. S4–S6 讨论了 LID 局部展开，而 NMP 和 CORE 的二级结构相对保持；但本数据本身没有二级结构、盐桥距离或展开判据，所以只能说“相容”，不能说已验证 cracking。

论文的实验核心是：在 AMP 存在时用笼状 ATP 光释放，TR-XSS 观察到约 **4.3 ms** 的晚期瞬态；最佳拟合结构显示 LID 和 NMP 均部分闭合，且 LID 部分展开（paper.md 第 41、55–57、83–85 行）。论文还明确指出两种底物都需要启动关闭机制，并承认 ensemble 时间序列也可能同时含有诱导契合和构象选择成分（第 93–105 行）。本题的两条无配体/未给出 ATP 结合事件的轨迹首末均值，**不能单独证明 ATP 结合因果性、4.3 ms 动力学或 TR-XSS 的散射拟合**；它最多为“两个域的响应可不同步/不等幅，并且存在协同变化的几何可能性”提供计算层面的补充。

## 仍未解决的问题

- “距离增大”究竟对应开化、局部展开、域旋转中的哪一种三维运动，当前两列标量不能判定；尤其不能直接与论文的“向 CORE 内旋闭合”对号入座。
- 轨迹是否含 ATP、AMP、Mg²⁺及其结合状态，题给表格未提供；因此不能从这两条轨迹隔离 ATP 特异响应，也不能区分配体诱导契合和无配体构象选择。
- 只有两条起始条件不同的单条轨迹，没有独立重复，且保存帧时间相关；首末 10% 差值不提供总体不确定度或显著性证据。
- 平均域间 Cα 距离掩盖了域内展开、局部盐桥破裂、域质心位移和旋转；也不能复现论文基于 CRYSOL/R-factor 的散射结构选择。
- 论文的 4.3 ms 是实验瞬态时间尺度，而本数据的帧间隔/轨迹时间是 ns；不能直接把轨迹时间或首末窗口映射成实验反应时间。

## 信息价值最高的下一步

1. 以 CORE 对齐每帧坐标，分别对 NMP 和 LID 做最佳刚体拟合，输出域质心位移、旋转轴/角度及相对 CORE 的投影；同时计算 open/closed 晶体参考的 Cα 距离差矩阵。这样才能把“标量距离变大”与真正的内旋/外旋区分开。
2. 对有明确配体和离子状态的多条独立重复轨迹，预先固定相同窗口，报告轨迹级均值、重复间 CI 和有效样本量；不要把相邻帧当作独立重复。
3. 联合计算 LID 二级结构、Arg131–Asp146 距离、NMP/LID 关闭坐标与配体接触，并与论文的 4.3-ms 最佳 R-factor 结构集比较；这才可以检验“ATP 结合—LID cracking—NMP/LID 协同响应”的链条，而不只是比较两列平均距离。
