## 结论及条件

**在所给的可复核读数下，不能支持“闭合起始比开放起始更容易离开原有构象并发生闭合→开放转变”这一整体命题。** 更准确的结论是分层的：

1. **按几何/接触双读数的方向标签，闭合起始确实显示出可观的向开放方向偏移；但开放起始组显示得更一致。** 在 20–1020 ns（每轨迹 1001 个 1-ns 点）的全分析窗口内，闭合起始轨迹中 10/20 条至少出现过一个 `OPEN_CONSENSUS` 帧，开放起始为 20/20；闭合起始还保留 `CLOSED_CONSENSUS` 的轨迹为 18/20，而开放起始为 0/20。按轨迹作为统计单位，后者更像开放起始组保持/进入开放读数，而不是闭合起始组更易离开原构象。

2. **若把“持久的闭合→开放候选”定义为：先出现持久的非冲突方向、随后出现相反方向的持久段，则闭合起始中只有少数候选，而且该字段不是“从种子状态出发”的转变判据。** 在 persistence=5、20、50 个保存点（定义上分别为历史 5、20、50 点；端点跨度分别为 4、19、49 ns）的结果中，闭合起始的 `opposite_direction_departure_candidate` 分别为 5/20、4/20、1/20，开放起始均为 0/20；`return_candidate` 两组均为 0。可是该算法把“第一持久方向”作为参照，且它可能不同于 `seed_lineage`，所以这些不是未经附加条件就可称为闭合→开放事件。尤其在 50 点标准下，闭合起始的第一持久方向为 CLOSED 11/20、OPEN 7/20；开放起始为 OPEN 20/20。因此，闭合起始中有些轨迹一开始的第一持久方向已经是 OPEN，不能由此证明它们经历了闭合→开放。

3. **严格 `state_core` 不是动力学状态转变证据。** 其定义是相对于 open/closed medoid 的锚定结构支持核心（阈值和半径固定），字段明确声明“not kinetic state”。全窗口只有闭合起始 1 条轨迹出现过 C 核心、开放起始 0 条；O 核心分别为 0/20 和 2/20（按 1001 帧计数：C=1、O=2，其余几乎全部 U）。这说明核心判据过于保守/与方向读数不等价，不能拿 `state_core` 的稀少 C/O 来确认转换。

因此，**可复核的观测变化是：闭合起始组中部分轨迹的 geometry/contact 联合符号由闭合一致或冲突，出现开放一致段；开放起始组则在该读数上全为开放方向且没有相反持久段。** 这与“闭合构象可在微秒尺度发生波动/部分打开”相容，但也与“开放起始轨迹只是更稳定地保持开放、闭合起始组包含若干本来就较快落入开放读数的轨迹”相容；它不足以建立闭合起始具有更高的闭合→开放转变概率。

## 依据的比较条件、时间窗口和统计单位

- 比较条件：20 条 `closed_seeded` 对 20 条 `open_seeded`；同一无配体 HSP90α-NTD 模拟设置。论文方法写明 40 条、每条 1 μs，20 条来自闭合 ATP-lid、20 条来自开放 ATP-lid；前 20 ns 为平衡，末 1000 ns 用于分析。
- 当前派生表实际窗口：20–1020 ns，含首尾共 1001 个点/轨迹，1 ns 间隔。
- 主要统计单位：**轨迹**（n=20/组），而不是把帧当作独立重复；帧数只作为描述性补充。
- “方向”：仅按 `geometry_delta_A > 0` 且 `contact_margin_A > 0` 为 `OPEN_CONSENSUS`，两者均 <0 为 `CLOSED_CONSENSUS`，否则 `READOUT_CONFLICT`；零归冲突。这里不是接受字段名的 departure/return 语义，而是按字段判据重建解释。
- “持久候选”：使用已有 time-anatomy 的 5、20、50 保存点阈值；注意其 `persistence_ns` 的历史计数约定与端点跨度不同，且三行/轨迹是同一轨迹的三种阈值摘要，不是 120 条独立轨迹。

## 实际分析

我读取并按轨迹合并 `frame_state_assignments.tsv` 与 `trajectory_time_anatomy.tsv`，重新按 `geometry_delta_A` 和 `contact_margin_A` 的零符号判据计数，而没有按列名解释科学含义。得到：

| 判据（轨迹层面） | closed_seeded | open_seeded |
|---|---:|---:|
| 至少一个 OPEN_CONSENSUS 帧 | 10/20 | 20/20 |
| 至少一个 CLOSED_CONSENSUS 帧 | 18/20 | 0/20 |
| 50点阈值首个持久方向 CLOSED | 11/20 | 0/20 |
| 50点阈值首个持久方向 OPEN | 7/20 | 20/20 |
| 50点 opposite departure candidate | 1/20 | 0/20 |
| 50点 return candidate | 0/20 | 0/20 |
| 出现过严格 C core | 1/20 | 0/20 |
| 出现过严格 O core | 0/20 | 2/20 |

在帧层面，闭合起始共 6764 个 OPEN、8341 个 CLOSED、4915 个 CONFLICT 判定；开放起始为 20020 个 OPEN、0 个 CLOSED、0 个 CONFLICT（每组共 20020 帧）。这些帧不是独立样本，因此不把它们当作 n=20020 的推断统计。

另外，50-ns箱只是每箱 50 个保存点的中位数分类，不能证明一个箱内发生了连续转变；`state_core` 的 C/O/U 也不能替代原论文的结构/动力学定义。由此最稳妥的表述是“方向读数变化/候选段”，而不是“已证实的闭合到开放状态转变”。

## 未解决部分

- 缺少原始坐标数组；当前只能复核交付的派生 RMSD/接触读数，不能重新计算 lid 的原子坐标、原论文式聚类或独立结构相似性。
- `contact_margin_A` 是沉积的 closed-state contact-violation readout 减 open-state readout；字段判据说明还特别区分了历史 pseudo-distance 与原生 NOE 违例。仅凭该联合符号不能证明所有开放方向帧都满足原论文 NMR open-state 定义。
- `first_persistent_direction` 可能与 `seed_lineage` 不同；因此 opposite/return 是相对于“第一持久读数方向”，不是严格的“相对于初始构象”。这正是当前不能把 5/4/1 个候选直接报告成闭合→开放概率的原因。
- 没有在本次分析中用独立阈值、bootstrap/生存分析或两状态隐马尔可夫模型估计转变率；20 条/组也不适合把短暂段当成可靠速率估计。
- 来源卡记录了论文 ff14SB 与其他归档描述之间的文件级不一致；这不改变本题对已交付表的计数，但限制了对模拟可重复性的外推。

## 有信息价值的下一步

1. 对每条轨迹按**初始 seed**而非第一持久方向定义事件：例如要求先有连续闭合支持段，再首次达到预注册的开放判据（至少 5/20/50 点），并报告事件轨迹数、首次时间、删失轨迹；分别用 0.5、1、2 Å 容差做敏感性分析。
2. 用原始坐标重算统一的 lid（98–136）核心对齐 RMSD/接触和论文式 open/closed reference ensemble；随后在轨迹层面做转移矩阵或生存模型，并以轨迹为重复单位。
3. 按 `FIELD_DEFINITIONS.md` 的原生 NOE 规则检查开放方向段（OPEN_NOE≤1 Å、开放方向中比例≥0.8等），把“方向读数变化”与“原生 NOE一致的结构转变”分开报告；该参照仍需明确其并非独立验证。
4. 在有坐标后检查轨迹/起始构象的 lineage、力场和快照映射，解决来源卡列出的归档描述差异，再讨论“更容易”这一动力学命题。
