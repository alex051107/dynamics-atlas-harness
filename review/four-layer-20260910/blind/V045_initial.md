## 结论

**按所给标量距离，两个结构域在各自轨迹中都表现为末段相对首段“距离 CORE 增大”，但运动幅度并不一致。** 因而不能说 LID 与 NMP 的幅度一致；而且开态起始和闭态起始的分配模式明显不同：开态轨迹主要是 LID 距离增加，闭态轨迹则是 LID 与 NMP 都有相近程度的增加。

这里的“方向”严格指所测的平均 Cα–Cα 域间距离的变化方向，不等同于完整三维刚体旋转方向。若把“闭合”定义为域向 CORE 靠近，则本数据的首末均值变化是距离增大、即**不支持一个简单的净闭合方向**；它可能反映热涨落、构象重排或从初始构象向其他构象采样，而不是 ATP 结合后的结构响应。

## 首末 10% 保存帧的实际计算

数据定义规定：每行是一个保存帧，时间间隔 0.2 ns；首/末 10% 取 `floor(n×0.1)` 行，不去除 burn-in；距离单位为 Å，是指定结构域与 CORE 间所有 Cα 对距离的均值。实际读取到的轨迹为开态 2253 帧（0–450.4 ns）和闭态 1678 帧（0–335.4 ns）。因此比较单位是**帧**，不是独立实验重复或独立轨迹；每种起始条件只有一条轨迹。

| 起始轨迹 | 比较窗口（帧） | NMP–CORE 首段均值 → 末段均值 | Δ（末−首）Å | LID–CORE 首段均值 → 末段均值 | Δ（末−首）Å |
|---|---:|---:|---:|---:|---:|
| 开态 | 225 帧 → 225 帧 | 26.2157 → 26.2864 | **+0.0707** | 34.3927 → 36.6831 | **+2.2904** |
| 闭态 | 167 帧 → 167 帧 | 25.2523 → 26.3432 | **+1.0909** | 30.2308 → 31.4073 | **+1.1764** |

所以：

* **开态起始**：两者同为正向（距离增大），但幅度高度不对称；LID 的变化约为 NMP 的 32 倍（仅作描述性比值），NMP 基本保持不变。
* **闭态起始**：两者同为正向，幅度接近；LID 比 NMP 多 0.0855 Å，差异很小（相对于帧间波动不宜过度解读）。
* 首段/末段帧内样本标准差分别为：开态 NMP 0.362/0.342 Å、LID 1.357/2.215 Å；闭态 NMP 0.371/0.359 Å、LID 1.444/0.988 Å。由于连续帧存在时间相关性，这些不是独立重复的误差条，也没有据此进行显著性检验。

## 与 Orädd 等（2021）的关系

论文把 ADK 描述为 CORE 加上 NMP（AMP-binding）和 LID（ATP-binding）两个柔性结构域；晶体结构中底物结合通常与两个结构域相对 CORE 的闭合相关（论文 `paper.md` 第 9–17 行）。论文的 TR-XSS 实验是在 AMP 存在下光释放 ATP，时间范围 20 μs–25 ms；动力学拟合得到约 4.3 ms 的晚期瞬态（第 31–41 行）。其结构精修不是简单比较本题的首末帧，而是把两条 MD 中的结构帧组合，计算差分散射并与实验晚期谱比较（第 44–57 行）。最佳拟合的 10 个结构对显示 LID 和 NMP 都部分闭合，作者据此提出 ATP 触发的协同性/同步性；LID 还伴随局部解折叠（第 65–83 行）。补充材料 S4 明确把相关分析称为 open/closed 晶体结构的 Cα 距离差矩阵，S5 显示 NMP 与 CORE 的二级结构总体较保守（`supplement.md` 第 38–47 行）。

### 本题计算能提供的证据

1. **支持两结构域都具有相对于 CORE 的可观测构象运动**：无论从开态还是闭态出发，首末窗口的两个域间平均距离都发生了变化。
2. **支持运动幅度依赖于起始构象**：开态起始时主要是 LID 标量距离变化，闭态起始时 NMP 与 LID 的变化更接近。这与论文强调的构象集合、而不是单一固定开/闭转换，是相容的。
3. **为“协同性”提供很弱的运动学背景**：闭态轨迹中两个距离均增加且幅度相近，说明两个域可共同重排；但这只是同一条无配体轨迹中两个标量的共同变化，不能等价于论文 TR-XSS 所说的 ATP 诱导协同闭合。

### 仍未解决或不能由本数据推出的内容

* **不能证明 ATP 结合因果性**：来源卡说明这些 MD 坐标中没有 ATP 或 AMP；它们是从开、闭晶体构象出发的无配体轨迹。论文的 ATP 响应来自光释放 ATP 的 TR-XSS，而非本题首末 10% 均值。
* **不能把正的距离变化解释成论文意义上的闭合**：域间平均距离是一个压缩后的标量，不能给出绕 CORE 的旋转轴、方向或局部闭合/解折叠位置；且本题使用的项目域集合为 LID 118–160、NMP 30–67、CORE 1–29/68–115/168–214，和论文正文所述边界并不完全相同。应避免把本计算数值直接与论文报告的 10–25 Å 域旋转幅度比较。
* **不能确定先后顺序或同步性**：首末窗口均值丢失了逐帧时间序列信息，且每个条件只有一条轨迹；没有配体结合事件、重复轨迹或独立样本，不能检验 LID-first、NMP-first、协同还是因果耦合。
* **不能验证局部解折叠/Arg131–Asp146 盐桥机制**：论文报告最佳拟合结构中 LID 局部解折叠和盐桥断裂，并由 NMR 的 Arg131Ala/Ap5A 实验支持（论文第 65–83 行；补充材料 S6–S1）。本表只有域间平均距离，没有二级结构、盐桥距离或散射曲线。
* **诱导契合与构象选择仍不能区分**：论文讨论指出 TR-XSS 的群体时间平均结果既可能表示 ATP 诱导的闭合，也可能是 ATP 将原有开—闭平衡偏向闭态，甚至两者兼有（论文第 91–105 行）。本题无配体、无群体实验，无法解决这一点。

## 分析与检查步骤

我读取了两个 TSV 的完整行数、时间戳和列名；按定义用 `floor(0.1n)` 选取两端帧，分别计算 NMP–CORE 和 LID–CORE 的算术均值及末减首；同时检查了轨迹端点时间、首末窗口帧数和窗口内标准差。结果中所有差值均使用 Å，统计样本是保存帧。没有把帧当作独立生物学重复，也没有将本题的新计算冒充论文已发表数值。

## 信息价值最高的下一步

若要真正检验“ATP 结合是否引起协同闭合”，应在相同域定义下，对**有 ATP/AMP 与无配体的多条独立重复轨迹**进行 CORE 对齐后的旋转/平移分解，分别计算两个域的闭合坐标，并用交叉相关、滞后分析和状态转移统计检验方向、先后与耦合；同时计算 LID 二级结构及 Arg131–Asp146 距离。最有区分力的是把这些指标与 TR-XSS 时间点或实验约束联合拟合，而不是只比较首末 10% 均值。
