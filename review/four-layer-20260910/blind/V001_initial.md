## 结论

**方向上：两条轨迹中 LID 和 NMP 相对 CORE 的平均距离均增加，因而按本数据定义都是向外/更开放的运动；幅度上：不一致。**但这里的“向外”是相对于 CORE 的平均 Cα–Cα 距离增加而言，不等同于直接测得的刚体旋转角或唯一反应坐标。

- **开态起始轨迹**（2253 帧）：
  - NMP–CORE：首 10% 均值 **26.2157 Å**，末 10% **26.2864 Å**，变化 **+0.0707 Å**；
  - LID–CORE：首 10% **34.3927 Å**，末 10% **36.6831 Å**，变化 **+2.2904 Å**。
  因此该轨迹中 LID 的变化远大于 NMP（约 32 倍；这个比值仅作幅度描述，NMP 的变化接近轨迹波动尺度，不应过度解释）。

- **闭态起始轨迹**（1678 帧）：
  - NMP–CORE：首 10% 均值 **25.2523 Å**，末 10% **26.3432 Å**，变化 **+1.0909 Å**；
  - LID–CORE：首 10% **30.2308 Å**，末 10% **31.4073 Å**，变化 **+1.1764 Å**。
  该轨迹中两者方向仍相同，幅度则近似相当（LID/NMP 约 1.08）。

所以，若问题中的“一致”同时要求方向和幅度，答案是：**方向一致，幅度不一致；且这种不一致依赖起始构象：开态轨迹主要表现为 LID–CORE 距离增加，闭态轨迹则 NMP 与 LID 都增加约 1.1 Å。**两条轨迹的末端差异也不能简单解释成真实动力学速率或总体平均响应，因为每种起始条件只有一条轨迹。

## 统计单位与分析方法

数据定义把每一行作为一个保存帧，时间间隔为 **0.2 ns**；距离是指定结构域与 CORE 间**全部 Cα 对距离的平均值**，单位为 **Å**，不是 RMSD、旋转角或散射强度。采用每条轨迹 `floor(帧数×0.1)` 个保存帧：开态首/末各 **225 帧**，闭态首/末各 **167 帧**。变化量统一计算为“末 10% 均值 − 首 10% 均值”。因此统计单位是“保存帧上的 Cα 对距离均值（Å）”；帧不是独立实验重复。

作为波动尺度的参考，首末窗口内的逐帧样本 SD（不是独立重复的实验误差）为：开态 NMP 0.362/0.342 Å、LID 1.357/2.215 Å；闭态 NMP 0.371/0.359 Å、LID 1.444/0.987 Å。它们提示开态 NMP 的 +0.071 Å 很小，不能仅凭首末均值把它当作确定的构象转变。由于轨迹存在时间相关性，未把 225 或 167 帧当作独立样本，也没有据此进行不恰当的显著性检验。

## 与 Orädd 等（2021）的联系：能提供什么证据

这组派生距离数据与论文的总体机制图景**部分相容，但不能单独重现实验结论**：

1. 论文把 LID（ATP 结合域）和 NMP（AMP 结合域）描述为相对 CORE 的柔性结构域；晶体结构比较中，完全开—闭转换对应两域相对于 CORE 的向内旋转，论文报告的尺度约为 **10–25 Å**。本题数据的首末变化只有约 0.07–2.29 Å，而且是平均 Cα 对距离，不是论文的开—闭晶体结构距离差矩阵，因此它们不应直接数值对照。
2. 论文的 TR-XSS 实验是在 AMP 存在时用光释放笼状 ATP，观察到约 **4.3 ms** 的晚期中间态；最佳拟合结构对显示 LID 和 NMP 均为**部分闭合/协同变化**，同时 LID 局部解折叠。开态起始轨迹中 LID 的较大末端变化、以及闭态起始轨迹中两域均有可见变化，说明两域运动可以发生耦合或相关变化；但本数据观察到的是距离增加（开放方向），并非直接证明 ATP 触发的向内闭合。
3. 论文的 MD 结果本身显示：闭态起始模拟可访问类似开放晶体结构的 LID/NMP 构象；开态起始模拟产生了较闭合的 NMP 构象，而 LID 仍较开放。论文据此通过大量结构对与散射曲线拟合，认为实验晚期状态是较弱的、LID 与 NMP 的协同部分闭合。当前首末窗口均值则是单条轨迹的端点汇总，能够作为“两个结构域相对于 CORE 并非完全静止、且二者运动幅度可随起始态改变”的补充证据，不能替代散射曲线拟合。
4. 论文及补充材料还支持 LID 的 Arg131–Asp146 盐桥断裂和局部解折叠可能参与 ATP 响应；NMP/CORE 的二级结构相对保守。当前 TSV 只有两个域—CORE 的平均 Cα 距离，不能检验盐桥、二级结构或局部解折叠。

## 仍未解决的问题

- **ATP 因果性未在这两条轨迹中被检验**：来源卡说明坐标文件不含 ATP 或 AMP；因此这些是无配体起始条件的轨迹，距离变化不能证明由 ATP 结合引起。
- **方向的物理含义有限**：平均跨域距离增加可来自局部柔性、域内变形或不同区域的相对运动，不能唯一确定旋转轴、闭合角或真实“开/闭”状态。
- **协同性和先后顺序未解决**：四个首末变化都是端点均值，无法说明 LID 先动还是 NMP 先动，也没有给出两者逐帧变化的相关系数、滞后关系或自由能面。
- **统计可推广性有限**：每种起始态各一条轨迹，且只有 2253/1678 个时间相关帧；不能把帧数当作生物学重复，也不能据此估计总体效应或显著性。
- **与实验时间尺度不能直接对应**：模拟温度为 303.15 K，TR-XSS 实验为 294 K；模拟保存时间覆盖数百 ns，而实验观察的是 μs–ms，二者不构成直接时间标定。
- **诱导契合还是构象选择仍未判定**：论文明确指出两种机制都可能，TR-XSS 的群体时间序列也可能反映快速开—闭平衡向闭态偏移。

## 检查与有信息价值的下一步

我核对了两文件的帧数、0.2 ns 时间步长、首末 10% 的取样规则和单位；并按来源定义使用连续链内的 Cα 对距离、避免最小映像/最近副本捷径。进一步最有信息量的分析是：

1. 对每条轨迹计算逐帧的 LID–CORE 与 NMP–CORE变化、交叉相关及滞后相关，并用 block bootstrap 或按相关时间降采样，避免把帧当独立样本；
2. 以 CORE 对齐后计算域质心位移、主轴/旋转角和逐残基距离差矩阵，把“距离增加”与真实开合方向区分开；
3. 检查 Arg131–Asp146 距离、二级结构和 LID 局部 RMSD，直接检验论文提出的 cracking/解折叠机制；
4. 在相同条件下加入 ATP、AMP（及双配体）和多条独立重复轨迹，再与无配体轨迹比较；最后用计算散射曲线与实验 late basis spectrum 的拟合检验是否支持论文的协同部分闭合模型。

证据位置：逐帧数值来自 `/source/data/open_domain_distances.tsv` 和 `/source/data/closed_domain_distances.tsv`；字段、单位和首末 10% 定义来自 `/source/FIELD_DEFINITIONS.md`；论文关于结构域、MD、4.3-ms 中间态、部分闭合/协同、LID 解折叠及诱导契合/构象选择的依据分别见 `/source/paper/paper.md` 第 11–13、47–57、65–103 行；补充材料对 S4/S5 及 Arg131–Asp146、实验参数和 Table S1 的说明见 `/source/paper/supplement.md` 第 38–71 行。
