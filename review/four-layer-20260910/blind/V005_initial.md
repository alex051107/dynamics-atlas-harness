## 结论

**按首、末10%保存帧的均值变化，两个轨迹中两个结构域相对 CORE 的平均距离都增大，因此方向是一致的：都表现为相对 CORE 的外移/开放，而不是闭合。**但幅度并不一致，而且差异取决于结构域和起始状态：

|起始轨迹|结构域–CORE|首10%均值 (Å)|末10%均值 (Å)|变化（末−首，Å）|解释|
|---|---:|---:|---:|---:|---|
|open|NMP|26.216|26.286|+0.071|近似不变、很小的外移|
|open|LID|34.393|36.683|+2.290|较明显外移/开放|
|closed|NMP|25.252|26.343|+1.091|明显外移/开放|
|closed|LID|30.231|31.407|+1.176|明显外移/开放|

因此：

* **方向：一致**——四个比较均为正值。
* **幅度：不一致**——open 轨迹主要是 LID 变化（2.290 Å），NMP 几乎不变；closed 轨迹则 NMP（1.091 Å）和 LID（1.176 Å）变化相近。open 的 LID 变化约为 closed 的 1.95 倍，而 closed 的 NMP 变化约为 open 的 15.4 倍。这个比值只是描述性比较，不应被当作精确动力学参数。
* 这不是说两个结构域在每一帧都单调运动；它是各轨迹两端窗口均值的差。尤其 open 轨迹 NMP 的 +0.071 Å 小于其窗口内的波动尺度，不能据此宣称有强的 NMP 定向运动。

## 统计单位与分析方法

数据定义规定每行是一个保存帧；距离是该帧中指定结构域与 CORE 之间全部 Cα 对的平均分子内距离，单位为 Å，而不是独立实验重复。采用每条轨迹帧数的 floor(10%)：open 为 2253 帧、每端 225 帧（首段 frame 0–224，末段 2028–2252）；closed 为 1678 帧、每端 167 帧（首段 0–166，末段 1511–1677）。保存间隔为 0.2 ns，所以这些窗口分别覆盖约 45 ns 和 33.4 ns 的保存数据（端点时间跨度按帧索引计算）。

我先核对了列名、帧数、时间单调性和首末索引，再对每个窗口逐帧取算术均值，最后计算末均值减首均值。这里的“统计单位”是帧内 Cα 对平均距离；帧数可用于描述窗口大小，但不能把 225 或 167 帧当作独立生物学重复。每个起始条件只有一条轨迹，因此没有用这些帧进行独立重复意义上的显著性检验或 p 值推断。

## 与 Orädd 等（2021）及补充材料的关系

论文将 ADK 的 LID 定义为 ATP-binding domain、NMP 定义为 AMP-binding domain，并把两者相对于 CORE 的向内旋转/闭合视为底物结合相关运动；晶体结构中的典型位移约为 10–25 Å（论文正文，结构表述及 Fig. 4 讨论）。论文的两条 MD 轨迹分别从 open 和 closed 晶体结构开始，长度约 450 ns 和 335 ns；论文报告 open-start 模拟可产生较闭合的 NMP 构象，而 LID 仍较开放，closed-start 模拟则可访问开放构象。当前逐帧导出的距离结果与“起始构象会影响两个域的响应、两个域并非刚性同步”的总体图景相容，但本计算采用的是项目定义的非重叠内部残基集合（CORE 1–29、68–115、168–214；NMP 30–67；LID 118–160），与论文正文的边界并不完全相同，因此数值不能直接等同于论文图中的 RMSD 或其结构精修距离矩阵。

对于 ATP 结合响应，能得到的证据分为两层：

1. **逐帧 MD 结果本身的证据较弱且是间接的。** 两种无配体起始轨迹都能发生域间距离变化，且变化幅度依赖起始状态，说明 ADK 存在构象可塑性和域间非完全同步性。这支持“结合响应可能利用预存构象集合”的可行性，但不能证明这些变化由 ATP 引起：来源卡明确说明所用坐标中没有 ATP 或 AMP，且每个起始条件只有一条轨迹。
2. **结合论文的 TR-XSS 证据，方向性解释更有实验支持。** Orädd 等在 AMP 存在、激光释放笼状 ATP 后，在 20 μs–25 ms 时间窗观察到时间演化的散射变化；4.3 ms 的结构精修显示 LID 和 NMP 都是部分闭合、且 LID 伴随局部解折叠。正文称这表明 ATP 触发的初始响应包含两个底物结合域的协同/同步部分闭合；补充 Fig. S4 给出开放/闭合晶体的 Cα 距离差异矩阵，Fig. S5 显示 NMP 和 CORE 的二级结构总体保持，而主文 Fig. 5–6 及补充 Fig. S6–S7 支持 LID 局部解折叠、Arg131–Asp146 盐桥破坏及配体结合后的折叠恢复。因此，本题数据可作为“域运动具有状态依赖性、不是简单刚体单一路径”的 MD 背景证据；ATP 响应的直接因果和协同性证据主要来自论文的配体触发 TR-XSS，而不是这两个无配体轨迹的首末均值差。

## 仍未解决的问题

* 首末10%均值不能给出真实的 ATP 结合顺序、过渡时间、速率常数或因果方向；0.2 ns 保存间隔也不等于实验时间分辨率。
* 不能仅凭两条单轨迹判断 open 与 closed 的总体概率、统计显著性、可重复性，或把 Å 的端点变化映射为完整的 10–25 Å 晶体闭合幅度。
* 距离均值没有区分旋转、平移、局部解折叠和不同残基子群的运动，也不能直接检测 LID 的 Arg131–Asp146 盐桥或二级结构变化。
* 论文的 TR-XSS 样品含 AMP，并由笼状 ATP 光解释放触发；笼状 ATP 的释放与最早结构响应有时间重叠，论文因此主要解析到晚期 4.3-ms 状态。故 ATP 结合后的最初超快事件、协同网络如何传播，以及 induced-fit 与 conformational-selection 的相对贡献仍未完全区分。论文讨论明确指出两种机制可能并存。
* 当前衍生数据不是 ATP/AMP 结合态轨迹，也未提供实验散射曲线的逐点原始数值；因此不能用本比较单独重建或验证论文的 TR-XSS R-factor 结构精修。

## 最有信息价值的下一步

在相同残基定义下增加独立重复轨迹，并分别模拟 apo、ATP、AMP 和 ATP+AMP 条件；对每条轨迹做 CORE 对齐后的 LID/NMP 局部 RMSD、刚体旋转角、域–CORE距离、二级结构和 Arg131–Asp146 距离的联合时间序列。随后用预先定义的闭合指标和变点/滞后分析比较 ATP 是否提高闭合占比、先改变哪个域及其协同性。若目标是连接实验，最好进一步用与 TR-XSS 相同的结构集合和散射计算流程进行配体条件的 ensemble 拟合，而不是只比较端点均值。
