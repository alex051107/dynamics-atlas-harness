# 低价 Agent 已能分析资料，当前运行器还不能稳定交付结果

这轮完成了 Q05 纳米盘和 T4L 两个开发题的三组比较，并用完计划允许的一次共同修订，共十二次独立运行。Luna medium 能自行读论文、选择计算、运行 Python 和看图，无需升级模型。当前还不适合启动二十四份正式比较，因为提交后的信息保留仍有缺陷，部分科学判断也有明确错误。Rules 的独立增益尚未建立。

全部模型费用为 **$0.16578，约 17 美分**，包括工具和图像连接检查。OpenRouter 账户还剩 **$3.95110**。没有充值或调用 Terra。十二次运行自身累计约 12.8 分钟；资料准备、开发和审阅时间另计，本轮没有完整计量这些人工投入。

## Agent 实际完成了什么

Q05 要判断同一个纳米盘构象集合能否兼容 SAXS 与 NOE。SAXS 是反映整体形状的散射强度，NOE 是核磁实验提供的局部原子距离约束。三组都自行选择了核对作者已发布曲线和实验数据，没有收到指定 θ、目标数值或必须执行的拟合流程。

A 组按相同散射变量 q 匹配了 90 个点，用实验误差标准化后，得到平均平方残差 **1.915**。它还核对了 NOE 距离上限，292 项酰胺约束有 47 项超限，40 项甲基约束有 8 项超限。这些数字有实际代码和工具输出，不是复述论文。它们支持给定重加权曲线整体较接近 SAXS，同时仍有局部偏差。检查的是作者提供的结果文件，没有重新优化出一套 ensemble。

B 组也得到约 1.913 的 SAXS 残差，但使用了作者统计表中已舍入的实验强度，A 使用原实验文件，因此两个数字不应要求逐位相同。B 对证据角色说得更明确，指出联合拟合用过的 SAXS 和 NOE 不能再作为该结果的独立验证。A 也已经给出有用的有限答案，本次两个暴露案例不足以证明 B 的额外指导有稳定增益。

T4L 三组都形成了有用初稿，区分了结构区域覆盖、MSM 模型中的状态比例和实验信号。第二批 B/C 实际看了补充材料的图像，保留了一个重要判断。AMS 覆盖开、闭宏观区域，但没有完整重现实验 FRET 分布。FRET 是通过荧光能量转移反映距离的观测，分布中的一部分相符不能直接证明全部构象比例正确。

## 现在最明确的三个问题

第一，运行器把普通确认文字误当成修订答案。T4L B/C 已经提交过有证据的长答案，随后一句确认或短总结覆盖了它。科学结果已经产生，却没有完整保留到交付。这是本轮最清楚的 harness 缺口。

第二，规则没有防住具体的数据处理错误。Q05 C 没有从实验文件逐项读入甲基 NOE 上限，而是手工拼出一个上限数组，报告最大超限约 **4.35 Å**。运行结束后，我按原子对身份核对原始文件，正确值为 **2.75 Å**。本报告的后验核对是开发者审计，不能计作 C 自己纠错。

第三，科学指导仍可能被过度推广。第一批 T4L C 把固定构象池重加权的限制扩展到继续 MD，声称延长模拟也不能产生新构象，这不成立。第二批这句话消失了，但又把比较中的初始种子等条件说成全部固定；实际上两条路径的起始结构和轨迹分配不同，明确匹配的是总生产模拟时间 20 微秒。指导文字没有改过，前后变化不能解释为规则改进的效果。

## 这轮对 Rules 和下一步的结论

C 本版只执行公开来源索引中的拟合重用检查。任意新计算的完整动力学依据还没有可靠记录，因此速率检查在开跑前已列为不执行项。所有 C 提交都没有产生可匹配冲突或直接纠错。这个结果说明本轮没有观察到窄检查的收益，不能写成检查保证正确，也不能据此否定所有科学 harness。

第一批五份被过于保守的输入预算预估提前截停。唯一一次修订改用了服务返回的既有输入计数，并为各组保留共同收尾机会，模型、科学指导和资料都未改变。第二批仍有一份在修订前停止，说明预算与交付机制尚未完全可靠。没有再开第三批，也没有把失败运行删掉。

**本阶段决定是保留 Luna，停在开发交付，不启动正式比较。** 它已经展示了自主分析能力；下一阶段若继续，优先验证已提交答案的保留与修订语义，再由领域人员确认新来源的评分边界。本计划的同题修订额度已经用完，后续工作需要作为新的明确阶段处理，不能把继续修同一题包装成新验证。领域评分人员尚未落实，四个正式来源和二十四份正式答复均未启动。
