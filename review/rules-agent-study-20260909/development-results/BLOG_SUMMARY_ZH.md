# 博文摘要：《Are We Capturing the Ensemble?》（Li, Thomasen, Cossio，RS Station，2026-08-31）

原文约 1800 词，本地衍生件 `research_reset_review_20260908/outputs/are-we-capturing-the-ensemble.md`。以下是我读原文后的摘要，不是引用二手分析。

## 作者在纠正什么

两种相反的直觉犯的是同一个错：看最终表示的样子来猜实验能告诉我们什么。一种把 cryo-EM 图里模糊的区域直接当成"系综存在"的证据；另一种因为 X 射线衍射是多分子平均，就断定它不能约束系综。前者把模糊当异质性，后者把平均当单一结构。

作者说更有用的问题不是"这份数据里有没有系综"，而是：**经过测量和后续处理之后，分子分布之间的哪些差异还能被区分出来。**

## 四个概念，按原文顺序

1. **进入实验的是哪个分布。** 科学上想知道的分布（p_target）和样品里实际存在的分布（p_src）不一定相同；温度、化学环境、制样（比如 cryo-EM 的快速冷冻）和实验时间尺度都会改变它们的关系。博文明确只讨论 p_src 之后的链条：p_src → 测量 → 处理后的数据。

2. **两类测量保留不同的信息，不是谁高谁低。** 系综平均测量（衍射、SAXS、大多数 NMR）报告的是可观测量在分布上的期望值；关键一句是**平均发生在观测量空间，不是构象空间**：p_A·m(x_A) + p_B·m(x_B) 一般不等于 m(p_A·x_A + p_B·x_B)。只要观测量对两个构象响应不同，它们的贡献就仍被分别约束，所以"平均"不等于"只知道平均结构"。单分子/单颗粒测量（smFRET、cryo-EM 单颗粒）报告的是从边缘分布里抽出的个体样本，保留了分子间差异，但噪声、未知的干扰变量、有限采样和构象差异的大小都可能让不同状态无法区分；**分子分辨不等于分布可见**。

3. **处理会再丢一次信息。** 筛选颗粒、估计姿态、分类、共识重建都可能把群体信息去掉；处理不改变物理上的 p_src，但改变了我们用来分析的表示里还剩什么。信息在两处流失：分布变成测量时，测量变成处理后数据时。

4. **Ensemble resolution（系综分辨率）。** 类比空间分辨率：两个源分布经过测量和处理后何时变得不可区分。它不是一个数，因为分布可以在不同方面不同：主要构象相同但比例不同、一个有稀有态另一个没有、各自涨落相似但相关运动不同；一个数据集可能分得清其中一种差异却对另一种几乎失明。cryo-EM 可以空间分辨率提高而系综分辨率下降；模糊密度不能自动解读成系综，即使真来自异质性，它也不指定一个分布。在候选构象固定的重加权设定下，这个问题开始能形式化（给定测量和不确定性，哪些比例差异被支持）；构象和概率都未知时仍是开放问题。

## 结论句（原文 takeaway）

在为某种系综推断方法辩护之前，先问数据是怎么产生的、经过了什么变换、源分布里的哪些差异还可观测。平均测量仍能约束多个状态；分子分辨实验不让系综直接可见；高分辨重建保留的群体信息可能比它所基于的观测更少。**问题从"这个实验包不包含系综"变成"这份数据集实际能区分分布的哪些方面"。**

## 它对"Rules Table 该是什么形式"的直接含义（我的推论，不是原文）

- 规则的基本单元应该是一条**关系**："对这种目标差异，这种测量加这种处理，在这些条件下保留 / 不保留区分能力"，而不是"这种来源可靠 / 不可靠"。
- 这条关系有四个槽位：目标差异（比例、稀有态、相关运动）、来源分布的条件、测量的前向模型与平均方式、处理记录。这四个槽位正好对应设计里的框题层（要区分什么）、准入层（对象与条件、处理记录）、分析层（前向模型与平均律）、结论层（这份数据能说到哪）。
- 博文没有规定实现形式。它要求的是**先验证目标差异是否还留在可用信息里，再选推断方法**；表、图、脚本都可以承载，能不能承载不由名字决定。
- 本项目自己撞上的例子：HSP90 的"两个差值读数的符号"是一种处理，它丢掉了绝对吻合度，所以"出现开放方向"分不出"接近开态"；用作者的两套 NOE 违例绝对值才分得出。这就是原文说的"处理把可区分的差异洗掉了"。
