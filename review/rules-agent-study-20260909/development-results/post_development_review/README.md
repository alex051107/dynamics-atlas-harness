# 已提交答案的离线保存修复

本目录保存开发实验结束后的普通程序维护。当前修复没有新的真实模型会话，也不构成第二次开发修订或正式试验结果。

- `submission_maintenance.patch` 显示已执行版本到维护候选的变化。普通消息不再隐式提交。所有组明确提交非空正文和至少一条含text的主张；其他科学字段可为空。这是新的共同提交协议，不追溯判定旧答案。
- `offline_submission_check.json` 保存真实处理代码在测试替身网络下对五类检查和T4L B/C保存响应的结果。
- `test_submission_maintenance_offline.py` 是上述离线检查脚本，模型和容器调用均被替换。不会改写历史运行。
- `before` 在本地保留已执行代码及原始报告。GitHub原版本仍由固定提交adba30a2eeececfd3612e7d89d603c69872175db保留。

一次新增离线提交检查通过后，原有多工具与图像回传检查的合成输入按共同提交协议补入主张记录，再运行一次该检查，结果通过。它验证原有图像消息次序、修订轮次、重复提交和回执行为。未重跑科学计算、原12次会话或完整历史测试。

检查范围只描述结构化主张与公开拟合关系是否对应。未匹配的主张没有获得科学确认；没有适用的结构化主张也不等于普通正文中没有错误。有效的较短新提交仍可替换旧稿，程序不选择科学内容最好的版本。

原有付费开发入口已关闭。新的正式实验仍需新的冻结配置和明确的研究决定。
