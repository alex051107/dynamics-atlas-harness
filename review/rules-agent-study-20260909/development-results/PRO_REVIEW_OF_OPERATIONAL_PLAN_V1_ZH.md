## 一、先说清楚：这份计划已经换了研究安排，不是上一版的细化

上一版主要是在问：

> 同一个有自主分析能力的 Agent，增加科学指导或确定性检查以后，回答是否变好？

这一版明确把四来源、24 份比较停放，改为：

> 接入旧规则选择器，依次完成三个蛋白体系的科学表征；A/B 差异作为附带观察，每个体系结束后交 Pro 审阅。

**这个调整可以成立。没有必要为了维护我之前的建议，强行恢复 24 份实验。** 如果你目前最需要的是让 Soojung 看见原型如何帮助理解真实蛋白资料，先完成一个清楚的科学案例，比继续准备一套大比较更直接。

但计划必须接受调整后的结论范围：**三体系开发可以展示实际用途、暴露失败、检查换资料时需要改多少东西；它不会自动回答 Rules 是否具有独立增益。** 同一个蛋白的三个问题、每题重复两次，也不是六份独立科学来源。

另一个变化需要明确：本轮不再使用之前的七条科学指导，而是重新接入 33 条候选注册表及旧选择器。研究处理已经改变。它可以是合理的复用选择，但不能把"来自旧注册表"当作比七条指导更科学、或更值得保留的证明。

这版应当先写明：

> **本阶段优先交付真实资料上的科学分析，并观察现有规则选择是否提供实际帮助。规则系统是待评估的实现，不是预先确定必须完成的成果。**

否则，原来围绕 Q15 修复的循环，可能只是换成围绕三个蛋白建设系统。

## 二、最需要修改的，是三处可能让系统"证明自己正确"的设计

### 1. 规则输出不能决定科学评分的范围

A6 要求根据每条 obligation 生成"正确答案必须区分／过强结论／合理弃权"的评分模板；离线完成标准之一是"rubric 段数等于 obligations 数"。B2 又将这份模板与历史结果中的允许、禁止措辞组合成评分依据。

**作为辅助检查清单，这可以使用；作为科学评价的主要来源，不合理。**

原因很直接：如果选择器漏掉一个重要问题，评分也可能随之漏掉；如果选择器选错了检查对象，评分可能反而奖励按错误义务作答。这样测到的是 Agent 是否遵守了选择器，而不是选择器是否帮助 Agent 回答科学问题。

最小修改不是另建评价框架，而是把两件事分开：

**科学评价依据**来自公开问题、实际数据和相应方法：哪些结果能够回答，哪些解释没有足够依据，哪些替代分析也有效。A/B 使用同一份。

**规则覆盖记录**再检查：选择器提出了哪些义务、遗漏了什么、增加了哪些无用工作。它可以与科学评价对照，但不能反过来定义全部评分范围。

可以保留模板脚本，也可以暂时不用。**必须取消"义务条数齐全＝评分齐全"这种完成标准。**

### 2. 格式合法的元数据，不会因此成为科学事实

B4 计划运行两次元数据起草，取第一份通过 schema 的结果，再经 A6 生成 `PUBLIC_FACTS.json`，供 C 组作确定性检查。

这里缺少一个关键区别：

> JSON 符合格式，只说明字段可以被程序读取；并没有证明里面关于样品、拟合角色、时间信息的判断是真的。

尤其 A6 拟从"来源时间语义为 UNORDERED，且没有动力学模型"生成 `exclusive_analysis_basis`。**"某个来源是无序结构集合"不等于"某项速率结论只使用了这个来源"。** 后者必须绑定具体分析、实际使用的证据及模型假设。

建议将模型生成的信息继续标为**待核对的提取结果**。用于硬性拦截的事实，仅限能够从具名原文、数据清单或实际执行记录核实的关系。无法核实就记录检查未覆盖，不自动判科学结论错误。

这不会阻止开发阶段继续工作，也不要求专家审批每一个字段。它只是防止：

> 模型误读一次 → 程序重复使用这个误读 → 因为程序是确定性的，就把结果叫作可靠。

### 3. `MATCH` 能证明数值对应，不能替代科学方法判断

A8、B7 和禁止清单要求：每个数字都必须由冻结脚本复算为 `MATCH`，才能进入报告正文；未能复算的数字只能进入错误节。审查提示进一步问，这能否替代"不要现场生成分析流程"的要求。

**不能替代。**

一段脚本可能准确重现错误的计算定义。例如，重复计算出"相邻帧作为独立样本"的标准误，并不会让这个统计处理合理。另一方面，Agent 采用了一种合理、但冻结核对脚本尚不支持的方法，也不等于它算错了。

至少要分别记录：

| 要核对的事情 | 它回答什么 |
| --- | --- |
| 数字是否来自所引文件或实际计算 | 有没有抄错、编造或绑定错对象 |
| 按声明方法能否重新得到该数字 | 计算是否可复现 |
| 方法是否适用于当前对象和问题 | 数字能否承担相应科学解释 |

此外，论文报告的数字应允许以"作者报告"身份引用，不必为了引用一项已发表的估计就重新拟合原始实验。对新计算，保留可执行代码、输入和参数，再作针对性核对即可。**核对器尚未支持，应记为尚未独立核验，而不是自动列为 Agent 错误。**

## 三、HSP90 三个问题值得研究，但当前输入并不足以同样支持三题

### 先修正 B0：两项"来源矛盾"不能继续原样沿用

计划从旧获取报告引入了：

* AMBER99SB 与目录 `amber14sb_OL15.ff` 的力场矛盾；
* 1021 与 1001 帧的矛盾。

我查阅的 Henot 原论文 Methods 明确写的是 **Amber ff14SB**；同时写明运行 **1020 ns**，前 **20 ns** 作为初始平衡，文章分析最后 **1000 ns**，按 **1 ns** 间隔保存用于分析的快照。([Nature][1])

这意味着：

**力场方面，首先需要核对的是旧获取报告为何写了 AMBER99SB，而不是继续把它当作原论文与目录之间尚未解决的矛盾。**

**帧数方面，1021 与 1001 可能对应包含和去除前 20 ns 的两个窗口。** 还需要核对本地时间列、端点及裁剪记录，才能确认本机文件具体是哪一种；但不能再把两个帧数不同直接视为冲突。

这是本轮最明确的一项事实修正。它不需要重跑 MD，只需要把原文方法与已有文件时间信息对应起来。

### 第一道：有限时间的变化可以回答，但不能把旧分类当作刚发现的状态

`HSP90_Q01_transitions` 是合理的科学问题。现有逐轨迹记录也可能足以支持有限范围的回答。

问题在于，计划提供的主要输入已经包含：`first_persistent_direction`、`opposite_direction_departure_candidate`、`return_candidate` 等分析结果。也就是说，旧流程已经替 Agent 完成了一部分轨迹分类。

**复用这些结果没有错。** 但本轮能力应描述为"检查并综合已有轨迹分析"，不能描述为"Agent 从原始轨迹独立识别了转换"。

同时，"更接近开放参照""满足一个持续性阈值"和"完成从闭合到开放的状态转换"不是同一句话。应让 Agent 检查这些定义与原文定义之间的联系，而不是因为字段名里有 departure 或 return，就直接接受其科学解释。

首份结果最应该讲清楚的是：**哪种可复核的观测变化发生了，依据何种判据，仍与哪些解释相容。**

### 第二道：窗口稳定性与平衡占比，需要分开回答

计划将 CPMG 占比"只作对照、不作答案"，方向正确，但仍需补一句：**CPMG 对应的交换状态与 MD 几何类别之间的关系，本身不是自动成立的。**

原论文也明确保留了这项限制：没有直接实验证据确认 CPMG 检测到的激发态就是所建立的闭合结构，作者将这种对应作为解释全部结果的最简单模型。([Nature][1])

因此，这题可以同时得到两种结果："某个描述量在所检查的前缀窗口中变化较小"；以及"这些有限时间、指定起点的轨迹仍不足以直接估计目标条件下的平衡比例"。不能因为后者未成立，就丢掉前者。也不能用"前缀曲线变平"代替平衡与采样充分性判断。

### 第三道：覆盖与 PCA 敏感性，目前最可能缺输入

计划要求回答：NMR 定义的构象空间覆盖了哪些 MD 区域，以及用 NMR 建立的 PCA 基底是否压缩了 MD 的分布外变化。

但 B1 列出的输入主要是到参照的最小／中位距离、时间分箱、方向分类及历史总结；没有明确列出完成该题所需的共同坐标或特征矩阵、原子对应、对齐方式与 PCA 变换。

**仅有最小距离和中位距离，一般无法恢复被降维丢掉的方向。** 这不是 Agent 多思考几轮可以补回的信息。

这里应二选一：保留现有输入，将问题缩成这些输入真正能回答的几何接近性分析；或者确认本机已有必要坐标与变换，允许有限的后处理。**新做一次已有轨迹的后处理，不等于跑新 MD。**

若这些输入确实没有，本题就不应成为首轮必须完成的第三题。也不要先写出"必须报告方法敏感性"的评分要求，再让 Agent 为缺少输入承担失败。

另外，NMR 结构模型集合的离散程度，也不能直接当作溶液中真实分布的全部宽度。原论文中的模型来自约束计算和筛选，其结构表示与 MD 时间采样承担的角色不同。([Nature][1])

## 四、B3 的旧记录比较存在实际对象不一致，不宜直接开算

这是我通过读取仓库文件确认的问题，不只是对计划的担忧。

B3 指定的 `profiler_reference_v1.json` 中，HSP90 参考对应：`hsp90_directional_time_anatomy_development_v1_alpha`。它只有一个 MD 来源，目标是固定双读出方向片段的描述，没有 NMR 比较边。对应公开输入也明确说没有实验比较对象。

但计划指定的 MiniMax 提案对应：`HSP90_NTD_EXPOSED_PAPER_BLIND_V1`。其中包含 NMR 和 MD 两个来源及一条比较边，结构也不是前一个参考文件的格式。

**它们都研究 HSP90，不代表它们是同一个任务、同一份可见证据的答案。**

把这些记录直接送进同一选择器，再计算义务 Jaccard 或错目标率，可能把任务差异、输入差异、格式转换差异都算成模型错误。若参考不能进入选择器，也不能按 B3 现有停止条件，默认先修 MD 方法范围；问题可能根本不在那里。

我的建议是：**B3 暂时不列为首轮前置任务。** 需要做时，只比较同一公开输入下、同一目标和同一表示的模型结果与参考；无法对齐的历史记录保留为历史，不强行汇总成模型能力表。

其中的"出现 population／kinetics 等字样就记为 claim 安全问题"也应删除。"不能由当前数据估计 population"同样包含这个词，却是正确限制。关键词最多帮助定位待审语句，不能判定过度结论。

## 五、当前 A/B 比较还存在一个直接的输入泄漏风险

A6 将 `ACTIVE_RULES.md` 写入：`cases/<case>/public/`。A7 只规定 A 组"不在提示末尾附规则"，而整个 `public/` 又是 Agent 可读的 `/source`。

**不附在提示里，不等于 A 无法读取。** 按计划当前目录安排，A 可以通过列目录或搜索发现规则文件。这样 A/B 可能只是在比较规则是否被主动贴进提示，而不是是否提供规则。

最小修法是让共同公开资料与组别附加材料分开。A 的可读范围不包含规则、C 的检查政策或隐藏评分；B/C 再分别增加声明的材料。现有挂载方式就能做到，无需新隔离框架。

与此同时，哪些预处理结果由三组共享，需要写清：

* 共享一份模型起草的元数据，可以减少组间输入差异，但比较的是**给定这份元数据后的分析增量**。
* 各组独立提取元数据，则结果差异同时包含提取误差，不能只归给后续规则。
* 无论哪一种，Agent 都应能回到原始公共资料指出元数据错误，而不是被一份格式合法的档案永久限制。

对于规则本身，建议在本轮作为可质疑的分析提醒，而不是唯一允许的科学路线。否则 Agent 看似能自由写 Python，实际上只能完成预先选定的检查，仍会回到你之前担心的"执行开发者安排"。

## 六、Pro 可以帮助审阅，不应成为科学真值和阶段授权的替代者

**不必等待专家齐备才能做开发分析。** 你可以先完成计算、记录假设、整理给 Soojung 看。计划保留"开发暴露、未经领域确认"的限制，这部分是合理的。

但下面三件事必须分开：

**Pro 的审阅意见**可以指出错误、提出核查和帮助解释。
**科学结论的依据**仍是原文、数据、方法与实际结果；模型同意不会增加一份独立实验支持。
**是否继续投入**由负责人根据结果、资源和风险决定，不能因为 Codex 已经填写了意见处置文件就自动进入下一体系。

当前 E 阶段的进入条件主要是"Pro 意见处置完成＋第二体系符合准入条件"；这甚至不能保证 Pro 的主要反对意见已被解决，因为处置可以是 `REJECT`。

最小修改是取消"处置文件齐全即继续"的含义。报告应直接呈现：科学问题回答了多少、哪些结果可靠、系统是否仍依赖人工代做关键步骤、下一体系是否会提供新的信息。由你据此作一次投入决定，不需要再逐条请求 Pro 批准小修改。

文献比对也一样。`AGREE/DISAGREE` 是与作者结论的关系，不是正确／错误判定。按关键词对齐可以减少整理工作，却不能判断两个主张是否真正谈论同一个对象、条件和量。应保留未能判断的情况，并允许**正确地不同意作者的过强表述**。

## 七、第二体系的选择标准应围绕科学问题，而不是注册表是否方便

目前准入条件是：能下载、至少两种模态、有比较论文、所需方法已经注册或最多新增一个定义。它有现实的资源意识，但科学条件还不够。

同一个蛋白有两种模态，并不说明它们能回答同一个问题。至少还要确认：

> 两类资料针对什么构建体和条件？存在什么具体可比较的性质？现有资料与方法足以给出哪一项有用答案？

这些内容可以写进现有盘点表，不需要新 schema。"方法最多新增一个定义"可以作为本轮工程成本上限，**不能作为资料科学价值或 Agent 能力的判据**。若一个好问题因为没有注册入口而退出，应报告实现范围限制，不能说该问题科学上不可分析。

目前我不建议直接确定 ADK 或 DHFR。ADK 已有本地端点结构，确实方便先核查；但只有几个静态结构，并不自动构成动力学或跨观测分析。没有读取两者这次拟使用的具体资料之前，不能以便利性代替科学选择。

也不需要默认第三个体系必做。第二体系最有价值的用途，是检查：**换了一套资料后，是否还能复用同一分析方式，而不为该题重写核心逻辑。** 若做到第三体系只是因为标题里写了三个，就不是研究理由。

## 八、预算中最需要控制的是开发与审阅投入，不是那 1.50 美元

不能简单说 1.50 美元一定不够。仓库已保存十二次 Luna 开发运行和费用记录，开发报告给出的模型及接口费用合计约 **0.16578 美元**。这至少说明低费用运行曾经实现过，但并不保证新阶段沿用相同耗用。

真正的问题是：**计划默认投入 23 个工作日，建设多个新脚本并完成三轮审阅，却没有对应的人工和计算时间核算。**

其中 `audit_answers.py` 与 `compare_to_literature.py` 被要求通用化处理开放科学答复，远不只是几个文件拼接。若严格限制到既有几类数值，则应明确其范围；若支持任意有效分析，三天完成整个系统的估计缺乏依据。

费用控制也应在请求发送前检查和预留，而不是只在整次运行结束后发现超过 0.35 美元。C 的可选运行必须计入次数与资源；"有公共事实"不等于有适用检查机会。

我赞成改为环境变量提供凭证，停止从历史会话记录中寻找 key。这是该计划中应保留的安全修正。这里核对到的是历史代码快照和拟议修改，未确认你本机现行代码已完成改变。

相反，固定"18 次检查、3 次哈希"、新写每周扫描任务标签的 `drift_check.py`，并不能保证研究不跑偏。所有任务都可以带上 `HSP90/S3` 标签，同时仍在处理错误的问题。**更有效的限制是：到期必须交付科学回答和失败原因，不能因为某个新框架尚未完善就自动续期。**

## 九、我推荐的最小修改方案

不要求重写整份计划，也不要求恢复旧的四来源实验。保留现有 Agent 运行能力和成熟分析工具，先做下面这个范围。

### 首轮只承诺一份 HSP90 结果，而不是整套三体系平台

先将原论文方法、当前可用数据和旧结果对应起来，纠正上述力场与时间窗口记录。

选择现有资料真正能够回答的一个主问题；有限时间变化最接近这个条件。PCA 覆盖问题只有在必要输入已存在时才纳入，否则作为明确未完成部分。

让同一个已有 Agent 在共同资料和工具下形成答案，规则版本作为一项额外处理。**可以保留每组两次，共四份首次答复**，用于观察这一个开发问题上的差异，不声称准确率或泛化。C 暂不自动开启；本轮没有必要为了使用已有代码而增加第三处理。

只补当前运行必需的凭证、挂载和接口问题。不先建设通用评分生成、通用文献语义比对或新的任务治理系统。

结果出来以后，报告分成两层：

**Agent 原始交付**原样保留，用于判断实际表现。
**经核对的科学报告**允许修正和补充，但每项人工介入要说明。

不能把修好的会议稿反记为 Agent 自己完成的答案。

### 用四种结果决定下一步

| 首轮结果 | 下一步 |
| --- | --- |
| 普通 Agent 已给出有用答案，规则没有明确帮助 | 保留普通流程继续科学工作；不因需要维护 Rules 而追加开发 |
| 规则帮助发现一个实质遗漏，且未损失可回答内容 | 保留这一具体用途，再到第二体系检查能否复用；不扩大成整个 Engine 有效 |
| 关键错误来自元数据、输入缺失或工具未返回结果 | 按实际失败归因；不把它们算成科学规则效果，也不修到答案必然正确 |
| 必须不断新增题目专用代码或核对器才能交付 | 停止本轮系统扩展，先交付已有科学结果和真实限制 |

这里不需要新的统计门槛或更多审批文件。首轮本来就是开发判断，重要的是**允许规则无增益、允许系统失败，也允许不依靠规则继续取得科学结果。**

### 对新增工作的取舍

**KEEP NOW：** 现有自主工具循环、来源与方法说明、原始答复保存、必要的数值核对、正确的挂载隔离、环境变量凭证，以及一个窄规则适配。

**DEFER：** 旧多模型 V2a 汇总、第三体系、通用主张—文献比对、自动评分模板扩展，以及为了新方法先补一整套注册范围。

**DELETE / AVOID：** 用规则选出的义务定义全部科学评分；把 schema 合法升级为事实真实；把未支持的核对方法列为科学错误；把 Pro 意见处置完成当作自动推进条件。

## 最终建议

**这份计划的有价值变化，是愿意回到具体蛋白和实际科学结果；它的问题，是仍把"建成 Rules 回路"设成必须完成的前提。**

建议修改后进入**有界的 HSP90 首轮工作**，而不是一次性承诺六周、三个体系全部自动推进。你不需要等到证明 Rules 在所有地方都无效，才可以选用简单流程；同样，也不需要先建成完整系统，才有资格观察规则在哪一处有帮助。

计划开头最适合替换成：

> 本阶段先利用现有 Agent 和已保存的 HSP90 资料，完成一项有明确方法与来源的科学分析，并观察加入现有规则提示后，答案是否得到实质改善。科学评价独立于规则选择结果。完成后根据科学结果、人工介入和复用成本决定是否进入第二体系；第三体系不作为自动承诺。Pro 提供咨询审阅，不能替代领域结论或负责人的投入决定。

**要避免的不是"多做几个蛋白"，而是再花六周把同一个尚未证明有用的组织方式做得更完整。先让一个科学问题被真正回答，再让结果决定保留哪部分系统。**
