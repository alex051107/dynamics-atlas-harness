我们的原始目标和最新想法如下。

我在做 Dynamics Atlas 相关研究。过去尝试把论文中的方法和判断整理为固定 Rules Table，再交给 agent 使用。上周四与 Soojung 讨论后，我们更想先研究科学家如何推进实际工作：看到现象后问什么问题，先核对哪些信息，怎样选择分析，结果不清楚时怎样补证据，以及什么时候该停止。长期希望这能帮助可靠地整理和分析蛋白动力学数据。

当前具体目标有两个。第一，先从复刻他们的 workflow 开始，用现有论文和公开数据实际做 Analysis，看能否得到与论文相近复杂度、且有证据支持的结论。第二，在下周四（2026-09-24）的会议上展示整理出的 workflow 和判断逻辑，请他们校正。我们需要研究工作过程，而不只是列出科学方法、摘录结论或重新命名规则表。

一个重要的待检验想法是：足够强、reasoning effort 较高的模型，也许本来就能完成相当多的工作。因此没有预先认定固定工作流、控制程序、记忆或多 Agent 一定有益。我们希望知道在哪些真实问题上需要什么支持，新增工程是否值得。

Soojung 分享的起始论文涉及 ADK、IL-2、K-Ras 和两篇 RfaH；链接及准确的取得状态在 SOURCE_STATUS.md。也允许补充其他论文，尤其需要考虑这些起始材料是否足以代表 MD 科学家的工作。模拟质量指南只是参考材料，不自动作为一项复杂科学结论的复现案例。
