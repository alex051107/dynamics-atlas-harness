# K-Ras 2023：作者从数据到结论的决策片段

来源：Hansen et al. 2023 NSMB 正文（`literature/workflow_papers_20260920/md/KRAS2023.md`，页码为期刊页）与补充材料 MOESM1（SI）。"明确"= 论文写出的步骤；"重建"= 我根据证据依赖推出、论文没写先后的步骤。"工作区"指 v2 盲测工作区；"R3"指 9-26 的 A/B/C 三组运行。

每个片段按这个顺序写：已有观察 → 没解决的问题 → 竞争解释 → 作者的检查 → 结果分别意味着什么 → 对结论的影响。

## 片段 1：Switch 区原本看不见（明确，p.1447，Methods）
- 观察：以往 NMR 和晶体结构里 Switch I/II 信号缺失；GTP 在测量中水解。
- 问题：没有这些残基的信号，就谈不上它们的动力学。
- 竞争解释：交换展宽；样品在测量期间变质。
- 作者的检查：用天然 GTP、样品不超过 3 天就换、交错采集抑制 t1 噪声、非均匀采样做归属，>98% 残基归属。
- 影响：之后所有分析的前提。
- Agent 对应：湿实验，Agent 无法重做；工作区已是归属好的数据。**不作为 Agent 动作**，在条目里记为样品条件。

## 片段 2：有几个状态、几个过程（明确，p.1450–1451，Table 1）
- 观察：P-loop、Switch I、Switch II 有 CPMG 弥散，部分残基 CEST 有第二个凹陷。
- 问题：用一个共享过程描述是否够；是否存在不止一个激发态。
- 竞争解释：单一两态过程；多个独立过程；三态。这组显式候选模型是为 Agent 重建的可执行选择，不能写成作者实际逐一拟合过三者。
- 作者的检查：CPMG+CEST 全局两态拟合；每个残基的 CEST 只见一个次级凹陷，"没有迹象表明任何残基显著布居不止一个激发态"（p.1451）。
- 影响：在采样条件和检测范围内，数据可由两态模型描述；Table 1 是条件于该模型的参数。论文未报告显式三态与两独立过程的统计选模，不能据此声称唯一识别了两态拓扑。
- 工作区：有 CPMG、CEST。
- R3：三组都只能拟合两态（**工具只提供两态模型**），比较了全局与逐残基、分区拟合；状态数实际上是框架给定的。→ **框架缺口**：要提供三态与"多组独立过程"模型，让状态数成为 Agent 的判断。

## 片段 3：激发态像什么（明确，p.1450–1451，Table 2，Fig. 3）
- 观察：CPMG 只给 |Δϖ|，CEST 给带符号 Δϖ。
- 问题：只凭骨架 ¹⁵N/¹H 位移很难确定结构（p.1448 原话大意）。
- 竞争解释：与实测 GDP 构象集合相似；局部位移接近序列预测的无规卷曲；其他构象。GDP 样与局部柔性不是互斥类别，GDP 态本身可以包含柔性区。
- 作者的检查：带符号 Δϖ 分别对 Ω(GDP)−Ω(GTP) 与 Ω(无规卷曲)−Ω(GTP) 逐区相关，GDP 位移为同缓冲液自测，无规卷曲由 POTENCI 按序列预测。
- 结果与含义：整体与 GDP 位移相似（效应叶 R² 0.88）。Switch I 对 GDP 的 R² 更高（0.951 对 0.875），但无规卷曲的 RMSD 更小（2.10 对 3.05 ppm）；两个指标不能合并成无条件的同一个“赢家”。Switch II 对 GDP 的 R² 更高（0.686 对 0.473）、RMSD 更小（1.56 对 3.39 ppm），支持 GDP 样的位移特征。作者另用 SSP/NASR 解释局部柔性，不能把位移比较单独升级成“有序但不同于 GDP”。
- 工作区：有 CEST；GDP 位移只有 BMRB 公开条目（条件不同）；**没有无规卷曲预测**。
- R3：三组只比较了 GDP。→ **证据缺口**（同条件 GDP 位移、无规卷曲预测）+ **流程缺口**（第五段只要求"比较相关参照态"，没要求至少两类）。

## 片段 4：偏离 GDP 的残基怎么解释（明确，p.1452–1453，SI 图 S2）
- 观察：G13、T35、E37、T58 偏离 GDP 对角线最远。
- 问题：是结构不同，还是 γ-磷酸带来的化学环境差异？
- 竞争解释：激发态在这些位置结构与 GDP 不同；位移差来自 GTP 与 GDP 的化学差别。
- 作者的检查：用 4OBE、5VQ2、5VQ6 三个晶体结构算骨架 N 到 γ-磷酸的距离，偏离最大的残基都靠近 γ-磷酸。
- 影响：距离结果支持局部化学差异这一解释，但不是排除构象差异的因果证明。原文用三结构对齐后到同一 γ-磷酸位置的平均距离；单个结构到最近配体原子的距离不能声称精确复算了该检查。
- 工作区：没有结构工具。
- R3：A、C 定性提到"核苷酸仍是 GTP"，没有做距离检查。→ **工具缺口**：需要"从 PDB 结构算残基到配体原子距离"的工具。

## 片段 5：激发态会不会是水解产物或 GDP 污染（明确，SI 图 S4，p.1452、p.1454）
- 问题：看到的次要态是否只是样品里积累的 K-Ras·GDP？
- 竞争解释：真实的 GTP 态构象交换；GDP 污染或水解伪影。
- 作者的检查：(a) GDP 结合样品的 CEST 在 Switch 区没有次级态（SI 图 S4，B1 42–45 Hz，150 ms；GDP 样品也测了 CPMG，未公开）；(b) k21 = 40.6 s⁻¹ 远快于无 GAP 时的 kcat < 4×10⁻⁵ s⁻¹（引文）；(c) 样品 3 天内更换。
- 影响：在所测残基、B1、饱和时间和误差范围内，没有观察到相同的 GDP 态毫秒交换特征。结合动力学时标和样品信息削弱水解解释；GDP 单样品对照本身不能排除 GTP 样品的所有污染、处理误差或混合物伪影。
- 工作区：**没有 GDP 对照数据**（Source Data 有十个残基的 GDP CEST 曲线）；没有 kcat 文献值。
- R3：B 只用推理（"与 GDP 交换不会给出 300 s⁻¹"），没有数据检查。→ **证据缺口**（补 GDP CEST 对照）+ **流程缺口**（第四段加"找一个过程应当不存在的对照样品"）。kcat 属文献值，Agent 可作为待查项，不作为已执行分析。

## 片段 6：快时间尺度的佐证（明确，p.1448–1449、p.1452，Fig. 4，SI 图 S5）
- 观察：常规 model-free S2 看不出 Switch 区的柔性。
- 作者的检查：用纳米颗粒辅助弛豫（NASR）得到的 S2，对比 GTP 与 GDP 态；二级结构倾向（SSP，需 Cα/Cβ 位移）。
- 影响：佐证 Switch 区柔性，但属于另一时间尺度，不是同一测量。
- 工作区：有 NASR 表（含作者派生的序参量，不能记为 Agent 从原始弛豫重新估计的量）；没有 Cα/Cβ 位移。NASR 扩展至约 10 ns–1 μs，不能只概括为 ps–ns，也不是次要态专属测量。
- R3：基本没用 NASR 表（A 明确写"未分析"）。→ **流程缺口**：第五段把"其他时间尺度的佐证"列为可选动作，并要求标明时间尺度不同。

## 片段 7：主、次态对应 state 2 / state 1（明确，p.1449–1450）
- 作者的检查：用早年 ³¹P NMR 测得的平衡常数（文献），把布居大的基态对应 state 2、激发态对应 state 1；再用"激发态像 GDP"支持这一对应。
- 工作区：没有 ³¹P 文献值。
- R3：三组都用模型先验知识说出 "state 1"。→ **结论边界**：这一对应需要外部文献，报告中应标为"文献对应，非本数据得出"。

## 片段 8：变体差异与功能（明确，p.1452–1453，措辞为 "may" / "help rationalize"）
- 作者的检查：WT 的 p1 和 k21 都高于两个突变体，与文献中 GTP 酶速率排序平行。
- 工作区：无功能数据。
- R3：三组都没有越界宣称功能关联。→ 维持：功能关联只能作为假设和建议实验。

## 缺口汇总与 v2 对应修改

| 缺口类型 | 片段 | v2 修改 |
|---|---|---|
| 框架：状态数被给定 | 2 | 拟合工具增加三态（线性、星形）与"多组独立过程"模型；题面不再预设"次要态" |
| 证据：同条件 GDP 位移、无规卷曲预测 | 3 | 工作区加入同条件 GDP 态 ¹⁵N 位移；参照库工具提供 POTENCI 序列预测 |
| 流程：第五段只比一个参照 | 3 | 构象解释前至少比较两类参照态（不点名），报告最大 |Δϖ| 残基覆盖 |
| 工具：结构距离 | 4 | 新工具：从 PDB 结构算残基到配体原子距离 |
| 证据 + 流程：对照样品 | 5 | 工作区加入 GDP 结合样品 CEST（十个残基）；第四段要求检查"过程应当不存在"的对照 |
| 流程：其他时间尺度佐证 | 6 | 第五段列为可选动作，标注时间尺度 |
| 结论边界 | 7 | 报告区分"本数据得出"与"文献对应" |
| 最终产品 | — | 结束时同时输出 Atlas 状态条目（证据等级只提议，由人决定） |

## 2026-09-26 独立核查后的执行状态

v3 工作区已经提供每种样品 10 条 GDP CEST 曲线、同条件 GDP 15N 位移和构建体序列；POTENCI 已能独立执行。WT 的 Y32/Y64 在实测位移表中缺失，现有固定中心筛选只分析到 8 条，必须单独报告这两个缺失，不能当成阴性。无规卷曲预测与作者使用同一方法，属于独立生成参照，不属于独立方法验证。

三态与分组过程接口已实际用于 V3 实验；两态极限和速率矩阵稳态检查通过，但不等于完成了状态数的辨识验证。六条真实数据运行中四条没有拟合 WT T35，说明“最大 |Δω| 覆盖”必须检查拟合集合之外的可用曲线，不能只列已经选入的残基。新一轮均生成候选 Atlas 条目；条目格式和来源链接合格不等于领域判级或数据库导入。

对应实测检查、源码修复与报告审查见 `resumption_20260926/independent_audit/REVIEW_ZH.md`。原始 R3 与 V3 报告全部保留。
