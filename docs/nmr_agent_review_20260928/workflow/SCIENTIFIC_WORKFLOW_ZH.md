# 通用科学流程正本 v2：从观测到可辩护结论

2026-09-26。依据 K-Ras 2023、AdK 2015、IL-2 2020、RfaH 2012/2025 的 37 条交接片段修订。本版完成的是**逐条处置和五篇论文桌面推演**，尚未证明真实模型会执行这些动作，也未证明相对强模型加工具有增量。逐条处置、原文复核范围与推演在 [五篇推演](FIVE_PAPER_TABLETOP_ZH.md)；实际接口缺口见 [工具清单](TOOL_REQUIREMENTS_ZH.md)。

科学判断以一条决策链为单位：**已有观察 → 未解决的问题 → 竞争解释 → 能区分它们的检查 → 各种结果的含义 → 实际结果与结论更新**。阶段可以回访；固定的是证据责任，不是工具顺序、目标状态数或结论标签。

## 六段合同

| 段 | 输入与触发 | 需要执行的科学动作 | 出口与回访 |
|---|---|---|---|
| F 问题与对象 `frame` | 任务、样品、实验；多个物种、构建体或状态称呼 | F1 登记物种、序列/构建体、变体、配体、编号、条件、观测对象；分开题目给定、需要估计和外部知识。F2 说明什么观测能回答什么问题；速率、结构、功能分别定范围 | 对象清楚后继续。无法建立同一性时分列；不能把孤立结构域结果直接写成全长蛋白结果 |
| I 输入与能力 `inventory` | 实测输入、派生量、参照、对照、工具 | I1 从所有可用输入建立覆盖基数，记录归属缺失、信号缺失、排除、工具跳过及各自原因；查采样与检测窗口。I2 核对跨样品映射、条件和关键配体归属。I3 寻找可区分伪影/机制的已有对照、可交叉核对的独立读数；明确工具实际支持的探针、检测态与模型 | 形成问题—数据—方法对应。不把未归属当交换展宽，不把平坦曲线、低于检测限和程序错误合并为阴性。缺关键输入时继续可答部分，列出具体补测 |
| B 基础分析 `baseline` | 有适用的实测数据和可执行估计方法 | B1 先用现成领域实现；检查原曲线、单位、误差、初值/符号、参数边界、优化状态、残差及覆盖。B2 若另一类实验或独立场强可检验该模型，**先冻结已估计的物理参数，预测未参与估计的数据**，保存预测、残差和假设；之后才允许联合拟合。B3 同一量有独立直接测量时进行一致性核对 | 明确能解释哪些数据。预测失败先核对条件、编号、误差、校准与前向模型；排除这些原因后转 D 检查缺失过程。没有可比的第二读数时写明未作外部预测，不伪造独立验证 |
| D 区分解释 `discriminate` | 未解释的数据、竞争模型、符号歧义、对照或扰动 | D1 执行前写竞争解释、读数及不同结果的含义。D2 在相同观测集合和误差约定下比较适用模型；只为有根据的未解释现象增加复杂度，记录拓扑、参数数目、优化、残差、预测表现和可辨识性。D3 对照/扰动同时检查基态折叠、结合占有率与检测窗口；优先选择独立扰动。D4 检查符号、初值、误差和残基选择敏感性，包括未进入拟合的高信号输入 | 停在足以解释现有数据的最简单可辩护描述。约化 χ²≈1 只是误差模型成立时的诊断，不能单独选状态数；同样拟合良好的拓扑并列，只保留跨模型稳定的量。工具不能比较时限制结论，不把工具上限认作自然界状态数 |
| T 结构与功能 `interpret` | 可信观测/模型条件估计、参照、区域与独立证据 | T1 有结构主张时原则上比较至少两类合理参照；同区域各参照用同一残基交集，同时报告相关性和绝对偏差。全局和局部均检查，分区依据在看参照优劣前说明。T2 查拟合外大变化、指标分歧、符号未知；几何距离和局部化学解释不能自动排除构象差异。T3 区分实测结构、同源/位移驱动模型和集合平均；主态证据不自动约束次态。T4 功能命名需独立动力学/结合/扰动证据，核对时间尺度及混杂 | 每条主张注明样品、区域、模型、证据和限制。参照不足时不强造第二类；收窄主张。柔性、参照相似、唯一坐标与路径身份不是同一结论。新分歧返回 I/B/D |
| S 综合与提交 `synthesize` | 已执行分析、未决项、主张、工件 | S1 交报告及当前工具合同的 Atlas 候选；每个数值/区域主张可追到完整观察或拟合，列出参数、位移、比较、覆盖/排除等实际产物。S2 区分观测、模型条件估计、外部知识对应、假设和建议；列出反证、无法支持的内容和最能解除歧义的下一测量 | 可辩护的未决结果也是完成。程序中断和科学数据不足分别报告；未完成运行不得装作科学阴性。等级仅为提议，Gina 审核后决定，不自动入库 |

## 方法经验层：触发后才使用

段合同定义需要回答的问题，方法经验帮助选择动作。经验必须带适用前提和失败边界，不能成为目标答案配方。

- 缺失有多种来源：归属策略、重叠、交换、样品质量、检测窗口。只有校准了可见性，未检出才能约束某个参数范围；不能无条件推出不存在。
- 拟合值与测量值分开；一条拟合所得曲线再与自己比较不算交叉验证。同一位移派生的两个指标也不是两份独立证据。
- 多态可辨识性取决于噪声、时间尺度、场强、覆盖和检测态；不预设必须拟合三态或恢复作者拓扑。边界解、多初值不一致和系统残差优先处理。
- 多条件扰动先核对样品完整性、占有率与可观测性。交换淬灭不能换算为布居为零；结合变化可能同时来自直接接触和构象平衡。
- 参照检索可以由先验提出，但要标为外部知识驱动。只从放行的库取数并核对条件；检索成功不证明状态身份。目标论文、作者拟合代码、答案和暗示性文件名由准备者封存。
- 设计者先查论文、GitHub 和现成实现；盲解题者只访问放行的方法/参照。正式结果优先由适用并验证过的领域软件生成或核对；软件名称不代替脉冲序列、模型和优化验证。

给模型的简短版本见 [METHOD_EXPERIENCE.md](METHOD_EXPERIENCE.md)。不把五篇论文的蛋白名、正确数值、目标拓扑、特定残基或作者分区放进通用提示。

## C 组增加的反思

B 组已经需要做科学比较和报告限制。C 组只增加显式的结果对预期复核、撤回与计划更新，不额外获得数据、数值工具或答案。触发包括跨实验预测失败、优化异常、符号冲突、覆盖变化、参照结论分歧及拟合优度与残差不一致。

一次有效反思应指向归档观察：预期是什么、实际是什么、区别在哪里、有哪些解释、下一检查如何区分，以及保留/撤回了什么。只写“再检查一下”不计纠错；同一错误重复提到不重复计数。允许结果不改变原计划，但须给理由。见 [REFLECTION_CHECKPOINTS.md](REFLECTION_CHECKPOINTS.md)。

研究状态和完整工具输出分开保留。反思是模型笔记，不是新增测量；输出裁剪时回读观察，不凭摘要补造事实。

## 两条开放问题的裁定

**没有比较多态是否必然失败：不是。** 若比较适用且影响主张，却未执行，记过程缺失；无数据/无工具支持时记能力缺口并检查是否限制主张；简单模型经诊断足够时不强制加态。结论错误单独判。作者直接假定两态不妨碍其模型条件参数有用。

**能否用先验寻找锁态突变体：可以提出，但只在冻结的检索政策内执行。** 跨组同权限，记录来源与条件，标为先验驱动；目标答案依然封存。五篇均参与了流程设计，RfaH 是第二开发案例，不是未见论文的留出验证。

## 如何检验本版的价值

科学恢复与可辩护性分别评分。机制增量看相同模型、数据、工具、预算和运行时下 A/B/C 的关键动作、实际纠错、引错和成本；每组 3 条只支持开发诊断。换运行时的一条 C 可证明接入及该条科学表现，不能把与旧运行器 A/B 的差异全归因于流程或反思。见 [RfaH 运行与评测边界](RFAH_FIRST_RUN_ZH.md)。
