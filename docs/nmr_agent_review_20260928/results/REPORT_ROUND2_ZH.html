1 结论

这一轮按"先拆作者卡点 → 固定流程 → 补框架 → 预先登记 → 运行"做完了一轮。对照上一轮的四处偏离：

  • 作者卡点已翻译成动作：八个决策片段（KRAS_DECISION_FRAGMENTS_ZH.md），每个标明作者做了什么、工作区有没有数据、Agent 该做什么。
  • 状态数由 Agent 判断：工具提供两态、分组独立过程、三态（星形/线性）。9 条真实数据运行（C1、C2、C2.1）全部实际拟合了三态模型，全部选两态，理由是 BIC 反对，且没有任何 CEST 曲线出现第二个次级凹陷。这是作者的论证，这次由 Agent 自己在数据上得出。
  • 证据补齐到接近作者：GDP 结合样品的 CEST 对照、同缓冲液的 GDP 态位移、POTENCI 无规卷曲预测（与作者表格 r = 0.9999）、PDB 配体距离。每条运行都分析了 GDP 对照，并据此排除"次要态是 GDP 污染"。
  • 输出连回数据库：每条运行都给出 Atlas 状态条目，写明模型选择、参数、逐区参照比较、对照、不能支持的内容；外部知识单独标出，证据等级只作提议。

结构结论：登记的主判据是逐区比较两类参照，并得出"Switch I 更接近无规卷曲、Switch II 更接近 GDP"。v2 提示为 1/3，未通过；只改一处比较工具的 v2.1 为 2/3，通过。v2.1 的第 3 条没按判据走，但走出了一条更强的路：自己在 BMRB 找到 K-Ras G12C/T35S·GppNHp 的 state 1 参照（条目 52072，另一课题组），核查偏移后逐区比较，Switch II 与 Switch I 36–40 同它的 RMSD 为 0.2–1.0 ppm，同 GDP 为 1.8–3.9 ppm。论文只能借外部 ³¹P 文献把激发态对应到 state 1，这条运行在数据层面支持了这一对应。

结论边界：K-Ras 是开发案例，论文参与了流程设计，结果不是留出验证。每组 3 条运行只能作为开发诊断，不能证明机制有统计增益。评分由主会话完成，另有一份独立核查（见第 6 节）；都不是领域专家判断。Atlas 条目是候选，没有入库。

5 负对照

合成数据里 WT 的次要态位移严格等于同条件 GDP 态。N2 三条都没有把 WT 判为无序：都算出与 GDP 一致到 0.05 ppm；并且都指出这对仍结合 GTP 的构象在物理上不合理（离 γ-磷酸 3 Å 的残基也完全一致），于是标为"可能是伪影，待核实"。它们识破了合成数据本身的不现实之处。N2.1 结果见第 7 节。

独立核查指出了这份负对照的缺陷：WT 的 HSQC/HMQC 符号文件仍是真实数据，与合成态不一致。下一版要么移除，要么由合成模型生成。

6 独立核查（另一会话完成）及采纳

另一会话对本轮代码和前九条运行做了独立核查（resumption_20260926/independent_audit/REVIEW_ZH.md），修复直接写进了共享源码。我全部复核后采纳：

  • 安全：参照工具可读取工作区外文件（用无害探测文件实测读回）、BMRB 屏蔽可用非规范编号绕过。均已修复。已有运行中没有被利用的记录，但这不等于当时入口安全。
  • 覆盖：第二轮 6 条真实运行中 4 条没把 WT T35 放进任何拟合。"报告最大 |Δϖ| 残基"只检查已选残基，关键曲线可能根本没被选入。C2.1 三条都纳入了 T35。
  • 判据与表述：判据 c 修正（见第 4 节）；"GDP 样"与"局部柔性"不互斥；γ-磷酸距离只支持化学环境解释，不构成因果证明；GDP 对照无凹陷只适用于所测残基和噪声范围。
