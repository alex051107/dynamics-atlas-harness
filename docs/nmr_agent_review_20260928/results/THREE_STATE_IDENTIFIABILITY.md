# 三态可辨识性检查（Agent 拟合工具，K-Ras WT 实验设置）

2026-09-26，Longleaf 作业 2508574（16 核，约 26 分钟）。脚本 `sim_identifiability.py`；逐次拟合 `identifiability_results.json`（225 次，0 次报错）；汇总 `identifiability_summary.csv`。

合成数据：WT 的真实实验布局（¹⁵N CPMG 850/600 MHz、¹⁵N CEST 28 Hz/150 ms）、正控 27 个残基、真实逐点误差与实测 R1。真值：两态（kex 400 s⁻¹、pB 0.10、Δϖ 取正控值）；三态星形（在两态基础上加第三态 C，p2 = 1/2/4/8%，kex2 870 s⁻¹，ΔϖC ~ N(0, 1.5 ppm)）。每个真值 3 份噪声，每份用两态、三态星形、三态线性各从 5 组随机初值拟合，取 χ² 最小者比较 BIC。

## 结果

| 真值 | BIC 选择（3 份噪声） | 两态拟合的 kex（偏差） | 说明 |
|---|---|---|---|
| 两态 | 两态 3/3 | 391–396 | 三态拟合编出 p2 4–24% 的虚假第三态，χ² 只降 35–46，被 BIC 否决 |
| 三态 p2 = 1% | 三态星形 3/3 | 492–504（+25%） | 星形恢复 p2 0.8–1.3%、kex1 380–402 |
| 三态 p2 = 2% | 三态 3/3（星形 1、线性 2） | 595–613（+50%） | 星形恢复 p2 1.6–2.1% |
| 三态 p2 = 4% | 线性 3/3 | 748–773 | 星形拟合各初值间 χ² 相差 1200–1400，kex1 偏到 486–559 |
| 三态 p2 = 8% | 线性 3/3 | 888–920 | 同上，初值间 χ² 相差约 3500 |

## 结论

1. 在这组实验和噪声下，第三态布居 ≥ 1%（交换速率约 900 s⁻¹、Δϖ 约 1.5 ppm 量级）能被 BIC 识别；真两态时没有假阳性。低于 1% 的第三态没有测试，检测下限写作"约 1%，条件于上述速率与位移"。
2. 拓扑（星形 vs 线性）用这套工具分不出：真值为星形时，布居 ≥ 2% 多数选到线性。原因是星形拟合在 5 组初值下常收敛不到全局最优，而不是数据偏好线性。三态参数（尤其 kex1）在 p2 ≥ 4% 时有明显偏差。
3. 存在未建模的第二过程时，两态拟合的 kex 会被系统性抬高（p2 = 1% 时 +25%）。
