1 结论

观察在提供两态拟合引擎、已归属的 CPMG/CEST 强度、基态位移与 R1 等辅助数据的条件下，解题 Agent 自选残基、符号初始化与分析顺序。运行时未向它提供目标论文及拟合答案；首轮评分所选的最终拟合恢复了 Table 1 的交换参数：kex 与论文偏差在 ±10% 以内，次要态布居大多在 ±5% 以内，带符号的 Δϖ 与作者最终值几乎全部同号（最终联合拟合共 20+22+21、24+31+27、39+40+36 个残基里只有 2 个不同号）。三组都找到了 P-loop、Switch I、Switch II 以及远端 α3 的交换，都得到 kex 排序 WT > G12C > G12D、布居 G12C 最低，都完成了次要态与 GDP 态的位移比较；结构解释及限制见下文。

观察结构解释仍不完整：三组都没有做无规卷曲参照比较；C 组还写了"次要态不是无序的"，这句超出了它检验过的证据。论文中 Switch I 的 GDP 相关性更高、无规卷曲 RMSD 更低，Switch II 的两项指标都更支持 GDP 参照；GDP 样与局部柔性不是互斥标签。观察事后用 C 组自己的 Δϖ 配作者的无规卷曲值计算：Switch I 对无规卷曲 RMSD 1.86 ppm、对 GDP 3.5 ppm；Switch II 对 GDP R² 0.86、对无规卷曲 0.66。这表明旧拟合输出包含可进一步解释的信息，但事后计算不是 Agent 的成果，也不能证明唯一瓶颈是参照工具。2026-09-26 的独立复算与修订见 纠偏核查。

观察三种设计都能完成数值部分。加入流程和方法经验（B）带来了"同残基集合比较变体"和"参照数据先做偏移检查"两个动作；再加反思（C）修正了两处真实错误（逐残基拟合落入符号初值造成的局部极小；残基选择带来的偏差大于 bootstrap 误差），代价是调用数从 29 增到 54。每组只跑了一次，还不能区分机制效应和运行间波动。

观察两项行为检查的表现符合预期：删掉 CEST 和 HSQC/HMQC 后，Agent 写明所有符号未知，把结构结论收窄为"至多部分像 GDP、不是 GDP 构象"；把全部残基号加 200 并给出映射后，参数和符号与原编号时一致。

2026-09-26 更正：本轮有三点在初版里没讲清。(1) 拟合工具只提供两态模型，题面也问"次要态的布居"，状态数实际上是给定的；"单一全局两态过程可以描述数据"只是给定模型下的比较，不是 Agent 自主判断的状态数。(2) 数值能恢复，主要靠我写好的确定性拟合工具；Agent 负责的是残基选择、分析顺序和比较。(3) 作者处理卡点的几个动作（同时比较 GDP 与无规卷曲参照、GDP 结合样品无交换的对照、离群残基与 γ-磷酸距离的核对）没有翻译成 Agent 可执行的动作，相应数据和工具也没提供，所以结构结论只恢复一半有相当部分是输入设计的问题。v2 已增加相应输入和工具，科学效果仍须按修订后的证据标准核查，见 KRAS_DECISION_FRAGMENTS_ZH.md、WORKFLOW_V2_ZH.md、PREREG_V2_TEST_ZH.md。
结论边界：K-Ras 论文参与了方法经验的编写，这是开发复现，不是留出验证；Opus 5.5 可能在预训练中见过这篇 2023 年论文，隔离只能保证运行时没有提供答案。结构结论只到"位移层面的相似"，不是三维结构。所有评分是我按封存参照做的确定性核对和阅读判断，没有领域专家复核。

2 背景与起点

项目的交付物是 Dynamics Atlas 数据库：从已发表实验数据（主要是 NMR）里识别出有功能意义的构象状态。9 月 17 日的会议把方法从收集规则（Rules Tables）转向收集科学家的分析动作，因为把规则塞进提示反而降低了表现。合作方在 Slack 给的五篇论文（AdK、IL-2、K-Ras、两篇 RfaH）是学习"作者怎样从数据推到结论、卡住时做了什么"的起点。

本轮开始前实际存在的东西：9-22 评审包里的读文记录、阶段卡草稿、数据可用性探针和一次 16 份条目的提示级试验（让模型读论文写条目，比较给不给阶段卡）；Compass 运行时代码（有状态循环框架，但策略是脚本替身，没有接真实模型）。没有任何"真实数据 → 模型选动作 → 工具执行 → 结果进下一轮 → 结论"的闭环，试验比的是读论文，不是分析数据。

首个案例选 K-Ras（Hansen 2023）：五篇里只有它把原始弛豫色散和 CEST 数据连同实验参数一起公开（Dryad/Zenodo，CC0），可以从原始强度重新拟合；论文 Table 1、Table 2 给了可核对的数值目标。RfaH 2025 也有原始数据和 MATLAB 脚本，列为下一个案例。

实现方向只比较了两个：复用 Compass（2.4k 行，子目标/产物图等抽象按 HSP90 设计，接真实模型和 NMR 工具需要大量改造）与写一个最小的原生工具调用循环。选了后者，借用 Compass 的思路（工具回执、错误作为观察返回）而不借代码。LangGraph 已安装但没用：当前只有一个线性分段流程加段内循环，显式图还没有带来收益。

3 数据、泄露与隔离

观察数据取自 Zenodo 10.5281/zenodo.8187159（Dryad j6q573nm0 的镜像；Dryad 接口现在需要令牌），三个文件的 md5 与记录一致。作者 Source Data 从 Europe PMC 取得，只放在封存目录用于评分。

观察公开数据里藏着答案，必须剥离：

  • WT 参数目录的 global.toml 写着 KEX_AB 403.1、PB 0.1006（作者 CPMG 全局拟合值）；shift_dw.toml 有逐残基 Δϖ 和误差；突变体目录也有同类文件。
  • 每个实验配置的残基列表后面带着作者的分类注释（"SlowEx : dR2 ~ 23.07"）。
  • BMRB 52021/52023/52024 的引文标题就是论文标题（"Excited-state observation…differential structural dynamics…"）。

盲测工作区只保留实测输入：原始强度曲线、实验参数、基态化学位移、实测 R1、HSQC−HMQC 峰位差、纳米颗粒弛豫表。剥离清单在 blind_workspace_v1_LEAK_AUDIT.json。BMRB 工具去掉所有标题和引文，并拦截上述三个条目。

观察隔离实测：解题会话由无头 Claude Code 启动，关闭全部内置工具、设置来源、技能和其他 MCP 连接器，只能调用 14 个分析工具；探针确认上下文里没有 CLAUDE.md、记忆或项目内容。沙箱里的 Python 读取原始参数文件和论文都被拒绝，网络不可用，工作区只读。

5 Agent 怎么工作

结构是"分段科学流程 + 段内由模型选工具的行动循环 + 触发式反思 + 小型研究状态"。

  • 流程：六段——问题与样品、数据盘点、基础分析、歧义与卡点、构象解释、核查收尾；每段的输入、判断、动作、输出和回访条件写在 outputs/WORKFLOW_V1_ZH.md，给模型的英文原文在 prompts.py。
  • 动作：筛选弥散、看原始曲线、两态全局/逐残基拟合、CEST 多起点定符号、残基重抽样 bootstrap、BMRB 检索（去引文）、沙箱 Python、记录研究状态、提出新实验（与已执行分析分开）、提交报告。每次分析调用必须填"为解决什么、预期结果各意味着什么"，执行器只执行模型选的那个动作。
  • 反思（C 组）：工具报错、拟合出现标志（参数贴边界、相对误差 > 30%、约化 χ² > 2）或连续 4 次分析未反思时，下一步必须调用 reflect，写出预期、观察、差异、可疑环节和决定；允许维持计划。
  • 记忆：研究状态（样品事实、假设及支持/反对证据、未决问题、计划、撤回的陈述、建议实验）由运行框架保存，模型只能通过工具改写；所有调用连同目的、预期和结果写入 actions.jsonl，拟合结果按编号落盘，报告引用编号。
  • 借用的外部机制：工具异常作为观察返回（aviary env.py:284-343）、旧观察用占位符隐藏（ldp simple_agent.py:36-89）、可执行代码环境（finch notebook_env.py），代码定位见 9-22 评审包的研究笔记。"失败信号触发文字反思"取自 Reflexion 的思路，本次没有核对其代码，属于设计推断。

和论文一致的部分

  • 存在毫秒级交换，区域是 P-loop、Switch I、Switch II，外加 α3 等远端残基（论文也提到 92–98 区的次要效应）。
  • 单一全局两态过程可以描述数据：三组都用 BIC 比较逐残基与全局模型，BIC 支持全局；都分区拟合检查了 Switch I 与 Switch II 是否同一过程。
  • T35、E37 的大 Δϖ（−11.5 / +10.3 ppm）由 CEST 确定（A、C）。
  • G12C 布居最低；突变体在 G13 和 Switch II 的 Δϖ 与 WT 不同。
  • 次要态在 Switch I 与 GDP 态方向一致、只走了部分距离（约 60–80%）；Switch II 有反号残基，不是 GDP 构象。

与论文不同或没达到的部分

  • G12D 与 WT 的布居：论文 10.15 vs 9.00%，三组都判为"相近"（C 在匹配残基集合下 10.4 vs 10.2%）。C 组量化出残基选择带来约 10% 的系统偏差，这个差别落在该范围内。推断这是合理的不确定性，不是分析错误；论文的差别也只有约 2σ。
  • Switch I 是否接近无序：没有 Agent 做无规卷曲比较（见第 1 节）。这是本轮唯一改变科学结论的缺口。
  • "state 1"：三组都把次要态称为 Ras 的 state 1，题面没有提这个词。推断来自模型对 Ras 的先验知识；论文也把激发态对应到 state 1，但依据是另一项 ³¹P 研究，不是这批数据。

10 Fable 评审（第一轮结果节点）

只带一个问题：v2 先改哪一处、怎样检验才可能失败。候选是加无规卷曲参照、改反思触发条件、强制大 |Δϖ| 残基定符号。

  • 采纳：先做参照态修订，把"大 |Δϖ| 残基覆盖"并入其报告要求；反思触发条件暂不改（单次运行分不清周期触发多余还是恰好没碰上问题）。
  • 采纳并已实现：负对照——合成一份"次要态就是 GDP 态"的数据（用 BMRB 27720 的 GDP 位移），若 v2 把它判为"无序"即失败，防止强制比较后一律偏向无序。生成器已写好并自检：恢复 kex 368（设定 380）、p 0.1005（0.10），约化 χ² 1.03。
  • 采纳：防泄漏措辞；无规卷曲值用独立来源，不用作者表格。
  • 预设检验：C（v1）对 C2（v2），同数据、同模型、70 次上限，各 3 次。命中 = Switch I 与 II 各报告两类参照的 R²/RMSD，且 Switch I 判为更近无规卷曲、Switch II 判为有序但不同于 GDP。通过：v2 ≥ 2/3 命中且负对照 0/3 判为无序；kex 仍在 ±10%、符号一致率不降、调用数增幅 ≤ 15。失败：v2 ≤ 1/3。
  • 没做到：执行 prompt 要求在"确定首个子任务前"也开一次讨论，这次没有开。
