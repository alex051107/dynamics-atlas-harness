结论

在 K-Ras 这个开发案例上，隔离的 Agent 从作者存档的原始 CPMG/CEST 数据出发，在 9 条独立运行里恢复了论文 Table 1 的交换参数。中位数与论文的对比：WT 392 vs 400 s⁻¹、10.2 vs 10.15%；G12D 309 vs 301 s⁻¹、9.1 vs 9.0%；G12C 343 vs 326 s⁻¹、7.1 vs 6.97%。带符号的 Δϖ 与作者最终值 715/720 同号。每条运行都自行比较了两态、分组和三态模型并选定两态，也都分析了 GDP 对照样品。结构层面，给了逐区比较工具之后，多数运行得到"Switch I 核心更接近无规卷曲、Switch II 与远端更接近 GDP"，与论文 Table 2 的读法一致。

还没做好的有三处：一是 Agent 选残基有偏差，D33 从未被拟合；二是本地引擎相对标准软件 ChemEx 系统偏低约 4%；三是拓扑和 ≲1% 的第二过程超出了本工具的辨识能力。条目已交 Gina 定级，全部标为候选。

边界：K-Ras 论文参与了流程设计，模型也可能在预训练中见过它，所以这是开发复现，不是留出验证。评分由主会话完成，另有 Codex 的独立核查，都不是领域专家判断。
