# 计划 v4：把五篇论文的流程用到可审核的数据库条目上

2026-09-28。依据：ChatGPT Pro 对本目录的审查意见（下称"审查"）、`IDEA_AND_FIT_ZH.md` 引述的会议原话。取代 `NEXT_STEPS_ZH.md` 与 `BACK_ON_TRACK_ZH.md`。Claude 设计与核对，Codex 执行，用户与 Gina 决定。

## 1 目标没有变，变的是检验单位

2026-09-25 的任务有四个部分：从五篇论文总结科学家的分析流程；把流程编进 Agent；不给答案，检验 Agent 能否恢复论文结论；结果汇入 Dynamics Atlas。前两部分有了第一版（37 条决策片段、六段流程、三层提示）。第三部分在 K-Ras 上做过一次，但检验的单位是"交换速率算得准不准"。

合作者要的单位是数据库条目。Soojung 在 9-17 会上说主交付物是数据集本身，做法是从 BMRB 和文献里找出没人标注的替代态并标上；Gina 的判据是"没有配体、慢到出现两套峰"。所以"恢复论文结论"要换成恢复论文的**状态断言**：在哪个构建体、什么条件下，观察到什么，支持哪些残基上的什么解释，有没有结构对应，功能相关性另有什么证据。这五层是不同强度的断言，条目里分开写，不从"有两套峰"一步跳到"功能相关的替代态"。

流程的六段不用改，直接对应条目构建：问题与样品对应"这是哪个构建体、什么条件、是否 APO"；数据与覆盖对应"这个病例的证据在哪、有哪几类"；基础分析和区分解释对应"两套信号是不是同一样品的两个态，还是不同条件、链或样品"；构象解释对应"结构对应"；核查提交对应"写条目、写不能支持什么"。K-Ras 那套拟合工具保留，遇到有原始色散数据的病例时作为基础分析段的深分析分支。

主线名称：**替代构象证据条目构建**。BMRB 是入口，文献、补充材料、原始数据存档用于补充和核验。

## 2 接受审查的哪些意见

全部接受，其中三条改变了执行顺序。

**先修 BMRB 读取器。** 已核实：`tools.py` 的 `bmrb_entry()` 用"原子 + 残基类型 + 编号"作键存位移，同一残基的第二套指认会覆盖第一套；样品条件按类型合并，多个温度或 pH 只剩最后一个。这恰好会抹掉要检测的"两套指认"。修之前跑出的任何低召回都不能解释成"BMRB 没沉积"。

**两层参照。** 参照 A：专家看完整资料后认为支持什么断言。参照 B：专家只看给 Agent 的同一证据包，认为最多能支持什么。Agent 在证据包缺关键证据时弃权，按 B 算对，不按"与论文一致"算错。专家先看 B 包，再看完整资料。

**八病例诊断设计**代替"一半正例一半负例"：

| 病例类型 | 数量 | 检验什么 |
|---|---|---|
| 存档中有足以支持断言的证据 | 2 | 能否找到证据、写出可接受的条目 |
| 论文报告替代态，但证据包缺关键证据 | 2 | 能否指出缺口，而不是背出论文答案 |
| 在所测条件下未检出目标信号的可靠阴性 | 2 | 能否给出有条件范围的阴性，不宣称永远单态 |
| 多套列表来自不同条件、样品或链 | 2 | 能否拆开对象，拒绝看似合理的假阳性 |

找不到可靠阴性就如实标证据不足，"论文没提替代态"不自动当负例。另设一个确定性基线：同一输入，程序只列出多列表、重复指认、条件差异、缺失区段，不下结论。Agent 相对它的增量才是流程和模型的贡献。

另外四条照改：缺指认只作候选线索，不写"即交换展宽"；"R2 异常"改为"弛豫异常及其竞争解释检查"；"两套可见峰"写明是首批入库的操作定义，不代表所有慢交换态（CEST 能看到常规谱看不到的低布居态），请 Gina 确认；Dyna-1（Nature 2026，用约一万个 BMRB 条目的缺指认预测动力学）是要正面比较的前例，我们的差别放在逐病例证据核验、条件对齐、竞争解释和可审核条目上。

**K-Ras 的措辞按审查第五节七处全部改**，包括：流程"对数值无贡献"改为待检验的观察；"检测下限约 1%"改为"所测 1%–8% 均被识别，未建立检出边界"；拓扑问题归到当前优化器；引擎偏差只限本次匹配比较，并修正 pB 方向不一致；负对照注明是修正前版本；"自主提出对照"改为"使用并分析了给定对照"；"全球约十个蛋白"改为"本次检索找到约十个新增候选"。补一份脱敏的最终答案账本：每条运行、每个变体的最终拟合编号、残基集合、参数、符号分子分母、选择依据；现有评分文件缺 C2.1 三条运行。

## 4 跑完能说什么

能说：六段流程在 N 个病例上被用来构建条目，专家接受了其中哪些断言，失败发生在哪一环；Agent 相对确定性基线多做了什么；盲化证据包下 Agent 的结论是否依赖证据。

不能说：全库准确率；流程的独立增益（没有同条件对照）；Agent 没见过这些论文（只能说"未参与本项目开发"）；双峰证据的沉积比例。
