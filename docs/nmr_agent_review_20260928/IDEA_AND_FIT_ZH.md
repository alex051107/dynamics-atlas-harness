**一句话：** 一个不知道论文结论的 agent，按谱学家的分析流程，仅凭已沉积的 NMR 数据能否判断一个蛋白是否存在功能相关的替代（APO）态，并产出领域专家愿意收入数据库的条目。

**与合作者的关系：** 这就是 Soojung 描述的建库动作本身（T0917 L144–152, L161–168），判据用 Gina 的定义（两峰/慢交换），检验用他们提议的 5–10 例人机对照（T0917 L249–255）。执行 prompt 也是这样定目标的："从 NMR 数据库及相关公开数据中，自动完成原本需要科学家进行的构象分析，并把有依据的结果汇入 Dynamics Atlas"（PROMPT L7），"数据库是最终产品"（PROMPT L9）。

## 3. 现在的形式最 fit 吗

**判断：不是最合适的形式；它是正确 idea 的一个过窄的子测试。** 现在的形式（隔离 agent + 19 工具，从原始弛豫色散曲线重拟已发表蛋白，对照封存答案打分，BOT L7）验证的是"能否恢复交换参数"。三个不贴合点：

1. **输入类型不可放大。** 全球公开原始色散数据只找到 10 个蛋白（SCOUT L77），计划自己承认不能说批量能力（BOT L63）。Soojung 的建库对象是 BMRB（T0917 L79, L168），那里大量存在的是指认化学位移、常规弛豫、多条件条目，不是色散曲线。
2. **打分单位不是合作者的单位。** 现在打的是 kex 偏差 ≤25%、态数、残基覆盖（BOT L52–57）；Soojung 要的条目是"有无替代态、哪些残基、能否映射结构、可不可信"（T0917 L149–152），Gina 的判据是峰分裂，不是速率。K-Ras 本身是 GTP 结合态而非 APO；prompt 允许不强套 APO（PROMPT L70），但合作者的第一片是 APO。
3. **已得结论指向别处。** K-Ras 上"流程对数值无贡献，对解释与检查有贡献"（BOT L78）说明工具本来就会拟，agent 的价值在判断、检查和弃权，而这恰好是建库时最需要、也最能在 BMRB 规模上检验的能力。继续在 AQADK/Hypo 上重复数值恢复（BOT L27–46）是在最难扩展的数据上验证最不缺证据的能力。

**更合适的形式：BMRB 条目分诊（entry triage）。**
- **输入：** 一个 BMRB 条目的机器可读内容（样品条件、配体状态、指认位移表，含同一残基的重复指认或多套位移表、缺指认区段、若有的 R1/R2/NOE）加它关联的 PDB 条目；不给论文、不给标题结论。BMRB API 已接好（TOOLS L18–19，`tools.py` L315, L337）。
- **Agent 做什么（六段沿用，动作换掉）：** 一段确认对象与是否 APO；二段盘点该条目有哪几类证据；三段找慢交换特征（一残基两套指认、第二套位移表、连片缺指认即交换展宽、位移推断二级结构在两套间的差异）和快时标特征（R2 异常）；四段处理歧义（是纯度/多聚体/温度差异还是真替代态，条件可比性即 Gina 的过滤层）；五段交叉引用 PDB 看有无对应替代 APO 结构；六段产出条目：有/无/弃权、残基、时标类别、证据、拟议等级、数据质量标记。原色散曲线存在时（那十来个蛋白和 Gina 的论文），现有 19 工具 agent 作为三段里的深分析分支被调用，不丢。
- **怎么打分：** 正例 = 论文明确报告慢交换替代态的条目（Gina 那批论文和五篇源论文关联的 BMRB 号），看召回；负例 = 论文说单一态的条目，看是否弃权而非硬报；再由 Gina 对 5–10 条做等级判定，算人机一致率。这正是 Soojung 的"先穷举后过滤"（T0917 L327）和"5–10 例人判"（T0917 L249–255）。
- **为什么更贴合：** 数据量从 10 个蛋白变成整个 BMRB；输出单位就是数据库条目；判据是 Gina 的定义；失败模式（把坏数据当替代态）正是她最关心的。
