## 要验证的 idea

一个不知道论文结论的 Agent，按谱学家的分析流程，仅凭已沉积的 NMR 数据，能否判断一个蛋白是否存在功能相关的替代（APO）态，并产出领域专家愿意收入数据库的条目。

过去三天验证的是它的一个窄子问题：从原始弛豫色散曲线恢复已发表的交换参数。这个子问题在 K-Ras 上答完了。下一步转向与数据库直接对应的形式，见 `NEXT_STEPS_ZH.md`。

## 做了什么，得到了什么

**任务起点（2026-09-25）。** 从合作方给的五篇 NMR 构象动力学论文（AdK 2015、IL-2 2020、K-Ras 2023、RfaH 2012、RfaH 2025）总结科学家的分析流程；把流程编进一个 Agent；在答案封存的条件下，让 Agent 从作者公开的原始 CPMG/CEST 数据自己分析，检验它能否恢复论文结论；附带比较三种设计的增量：A 只给工具，B 加流程与方法经验，C 再加反思。

**K-Ras 2023（唯一跑通的案例，开发案例，不是留出验证）。**
- Agent：Claude Opus 5.5，无头 Claude Code 会话，只能调用 19 个 NMR 分析工具（MCP 服务器）。论文、作者拟合参数、引用该论文的 BMRB 条目全部封存；沙箱 Python 读不到工作区外的文件。代码在本分支 `src/dynamics_atlas_harness/nmr_agent/`。
- 共 21 条运行。v3 的 9 条运行，交换速率与次态布居的中位数：WT 392 s⁻¹ / 10.2%（论文 400 / 10.15%），G12D 309 / 9.1%（301 / 9.00%），G12C 343 / 7.1%（326 / 6.97%）。带符号的 Δϖ 与作者最终值 715/720 同号。逐条运行见 `evaluation/grading/V3_GRADES.txt`。
- 状态数由 Agent 自己选：9 条都拟合了三态并选两态（BIC、无第二个 CEST 凹陷）。
- 结构解释：给逐区、同残基交集的多参照比较工具后，"Switch I 核心近无规卷曲，Switch II 与远端近 GDP"在 3 条里出现 2 条；没有这个工具时是 1/3。
- 负对照（合成的"次态 = GDP 态"数据）6/6 没被判为无序，且都识破数据不真实。删符号证据后结论收窄；改残基编号后结论不变。
- A/B/C 各 1 条：三组都恢复数值；差异出现在模型比较、对照检查和参照比较这些步骤。
- 确定性检查：本地拟合引擎与 ChemEx 对照，kex 系统偏低约 4%，Δϖ r=0.9996（`results/ENGINE_XVAL_CHEMEX.md`）；三态可辨识性模拟，检测下限约 1%，拓扑不可辨（`results/THREE_STATE_IDENTIFIABILITY.md`）；覆盖审计发现 D33（作者 |Δϖ| 第三大）从未被 Agent 拟合。
- 收尾报告：`results/REPORT_KRAS_CLOSEOUT_ZH.html`。第一轮报告有措辞过度，已在文内加更正框（`results/REPORT_ROUND1_ZH.html`）；独立审查的偏离清单见 `results/FABLE_DEVIATION_REVIEW_ZH.md`。

**流程的沉淀。**
- 五篇论文拆成 37 条决策片段，每条写：观察、未决问题、竞争解释、作者的检查、结果含义、后续动作，并标"作者明确/按证据重建"和原文位置（`workflow/fragments/`）。
- 合成六段流程正本（问题与样品、数据与覆盖、基础分析、区分解释、构象解释、核查提交）与三层提示（`workflow/SCIENTIFIC_WORKFLOW_ZH.md`、`workflow/codex_prompts/`，由 Codex 会话维护）。37 条都有处置，五篇做了桌面推演（`workflow/FIVE_PAPER_TABLETOP_ZH.md`）。只有 K-Ras 在数据上验过。

**第二、三个案例的准备。**
- RfaH 2025：数据入库并封存（`cases/RFAH_DATA_INTAKE_ZH.md`）。ChemEx 方法复现 12 小时，定性复现（慢交换；CEST 两态参数解释不了 CPMG，约化 χ² 3.7），定量不符（kex 5.8 vs 论文 3.3 s⁻¹，pB 14% vs 25%）。疑因只用了主态一组峰，工具缺"观测哪组峰"的功能。
- 新蛋白：公开原始弛豫色散数据的蛋白，全球只找到约十个（`cases/RAW_DATA_SCOUT_ZH.md`）。其中 Dyna-1（Nature 2026）存档含 7 个蛋白的 R2,eff 数据，已下载到集群。

**本分支不包含的东西。** 原始实验数据、Agent 运行记录、封存的作者答案（公开仓库，且为防止泄露给后续解题会话）。Codex 会话的运行时代码（LangGraph 外壳）与工具改动尚未提交，不在本分支；其文档快照在 `workflow/`。

## 目前的主要教训

1. 数值恢复主要靠工具，好模型加拟合工具不需要流程也能算对。流程的作用在解释与检查：比较模型、查对照、逐区比较参照、说明不能支持什么。
2. Agent 的弱点是选残基（覆盖）和在证据不足时收窄结论。这两点是后续检验的重点。
3. 三天里文档对实验比例失衡，计划反复翻转。`BACK_ON_TRACK_ZH.md` 是整理后唯一的计划。
