# HSP90 and ADK development capsule review

## Result

This PR provides a reproducible two-case development integration capsule with
recorded fact proposals, active Draft Rule evaluation, two descriptive scientific
adapters, and one separate exact HSP90 control. It demonstrates a constrained
causal path from fresh Rule state to Planner input, validated card selection or
abstention, selected action execution, and a human-facing packet.

The PR does not establish paper understanding, independent answer blindness, Agent
performance, source-science validity, scientific correctness, broad HSP90
Rule-to-evidence closure, or ADK dynamics portability.

## Causal path exercised

```text
public development question
  -> recorded fact-only Profiler proposal
  -> deterministic admission
  -> current active Draft Rules
  -> fresh unresolved-state materialization
  -> legal public action cards
  -> recorded Planner selection or abstention
  -> deterministic authorization
  -> exactly selected descriptive action
  -> EvidenceResult with explicit Rule effect
  -> human-facing abstention packet
```

The repository cannot technically demonstrate a fresh isolated Agent workspace.
The proposal artifacts therefore use `RECORDED_PROPOSAL_REPLAY_ONLY` and
`ANSWER_BLINDNESS_NOT_INDEPENDENTLY_VERIFIED`, rather than a live-Agent claim.

## Behavioral evidence

The focused tests cover the causal and semantic boundaries:

- changing an admitted source fact can remove a fresh unresolved Rule from the
  materialized Planner input;
- stale HSP90 and ADK Planner references are not materialized;
- a card is offered only for a fresh unresolved reference in the same case with
  verified frozen prerequisites;
- an explicit `ABSTAIN_NO_ACTION` produces no public adapter output;
- a cross-case selection fails before a public action artifact is written;
- a descriptive adapter cannot forge an active Rule effect;
- `NO_EXPLICIT_CONTRACT_OUTCOME` is a lifecycle issue, candidate-only F04/F05/F07
  remains lifecycle-pending, the HSP90 bridge remains method/forward-bridge
  pending, and ADK dynamic coverage remains new-data pending;
- human packets report a sorted unresolved inventory rather than an order-derived
  first blocker;
- the reference comparison labels platform-fixed overlap as
  `BOUNDARY_CONSISTENCY` and leaves free-text fields for human semantic review.

The final validation section is completed from the exact pushed PR head and CI
readback. The source-science gate remains unchanged throughout this delivery.

## What this PR deliberately excludes

- a generic action registry, router, scheduler, DAG, plugin framework, MCP, RAG,

- another HSP90 analysis, a dynamic ADK case, DHFR, a coverage benchmark, or a

  Rule-to-evidence closure.

## Claim ceiling and next gate

The strongest supported statement is limited to this: on two exposed development
cases, fresh deterministic state can materialize bounded Planner input; a recorded
non-authoritative legal-card selection or abstention is validated; only selected
development actions execute; their outputs retain explicit scientific semantics
and Rule effects; and a human-facing packet preserves unresolved scientific
authority.

The remaining gate is a named human/domain source-science review for the current
F01/F02/F03/F04/F06 scope and case applications. The next engineering phase is not
authorized by this PR.
