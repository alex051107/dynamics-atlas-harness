# Research records for maintainers

The group-facing entrypoint is [collaborators/](../collaborators/README.md). This directory is a navigation layer for technical provenance, not the recommended reading path for collaborators.

| Category | Location | Status |
|---|---|---|
| Agent experiments | [agent_experiments](../agent_experiments/) | Historical/current experimental implementations; separate from the portable science replay |
| Frozen evaluation evidence | [four-layer records](../review/four-layer-20260910/) | Completed outputs and sealed scoring, with known interpretation limits |
| External review preparation | [Pro briefing](../review/pro_briefing_20260910/) | Internal prompts, source-history index and review copies |
| Earlier scientific and engineering reviews | [review](../review/) | Historical records; dates and supersession matter |
| Engine design and operational documents | [docs](../docs/) and [governance](../governance/) | Historical prototype contracts, not evidence of general scientific effectiveness |
| Prompt templates | [prompts](../prompts/) | Implementation material, not collaborator-facing content |

Files are kept at their original locations because frozen hashes, citations and runners depend on those paths. Repository history is preserved. The standalone collaborator ZIP contains none of these management or provider-conversation records.
