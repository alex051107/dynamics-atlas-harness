# 纳米盘联合拟合的 Rules 实测结果

由 ΔH5 蛋白和 DMPC 脂质组成的纳米盘是首个试题，问题是同一构象集合能否同时解释 SAXS 与 NOE，并支持形状异质性的判断。选择它是因为作者提供了可用的预测矩阵和实验数据，可以把计算问题与 Rules 的作用分开检查。本轮补了一个仅供 Q05 使用的事实接入口，复用原有输入验证、事实投影和整组活跃 Draft 规则。Rules 本身没有改动。

**这次已经得到真实规则输出，但没有触发数值补算。** 8 种活跃规则在三个来源、两个比较关系和一个研究问题上产生17条实例结果。7条通过声明检查，10条保留未解决。通过的内容是问题、范围、样品组成和测量声明，并未证明联合拟合或纳米盘形状结论。

| 实际结果 | 数量 | 含义 |
| --- | --- | --- |
| 声明检查通过 | 7 | 输入提供了相关声明，未认证科学结论 |
| 输入或比较关系未解决 | 7 | 模拟的时间与坐标支持、条件关系、可比性或独立性仍未知 |
| 进入合同默认未解决分支 | 3 | 来源核验状态没有对应的明确合同分支 |
| 数值补算要求 | 0 | 没有生成可执行的科学计算要求 |

[完整规则输出](raw_rule_results.json)、[逐条摘要](rule_results_summary.tsv)、[执行回执](receipt.json)保留了每个实例的触发原因和处理路线。七条结果指向直接检查，十条指向资料查找。本轮没有运行数值 Operator，也没有把原先的人工 BME 计算记到 Rules 名下。

## 首题暴露的问题

**当前可执行规则主要处理声明和来源关系，还没有覆盖这道题所需的可靠性、构象支持和前向模型计算判断。** 注册表中的这些相关条目仍是候选映射，未进入本轮实际执行的规则集合，可辨识性条目也处于同样状态。[规则快照](rules_bundle_snapshot.json)与[路线清单](route_inventory.json)保留了具体条目。因此这次应记为科学规则与计算路线的覆盖缺口，尚不能说某条已实现的科学判据发生漏判。

另一个较小但明确的问题发生在来源状态的传递。现行投影统一输出 `AGENT_PROPOSED_UNVERIFIED`，来源角色规则的合同没有明确处理这个值，三个来源都落到 `NO_EXPLICIT_CONTRACT_OUTCOME`。它保持了保守的未解决结果，但没有准确解释为何未解决，不能把这三条一概归因于论文缺资料。

完整原始事实仍在[事实快照](original_facts.json)和[公共输入](public_packet.json)中。投影保留了部分方法文字，却没有专门用于 NOE 误差传播、联合目标归一化或预测矩阵数值的字段。这些信息被保存，不等于 Rules 已经检查它们。[投影后的输入](projected_casegraph.json)可以直接核查这一区别。

## 接入口与验证范围

新增内容仅有 Q05 公共事实包、记录的事实提案和一个探测脚本。原来的 `run-case` 登记表保持不变，[此前真实拒收](../q05_rules_baseline_existing_env_v1/receipt.json)也保留。本轮使用新接入口进入原有评估组件，不能把它写成原入口已经支持 Q05，或整条 Operator 执行路线已接通。

接入口通过了一组针对性检查，包括合法输入、六种越界或不一致输入的拒收，以及未知项保留。实际规则探测执行一次，未重跑已通过的28项 BME方法比较，未优化参数，也未修改规则合同。科学结论仍未产生，论文原始联合配置仍未知。

下一步应集中补通一条有科学依据的可执行判据及其数值证据接口，先保存冻结版本的这份覆盖缺口，再另记修复版本的比较结果。没有真实数值义务时，不能把资料查找改名为补算，也不能预先安排一次 BME 计算来制造 Rules 增益。其余19题仍未执行，当前结论只来自首题。
