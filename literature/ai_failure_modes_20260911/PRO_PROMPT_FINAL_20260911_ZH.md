### 目标
我们在做一个 AI agent，任务是判断一组蛋白动力学数据（MD 轨迹、NMR 系综、smFRET、SAXS）里哪些系综量能信、信到哪一级，人做最终审核。我们想给 agent 配一张"规则表"来提升它的科学判断。请审查附件里我们对三个问题的回答，指出错、漏、过严，并逐条回答下面的核实项和设计问题。宏观问题和细节问题都要答。

### 背景（事实）
- 项目证据：规则原文整段进提示，HSP90 方法题从 4.5/5 掉到 2/5；把每个数字绑定到产生它的计算，8 份历史答复里 7 处错误抓到 6 处，零误报；给 agent 的准入卡 4 次运行 0 次被打开；两个自定义"邻域"定义未过正反对照，撤回；要求提交前必须跑算子，同一批题完成率从 58%/74% 升到 98%/100%（但该对比的自由分析组被读取截断，只能支持"可核对"，不能支持效应量）。
- 34 处失败逐条判定：agent 不知道判据 0 处，知道没用上 18 处，输入或机制问题 16 处。典型：一份答复把 FRET 规则的术语一个不差写对，用在了核磁题上。
- 文献：63 篇方法文献抽出 295 条"什么条件下什么证据能支持什么"，写成 58 条候选规则；另检索 53 篇 AI 失败模式文献（2023–2026），精读 8 篇。

### 我们的三个回答（待审）
A1 收什么。只收四类：模型不可能知道的事实（体系专属数值、作者分类、论文里的定义、项目约定）；强制位置上的义务（判据模型已知，价值在位置，进代码）；冲突卡（结果与作者预期冲突时有哪些解释、用什么观测分开，只在检查步给 agent，专家写）；针对 agent 自身判断的检查（翻转预期再问、校准误差、换条件重算）。入表判据只有一条，咬住一处已发生失败，或封住一个结论模板的前提。收集起点是已知的 agent 失败类型，每类失败对应一个决策点，问"这个位置什么检查能拦住它"。
A2 什么形式。规则表本身是给人用的登记簿（出处、状态、对照记录、咬住的案例）。agent 只看四样东西，题面模板（拆成哪几问、每问配什么计算、最高答到哪一级）、算子卡（一张卡等于一个计算，前置条件、参数范围、对照记录、结论上限）、有类型的退回、冲突卡。任何规则不以原文进入分析上下文。
A3 颗粒度。按消费者分两层，题面模板里的宏观内容和代码里的微观内容，两层都不以原文进提示；条目数由失败目录和结论模板封顶，第一轮不超过 60 行。

### 文献里 agent 最容易错的地方（我们的归纳，待审）
F1 无声失败：代码能跑、数像样、无报错、数是错的（CMBAgent、MDGym、MDForge 的假收敛 51%）。
F2 答案对、机制错：换一个条件就崩；一步换条件探针加重算抓到全部案例（Eulig 2026，主模型 20 回合里 4 回合）。
F3 没给判据时自己编判据（ScienceAgentBench、神经科学流水线案例）。
F4 凭记忆报数不跑分析（BixBench 开放题 17%）；方法选择偏差（BLADE 覆盖专家合理方法不到 13%；CauSciBench 默认 OLS）。
F5 跳过验证、伪造产物（Reward Hacking Benchmark，0% 到 13.9%，72% 的作弊附带合理化推理；环境加固相对降 87.7%）。
F6 多步流水线错误级联，缺"拿结果对证据、不对就改"的回路（MAST 14 类、AutoResearchEval 45 类，8 种模型框架组合都出现）。
F7 agent 自己的过度自信与顺从（GIScholarBench、Sharma 2023、Chhikara 2025）。
F8 动力学数据侧的人类陷阱：把时间平均的多态混合当单一态（smFRET，Lerner 2021 给出 confocal <0.1 ms、TIRF <10 ms 的平均阈值）；跨实验室 ΔE 0.02–0.05 的系统偏差被读成生物学差异；拟合用过的数据再当验证。
有效果数字的修补只有四种，全是结构性的：堵住作弊的缝、根因定位反馈（+24 个百分点）、逐阶段诊断加独立评审（假收敛 51% 到 0%）、换条件重算探针。没有一篇报告把要求写进提示词有稳定收益。
